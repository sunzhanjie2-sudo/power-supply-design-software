# 电源设计工作台 · 本地网页版

这是第二阶段的本地浏览器界面：Vue 页面负责输入与展示，FastAPI 负责本机接口，Python `design_engine` 继续提供唯一的计算实现。它与原桌面软件共用计算模块和 Word / Excel 报告排版器，不把电气公式再写一遍到 JavaScript。

当前是本地工作台，不是完整桌面版的替代品，也不是已部署的在线服务。原有 EXE 和桌面入口保留。2026-10-23 补齐了首版遗漏的多项交互，逐模块映射与剩余差异见 [桌面与网页功能核对](../docs/WEB_DESKTOP_PARITY_20261023.md)。

## 1. 项目位置与启动

项目根目录：`<本机路径，不随源码分发>`。

| 位置 | 用途 |
| --- | --- |
| 根目录 `启动网页版.cmd` | 日常启动入口，启动本机服务并打开默认浏览器 |
| 根目录 `run_web.py` | Python 启动器，固定绑定 `127.0.0.1` |
| `tools/setup_web.ps1` | 首次准备 Web Python 环境、安装依赖、构建前端 |
| `web_app/frontend/` | Vue / TypeScript 前端源码与依赖锁文件 |
| `web_app/static/` | 前端构建结果，由本机服务提供；不是新的源码副本 |
| `web_app/*.py` | 接口、任务管理、曲线适配与图表适配 |
| `design_engine/` | 桌面和 Web 共用的计算服务层 |
| `examples/` | 可载入的正式配置示例 |

### 首次准备

需要 Python、Node.js 与 npm。脚本检查 Python 3.11 以上，建议使用项目数值回归所用的 Python 3.13；Node.js 可使用 20.19+、22.12+ 或 24+。

在项目根目录的 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\setup_web.ps1
```

若 `python` 未指向预期版本，可指定解释器：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\setup_web.ps1 -Python '%LOCALAPPDATA%\Programs\Python\Python313\python.exe'
```

该命令只对本次 PowerShell 调用指定执行策略，不要求永久修改系统策略。首次安装依赖需要可访问相应的软件包源。

脚本在项目内建立 `.venv-web`，使用 `--system-site-packages` 复用可用的基础依赖，再将 Web 依赖安装到此环境；它不主动向桌面 Python 环境安装或升级包。因可复用基础包，这不是完全封闭、可任意迁移的运行环境。前端依赖通过 `npm ci` 安装到 `web_app/frontend/node_modules`。

已有依赖、只需重新构建时可用：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\setup_web.ps1 -SkipInstall
```

### 日常使用

双击根目录的 `启动网页版.cmd`。默认地址为 `http://127.0.0.1:8765`，启动窗口需要保持打开。按 `Ctrl+C` 停止服务；停止后当前网页不能继续计算或下载临时报告。

端口被占用时，可在项目根目录手动使用另一个端口：

```powershell
.\.venv-web\Scripts\python.exe run_web.py --port 8766 --open
```

启动器没有开放局域网监听选项。不要通过反向代理、端口转发或修改监听地址，将这一版本直接当成多人在线服务使用。

## 2. 推荐操作流程

1. 从默认的 40 W CCM 反激配置开始，或载入示例 / 现有 JSON 配置。
2. 选择拓扑，填写 `Vinmin`、`Vinmax`、预设效率及适用参数；多路输出在左侧配置输出支路与主反馈路。
3. 在“器件计算方式与曲线”中明确选择固定值估算、曲线计算或逐项覆盖，确认器件位号和坐标方向。
4. 点击计算，等待当前作业完成。工作点、损耗、环路、检查项及报告所需效率数据由后台准备。
5. 在 `Vinmin` / `Vinmax` 间切换，查看同一套固定硬件的两个工况。该切换读取已经算出的结果，不重新设计磁件。
6. 在功率级、器件、电容纹波、磁件、环路页面检查模型结果与限制。需要整定、补偿阻容反推或优化时，先运行候选分析，检查结果，再显式应用；应用后重新计算，才会更新正式结果与报告。
7. 磁件页可编辑疏/密绕、利兹线与交错层序；工程评审页可运行固定硬件角点或冻结 A/B。角点与 A/B 分析结果目前不追加到 Word / Excel 报告章节。
8. 到“报告与检查”下载正式双工况报告。需要后续继续编辑时，另存输入 JSON 配置；需要审计记录时，另存 JSON 计算快照；A/B 如需保留，应另行导出对比快照 JSON。

首次打开页面会自动计算默认配置。之后修改参数不会在每次键入时执行完整计算，需要点击重新计算。页面保留旧图表时会显示“参数已更改”的提示，旧结果不能作为当前设计报告导出。

“取消”是协作式取消：底层数值调用到达取消检查点后生效，不保证点击后立即终止当前原生数值运算。新计算会替换旧计算；不需要连续点击计算按钮。

### 高级分析的使用方式

- “环路”页运行自动整定；“补偿参考电路”页按实际网络正向求阻容或反向求零极点。候选不会自动改工程，点击应用后必须重新计算。物理网络不可实现目标时保留参考图与说明，不生成假的阻容值。
- “效率与优化”页的扫描与优化允许按原桌面流程重新设计候选磁件，不是固定 BOM 的生产角点。扫描点数限 5–41；优化最多 3 个变量、1–20 次迭代和 5–10 种群倍率。预算用尽不代表全局最优，需检查候选的饱和、温升、应力与稳定性。
- “工程评审与对比”中的固定硬件角点采用各路同比例负载，最多 8 个负载点；不替代非反馈路独立轻/重载组合的交叉调整率。失败角点明确保留，不拿其他点代填。
- A/B 冻结服务端返回的完整轻量计算摘要、输入、固定硬件和 `snapshot_id`，不是只复制输入值。切模块或重算不清除已冻结方案，但浏览器刷新会清空内存；需保留时下载对比 JSON。需求不同的方案会提示不可直接判断优劣。
- 磁件页几何预览使用当前已经求出的实际绕组。修改窗口/排层后可局部评估；更改电气匝数、线径或股数后先重算。有效排层不会反向修改 DCR、铜损、漏感或 kij；原有矩形束配置需要主动转换，不自动替换。

高级动作与主作业都在同一独立数值进程中串行执行，可请求取消；编辑输入、切换高级分析上下文会使旧候选失效。不要把尚未应用的候选图当作当前正式工程结果。

## 4. 数值、单位与曲线

### 参数

普通表单显示工程单位，发送给计算层的数值采用 SI。例如输入 `250` 并选择 `kHz`，对应存储值为 `250000` Hz。百分比字段使用界面百分数，计算层使用比例；自定义磁芯和绕线窗口按各字段标明的 mm、mm²、mm³ 转换。

不要仅凭输入框数值判断量纲，请同时核对字段名和单位。完整参数 JSON 支持项目原有格式；直接填写普通数字时，原则上应按计算接口约定使用 SI。历史 `{ "v": 数值, "u": 数量级 }` 配置由共用解析器处理，不能将一个已转换为 SI 的值再乘一次数量级。

### 简洁曲线文件

文件只需保存坐标，名称由用户辨识，不要求文件内携带物理单位。CSV 可以是：

```csv
x,y
0.45,0.01
0.60,1
0.80,5
```

同样的 JSON 可以是：

```json
[[0.45, 0.01], [0.60, 1], [0.80, 5]]
```

导入时先选目标，再按原始数值选择 X / Y 数量级。一个文件有多条曲线时，需要选择实际使用的那条。当前单个曲线文件限 CSV / JSON，大小不超过 5 MiB。

| 导入目标 | X 轴 | Y 轴 | 数量级示例 |
| --- | --- | --- | --- |
| Q1 · 米勒平台的转移曲线 | Vgs | Id | 原图 V、A 均选 `1` |
| Q1 · 栅电荷曲线 | Qg | Vgs | 原图 Qg 数字以 nC 表示，X 选 `n · 10⁻⁹`，Y 选 `1` |
| 对应二极管 · 正向曲线 | Vf | If | 原图电压以 mV 表示时 X 选 `m · 10⁻³`，电流以 A 表示时 Y 选 `1` |

若文件坐标已经换算为 C、V、A，则均使用 `1`，不要再次乘 n、m 等前缀。带结构和 SI 声明的旧格式沿用其既有解析，数量级须为 `1`。

简单栅电荷曲线还必须核对米勒平台起点与终点，输入的是原文件的 X 数值，程序再应用所选数量级。自动建议值不等于已经校核。平台起点表示从 0 V 到平台的 Qgs，平台终点与起点之差表示 Qgd。

二极管列表会区分 `D_IN`、`D1` / `D2`、`D_OUT`，以及多路的 `D_O1…6`（整流）、`D_F1…6`（续流）、`D_B1…6`（输出防反）；实际是否显示取决于拓扑与已启用器件。导入窗口中的位号、用途、X / Y 说明应与原图一致。

“使用全局选择”表示该项继承全局固定值 / 曲线来源；逐项选择可覆盖它。若选择曲线计算但缺少相应曲线，计算层会明确报缺少数据，不悄悄改用固定值。曲线文件正确导入也不代表温度、测试条件、平台边界和外推范围已经适合当前设计。

导入弹窗与“预览 / 复用”中可以查看当前坐标曲线，并临时选择 Y 对数轴；此切换只影响预览，不改变保存数据。二极管曲线只在用户选定另一个位号并确认后复制，不按“型号看起来相似”自动分发。

## 5. 报告、配置与快照的区别

| 文件 | 用途与边界 |
| --- | --- |
| 输入配置 JSON | 继续编辑设计；保留输入设置和内嵌曲线，重新载入后需要计算 |
| Excel `.xlsx` | 按模块组织设计报告，在同一 Sheet 内对照 Vinmin / Vinmax；使用既有 Excel 导出器 |
| Word `.docx` | 完整双工况工程报告，包含参数、检查、图表和模型限制；使用既有 Word 导出器 |
| JSON 审计快照 | 记录该次输入、固定硬件、两工况结果、波形、来源信息与内容哈希；不是可直接恢复 Python 运行时对象的文件 |

报告读取已经完成的计算快照，不在导出按钮中另做一套硬件设计。完整快照文件可能大于输入配置。网页重新导入快照时取其输入 `spec` 作为新设计输入，仍需重新计算；它不会把历史结果伪装成当前运行时结果。

`__comp` 是补偿参考电路的报告配置元数据，不是电气零极点本身。网页补偿页面可以可视化维护四类网络，并显式保存配置用于报告。未标记的旧配置按桌面正式约定 `v × u` 读取，例如 `20` 与 `k` 为 20 kΩ；若确认旧文件的 `v` 已是 SI，只能主动选择“旧文件数值已是 SI”，不能凭数量级静默猜测。网页新保存的补偿状态使用 SI 值、空前缀与 `encoding: "si"` 标记。

新增高级角点和冻结 A/B 的表格、图表结果目前尚未追加进现有 Word / Excel 的相应章节；报告仍按已经重算并保存的正式 `DesignRun` 导出。补偿电路配置显式应用并重算后可以进入原有补偿报告内容，但未应用的候选整定、扫描或优化结果不会自动写入报告。

顶部“计算说明”菜单依次提供 `计算方法与公式说明.docx` 和 `多路反激电源设计入门教程.docx` 下载，教程位于公式说明下方。使用本机 Word / WPS / 兼容软件打开；不是网页内公式编辑器，也不要求连接云文档服务。教程单独维护，不覆盖原公式说明。

## 6. 临时数据与多窗口行为

当前版本每个本机服务只保留一个最新的完整数值快照。一个浏览器标签页提交新作业，会使同一服务中其他标签页的旧图表 / 报告操作失效。它不是按用户、浏览器窗口隔离的多用户设计系统。

作业状态记录有数量上限；图表和生成中的报告位于服务拥有的临时目录。停止服务会清理其临时目录，旧的任务 / 文件链接不能用于长期存档。刷新浏览器也不等于保存项目。请在关闭前下载需要的 JSON 配置、审计快照与报告，浏览器已下载到用户目录的文件不会随临时目录清理被删除。

若页面提示“会话已过期”，先保存仍需保留的输入，再刷新连接当前本机服务。服务重启后原任务 ID、令牌和下载链接均不应当作持久记录使用。

## 7. 架构与本机边界

```text
浏览器 Vue 表单 / 结果页
    ↓ 同源 /api 请求、当前会话令牌
FastAPI（一个本机 HTTP 服务）
    ↓ 有界任务队列、进度与取消标记
独立 Python 数值进程（一次处理一个任务）
    ├─ design_engine → 原电气计算模块
    ├─ 原图表代码 → 按需 PNG
    └─ 原 Word / Excel 排版器 → 当前快照报告
```

HTTP 主循环不负责电气求解；数值进程串行处理计算、图表和报告，避免并发创建多份大型数值结果。取消采用代际标记和既有取消检查点。重算前释放上一份运行时快照；前端按需请求当前模块图表。以上是资源控制机制，不是对任意电脑、任意配置的实时性或内存上限保证。

浏览器本身也占用资源；进程分离主要改善计算期间的响应，不保证总内存比桌面版更低。轻量视图 JSON 与含波形的完整审计 JSON 内容不同，因此内容哈希不同；同一次计算的创建时间、输入、固定硬件和计算摘要一致。

接口仅面向本机同源页面：检查回环访问、Host、Origin 和会话令牌，没有账号、权限分级或多人隔离，也不提供任意服务端路径读取、命令执行接口。它不是适合直接暴露公网的安全架构。前端加载、计算与报告不需要第三方在线 AI 服务。

### 主要接口

下表省略统一的 `/api` 前缀；除 `health` 和 `bootstrap` 外，接口需要当前会话的 `X-Power-Token`。这些接口主要供内置前端使用，仍可能随本地工作台迭代。

| 请求 | 用途 |
| --- | --- |
| `GET /health`、`GET /bootstrap` | 就绪信息、表单元数据、默认配置与会话令牌 |
| `GET /examples/{name}` | 读取白名单配置示例，不接受任意磁盘路径 |
| `GET /manual` | 下载项目内白名单 Word 公式说明，不接受任意路径 |
| `GET /tutorial` | 下载固定的多路反激入门教程，沿用本地会话验证，不接受任意路径 |
| `POST /config`、`POST /preview` | 配置归一化、支路 / 曲线目标预览；不是完成电路求解 |
| `POST /curves/inspect`、`POST /curves/apply` | 检查上传文本、按目标和坐标数量级导入曲线 |
| `POST /jobs` | 提交双端点计算；返回作业 ID，不阻塞等待全部结果 |
| `GET /jobs/{id}`、`GET /jobs/{id}/result` | 查询进度、读取已完成的结果 |
| `POST /jobs/{id}/cancel` | 请求取消未完成作业 |
| `GET /jobs/{id}/chart/{kind}` | 按 `case=Vinmin/Vinmax` 与 `output=1…6` 请求当前快照图表 |
| `POST /jobs/{id}/export` | 请求 `xlsx`、`docx` 或 `json` 导出，返回操作 ID |
| `POST /jobs/{id}/action` | 发起整定、补偿、扫描、目标、优化、角点、多路响应或绕制局部预览；只返回候选，不暗改正式快照 |
| `POST /operations/{id}/cancel` | 请求取消单次高级动作 / 图表 / 导出，保留已成功设计快照 |
| `GET /operations/{id}`、`GET /files/{id}` | 查询导出状态、下载已生成文件 |

计算、图表或报告失败会返回错误，不保证任何输入组合均可收敛。共用引擎的 JSON 约定与来源记录见 `docs/ENGINE_SERVICE.md`。

## 8. 已知限制与桌面差异

- 本次补齐的是逐模块交互与显示，不声明完全覆盖 EXE 的每一个辅助操作、快捷键、报告组合和历史配置变体。完整参数 JSON 仍作为少见高级设置的兼容入口，不应替代日常表单操作。
- 新增工程角点、冻结 A/B 的结果尚未追加进 Word / Excel 报告章节；A/B 可另存 JSON。正式报告只读取已完成计算，不混入未应用的整定 / 优化候选。
- 自动整定、补偿求解和优化可能提示目标不可实现、网络不匹配或预算未收敛。这些是保留的模型结论，不代表软件可以保证某组目标一定成功。
- 绕制编辑是净窗口几何估算，不含端部连接、引线、制造公差和完整安规间距；交错绕制不会自动推导新的漏感 / 耦合矩阵。
- 当前的多路耦合、交叉调整率、环路和开关波形继续采用原模型及其适用范围，网页不会提高模型的物理精度。估算不能替代样机实测、SPICE 验证、热 / 电磁仿真或安规验证。
- MP6005 PSR 不套用 SSR Bode 结果；无可用环路模型时应查看说明，不把空图或缺失裕度视作通过检查。
- 非反馈输出电压、二极管反压、MOS 钳位应力和磁件温升均应按报告中的模型限制理解；例如整流反压不包含实际尖峰，最终耐压选型应留余量并实测。
- 没有项目数据库、自动持久保存、共享账号、云同步或公网部署功能。独立器件提取程序仍是独立项目，不在此目录重复实现自动描点。
