# Windows x64 完整便携程序

| 文件夹 | 双击运行 |
| --- | --- |
| PowerDesignDesktop | SwitchingPowerSupplyDesign_V0.exe |
| PowerDesignWeb | StartWeb.cmd |

每个文件夹是独立程序包，选择需要的整个文件夹复制到其他电脑。不能单独拿走EXE，也不能删 `_internal`。不需要另装Python/Node，日常计算不用联网；网页需要浏览器，Word/Excel需要兼容软件查看（导出不需要Office）。

本批包含上表两个程序包。需要 ZIP 分发时可另运行 `tools/zip_release.ps1`；解压后运行完整程序文件夹。

网页仅在本机 `127.0.0.1:8765` 运行，保留服务窗口；关闭或Ctrl+C停止。端口占用时运行 `PowerDesignWeb.exe --port 8766 --open`。不是多人在线系统。

启动后先显示系统供电架构。添加、拖动、删除和连接节点；双击电源模块进入完整计算，返回时保留各自参数。保存系统工程 JSON 可同时保存全部单元、连线和布局；旧单元 JSON 可直接导入。

多源版增加 OR 汇流与可命名负载。多源接入自动使用独立二极管支路，点连线修改压降或停用；同一输出可连接多个模块与负载。点击“载入 OR 示例”体验完整双源供电网络。

自由画布版：所有节点及竞争二极管卡片都可拖动。Ctrl+滚轮缩放，拖动空白处平移，“适应画布”查看全图。二极管位置随工程保存并同步至报告；右侧属性检查器修改参数，系统预算单独打开或展开查看。

字体与流畅度版：顶部“界面字号”可调整并保留；右侧底部蓝色“保存节点修改/保存支路修改”提交编辑，顶部“保存系统工程”导出 JSON。拖动只更新当前对象和相连的支路，松手保存一次。

本批在Windows 11 x64本机验证启动、实际计算与报告；尚未在另一台实体电脑或所有Windows 10版本上测试。manifest.json提供文件SHA256校验。

公式与设计结果用于初选/复核，仍需仿真、样机与实测。单独角点/A-B结果尚未追加进网页Word/Excel新章节。
