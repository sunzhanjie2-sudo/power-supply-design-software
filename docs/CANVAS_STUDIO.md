# 自由画布工作区

版本：2026-10-31。运行包位于 `releases/Windows-x64/20261031-canvas-studio/`，桌面双击 `PowerDesignDesktop/SwitchingPowerSupplyDesign_V0.exe`，本地网页双击 `PowerDesignWeb/StartWeb.cmd`。复制到其他电脑需复制完整程序文件夹。

## 编辑方式

- 输入源、电源模块、OR 汇流节点和负载：抓住卡片标题或空白位置拖动。
- 竞争二极管：抓住带连接编号、二极管符号和压降的小卡片拖动；右侧修改 Vf、停用或断开支路。“重置二极管位置”恢复连线中点自动位置。
- 连线：从 DC/OUT 端口拖向 IN，或依次点击两个端口；同一输出可连接多个后级。
- 双击电源模块或点击“进入单元设计”，打开该模块的完整计算器。
- Ctrl+滚轮缩放，也可使用加减按钮；空白区域拖动或鼠标中键拖动平移。“适应画布”显示整个网络。普通滚轮上下滚动。
- 点击节点右上角 × 删除，工具栏可撤销一次删除。“自动排列”重新布置全图，同时重置二极管自定义位置。
- 预算、接口与掉电检查：桌面点击“查看系统预算”，网页展开“系统检查与报告”。

保存系统工程会记录节点、二极管位置和全部模块参数。旧工程没有二极管位置时按连接中点显示。布局字段与电气字段独立，拖动、缩放、平移不会重新运行电源数值求解。缩放和平移仅为当前视图，不作为工程物理数据保存。

## 修复与维护

原桌面事件仅允许输入源、电源模块拖动，遗漏负载和 OR 节点；原二极管只有连线装饰。新版补齐四类节点，增加二极管布局数据并处理连续点击引发的 Tk 双击事件。网页保留重绘前的缩放值，按实际 SVG 边界换算指针坐标。

`system_canvas.py` 负责原生绘图，`network_layout.py` 统一桌面和报告的二极管位置；`system_workspace_ui.py` 负责手势和属性面板；网页绘图交互位于 `shared/power_architecture.js`，样式位于 `web_app/frontend/src/system-workspace.css`。工程合同仍为 `power.system-network/2`，可选增加 `layout.diodes`。

## 验证

原生 Tk 事件测试在 75% 和 135% 缩放下拖动负载、OR 节点和二极管，验证坐标、保存重开、电气连接与预算不变。真实 Edge 测试验证两种缩放、三类对象拖动、平移、删除撤销、属性编辑和 JSON 保存重开；拖动与缩放不发送电气校验请求。相关脚本为 `tests/system_canvas_check.py` 与 `tests/system_network_browser_check.cjs`。

最终 Windows x64 程序包已验证：桌面通过真实鼠标拖动三类对象，并核对自动恢复文件中的坐标；冻结网页版完整通过上述交互与实际报告下载。系统总览 Word 渲染为三页，逐页核对图形与表格；自定义二极管位置出现在报告图中。原系统及网络/PCS 合同共 21 项 Python 检查、两组图形检查、完整计算器进入与回存浏览器检查均通过。证据位于 `artifacts/qa/canvas_studio_20261031/` 与 `output/playwright/system-network/`。尚未在另一台实体电脑验证。
