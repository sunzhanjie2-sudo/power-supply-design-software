# 电磁仿真，电路仿真，设计计算联合报告

此流程用于个人Windows桌面版。点击右上角 **导出报告 → 电磁仿真，电路仿真，设计计算联合报告**。窗口、Word主标题和默认文件名统一使用此名称；默认文件为 `电磁仿真，电路仿真，设计计算联合报告.docx`。拓扑页和磁件页的“仿真与报告中心”打开同一窗口，单独调试的入口集中在“工具与模型”。本地Python网页与独立TypeScript浏览器内核本轮没有接入联合任务。

## 日常使用

1. 在当前单元完成电源规格、磁芯、匝数、线材和层序。已有手调匝位置、窗口及绝缘优先保留。
2. 首次使用在“工具与模型”选择本机 Elmer、磁芯实体与装配/定位设置和 LTspice；内置提取内核随程序携带，提取JSON根据当前设计自动生成。换电脑可导入磁芯模型配置包，重新定位本机软件。[便携配置说明](PORTABLE_SIMULATION.md)
3. 在“联合运行与结果”选择输出目录，核对**漏感工程裕量倍数**，点击“开始联合仿真并导出”。默认1.20是项目经验假设，可修改；1.00保留原始场解。
4. 后台依次求解变压器、映射矩阵、复算同一硬件、执行电路验证并生成一个Word报告。界面显示进度，可以取消。
5. 完成后直接打开联合报告或运行目录。自动回填只作用本次导出副本；需要修改当前画布时，点击“采用结果到当前单元”，再返回画布保存系统工程。运行后编辑过的单元不会被旧任务覆盖。

骨架净窗口来自当前设计，r0/z0来自工程或已登记的同型号CAD坐标；缺失时明确提示。完全空白接线可以生成标明假设的参考串联接线。已有但不完整的接线、窗口装不下、气隙不匹配等需要先修正，不自动缩小线径、减少绝缘或扩大窗口。旧外部工具/模板保留在显式兼容模式，默认关闭。

## 裕量如何影响矩阵

原始电感矩阵为 `Lfield`，原始耦合矩阵为 `Kfield`。原边漏感是其余功率绕组全部理想短路时的Schur消元结果，不是各对漏感相加。

```text
Lsc = Lpp − Lps · inverse(Lss) · Lsp
目标 Lsc = 裕量倍数 × 场解 Lsc
K(α) = (1−α) I + α Kfield,  0 ≤ α ≤ 1
L采用 = diag(sqrt(Lii)) · K(α) · diag(sqrt(Lii))
```

保持每个绕组自感，通过一维求根确定统一互感缩放系数α。它是单位矩阵与原正定耦合矩阵的凸组合，避免逐对随意缩放造成不可实现的矩阵。原始矩阵、裕量后的矩阵、实际原边及各副边短路漏感均在报告并列；只有原边漏感保证达到指定倍数，其他端口不保证同倍数。目标漏感不小于原边自感时直接拒绝，不截断为另一个倍数。

这不是实测校准，也不能补偿未知的绕组尺寸或求解器误差。原始场解始终保留。新增的 `coupling_config.port_order`、`self_inductances_H` 保存有序的场解自感，电路采用相同自感和耦合矩阵，保留旧工程按匝比推导自感的兼容路径。

## 覆盖范围与失败处理

| 项目 | 当前覆盖 |
| --- | --- |
| 固定频率反激SSR | 单路及已支持的最多六路矩阵功率级，电路瞬态、环路FRA、适用的交叉负载角点 |
| 有源钳位正激SSR | 变压器矩阵与独立输出电感；同一矩阵进入周期计算及电路仿真 |
| 准谐振反激SSR | 一路主反馈、最多六个功率输出。LTspice保留每个绕组及完整矩阵；解析计算采用总能量的共享QR周期，低频环路按实际匝比折算各路负载与每颗C/ESR。解析侧未独立预测轻载绕组换流脉冲和交叉调整率，两者区别明确列出 |
| PSR、非隔离拓扑的联合场解 | 未接入。不会套用其他拓扑冒充通过；非隔离拓扑继续使用独立电路仿真入口 |
| 变压器场解 | 线性、零偏置磁静态。网格收敛、空气域收敛及样机验证分别标记 |

输入端点按同一套已冻结硬件计算。芯片与补偿沿用当前工程，仿真观察时间和适用任务范围根据现有智能计划准备，不偷偷更换控制器或重新调参来消除差异。

任何前置阶段失败即停止依赖它的后续步骤，保留已生成的证据和明确的未完成原因。取消会停止后台求解并保留诊断，不以以前的成功结果补齐。本次运行结束不等于所有指标满足规格；电路不稳定、FRA未取得或部分角点未完成时报告写明“部分完成”。QR各输出的最小/最大负载完全相同时，不虚构轻重载交叉调整率角点。

后台续跑默认要求同一份冻结输入。另有受控的“仅负载改变”场解复用接口：必须校验原ZIP与所有原产物，逐项核对当前几何、材料、磁芯实体、气隙、接线及零偏置线性条件；仅允许负载功率变化。新输入另存，原场解包和哈希不改，报告注明没有重新求场。不能用它复用已经改变线径、绝缘厚度或磁导率的结果。

## 输出与维护

每次在选定目录下新建唯一“联合仿真”目录，包含：

- 一份联合Word：场解条件、剖面/磁场图、全部矩阵、裕量映射、完整输入端点设计计算、真实电路波形/FRA/适用交叉调整率和证据追溯。
- 冻结输入、采用矩阵后的工程JSON、共享计算快照和 `joint-record.json` 阶段记录。
- 原始变压器几何包、求解日志与场解报告，以及电路对比Word、工程ZIP和 `comparison.json`。

备份时复制整个运行目录。画布只保存精简的结果引用，不把完整波形或层层嵌套的任务历史塞进工程。

维护边界：`joint_simulation.py`负责调度和裕量；`joint_simulation_ui.py`负责集中配置、不可变输入与进度；`joint_simulation_report.py`消费已完成证据。物理公式仍在共享计算模块，报告不另写一套电源公式。
