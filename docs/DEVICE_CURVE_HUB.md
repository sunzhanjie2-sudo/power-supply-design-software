# 器件计算方式与曲线统一入口

2026-10-20。仅调整数据来源选择和交互，不改变 MOS 栅电荷法、二极管损耗积分或多绕组计算公式。

## 使用顺序

左栏“需求与方案”之后是独立的“器件计算方式与曲线”。原 MOS 平台、栅电荷与二极管导入按钮已合并到这里，不再分散于器件参数组。它与需求、功率级组默认展开，也支持折叠和搜索。

1. 选择醒目的“固定值快速估算”或“导入曲线精细计算”。这是器件损耗的数据来源，不是整机精度或仿真等级开关。
2. 在清单选中具体位号和计算项，下方核对用途、X/Y 方向和基本单位。
3. 点击“导入 / 替换所选”，确认数量级并选定曲线。仍支持仅有 x,y 的 CSV 或点数组 JSON，不要求文件携带物理单位。
4. 用“此项计算来源”覆盖全局选择。例如只有 OUT2 导入曲线，其他器件仍用固定值。摘要明确标注混合来源。
5. 看颜色与文字状态，再计算或导出；需要时通过“四工况”窗口并列核对 MOS 结果。

切换全局方式会重置逐项来源例外，但不删除曲线和手动参数。覆盖选“跟随全局”则仅清除该项例外。旧配置沿用旧来源：原先手动仍为手动，原先启用的曲线仍启用；不强行要求补齐所有曲线。旧跨导模式明确标为兼容模型。

## 清单对应关系

| 计算项 | X | Y | 用途 |
| --- | --- | --- | --- |
| Q1 · 米勒平台 | Vgs / V | Id / A | 按开通、关断电流反查栅压，作为动态平台的静态近似 |
| Q1 · 栅电荷 | Qg / C | Vgs / V | 按已确认平台前后支路读取 Qgs、Qg(th)、Qgd 与总 Qg |
| D1 / D2 / D_Oj / D_Fj / D_IN / D_OUT / D_Bj | Vf / V | If / A | 对对应器件的电流波形平均 If×Vf(If) |

只出现当前拓扑启用且有独立损耗模型的器件。反激不会出现正激续流二极管；多输出显示 OUT 对应位号。Q2 钳位 MOS 和 D_SN1 尚无独立曲线损耗接口，不虚构导入入口。旧带 Vgs 分组的 MOS 输出曲线族继续兼容，并明确显示 X=Vds、Y=Id 以及读取 Vds 参数。

## 状态与操作

- 绿色“曲线已启用”：数据通过格式/模型校验且用于此项计算，不代表厂家最差条件或硬件验证。
- 灰色“固定值”：使用下方相应参数；如已存曲线，会显示“已存曲线 / 已存但不使用”。
- 橙色“需校核”：二极管小幅回退已整理，或当前有效计算使用了端点外推；详情给出提示。输入变更后清除旧工况外推状态。
- 红色“待导入”：明确选择了曲线但尚无绑定；计算和报告被阻止，不会静默退回固定值。可先保存中途设计，之后继续导入，或明确改用固定值。

“预览”显示绑定数据及坐标方向。“解除绑定”确认后仅清除当前设计中的这条曲线，并明确改用固定值，不删除源文件。“复用到其他二极管”需要逐项勾选目标、确认替换；仅适用于同型号、同温度与测试条件，不自动推断。

固定值仍在原器件/逐路输出/防反组输入。曲线模式仍需要 Rds(on)、Coss、Vth、MOS 内部栅阻和驱动电阻等未被曲线替代的参数。二极管固定 Vf 仍用于工作点、换流和环路近似，Qrr 单独输入，动态电阻不再使用。

## 保存与报告

`device_curve_settings` 保存全局 `mode`（fixed/curve）及逐项 `overrides`。Q1 两项标识为 `Q1:transfer` 和 `Q1:charge`，二极管以图上位号标识。所有曲线库与手动草稿独立保存，固定值模式不抹除曲线。缺少此字段的历史文件自动保持原行为。

Word 与 Excel 的器件模块新增“器件计算方式与数据来源”，按实际结果逐项记录来源、坐标和曲线名；停用曲线明确标为已存但未启用。原有 MOS/二极管报告保留整理、外推和模型限制。Vinmin/Vinmax 使用同一套绑定，各自重新计算损耗。

这不是新增 SPICE 模型：四个 MOS 开关事件可复用同一条栅电荷参考曲线，Qgd/总 Qg 允许相同；二极管曲线仅参与损耗后处理，未反馈到非线性多绕组换流或 Bode 中。
