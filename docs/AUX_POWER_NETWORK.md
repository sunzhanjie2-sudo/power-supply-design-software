# 可配置辅源供电网络

2026-10-31。本版将独立计算器的架构从单上游树扩展为供电网络，单个电源的电气计算继续使用原内核。

## 节点和连接

可配置四类节点：外部输入源、电源计算模块、二极管 OR 汇流节点、终端负载。每个节点可命名、拖动、删除和停用；负载可输入功耗与允许电压范围。负载电压上下限填0表示不限定，不是0V供电。

同一输出可以连接多个模块、汇流节点和负载。多个输入源也可以接到同一个模块或负载：第二条支路接入时，现有及新增输入自动改为二极管隔离，默认 Vf=0.3V，用户需按实际器件修改。也可先将多源接入 OR 汇流节点，再由同一母线向多个后级分配，避免将同一组实体竞争二极管重复画在各负载前。

连接是独立对象，选中连线可以设置直连或二极管、修改 Vf、停用或断开该支路。删除一个源只移除相关连接，其余输入仍保留。一级撤销可恢复原来的多源关系；随后重新接线的下级不会被恢复操作覆盖。多个启用输入禁止直接并联，避免把不具备均流能力的普通电源当成并联电源。

“载入 OR 供电示例”展示主辅源与电池备用源竞争供电、24V 母线同时供给风扇与12V控制电源、12V再供给DSP采样板和继电器通信负载。节点名称、功耗、压降和所有连接均可修改。示例配置：`examples/SYSTEM_AUX_ORING.json`。

## 预算方法

- 二极管采用固定 Vf。竞争节点选择二极管后电压最高的支路；同压时逐支路独占供电枚举，不假设均流。
- 直连支路功率等于下游需求；二极管支路按输入功率 = 下游功率 × 上游电压 / 二极管后电压，损耗为输入与输出功率之差。
- 变换器输入需求按配置总额定输出功率 / 预设效率。后级电源与终端负载占用相应输出端口容量，不再次叠加到上游模块输入，避免重复计数。
- OR 汇流节点需求来自实际连接到该母线的所有下游分配；可以设置母线容量并检查是否超额。
- 评估全部已启用输入、逐源掉电、单源独供，并组合全低/全高/逐源高压端点；相同工况合并。表中正常值与已评估最大值分列，另记录发生最大分配的工况。
- 各节点显示可用输入电压范围、设计范围和失电情况。“沿用上游电压”将已评估的二极管后范围写入模块 Vinmin/Vinmax；连线本身不修改单元设计。

这是固定 Vf 的标称稳态架构预算。没有仿真软启动、切换瞬态、尖峰、反向漏电、温度影响或真实电流分配；变换器输出采用当前设计标称值。未遍历所有独立电压组合。大量同压分支设有组合限额，触及限额会标记覆盖不完整，预算不判为通过。供电图保持无循环；控制器自供电、启动电路等应区分功率输入与控制负载，而不是把它们画成同一个功率输入端口。

## 工程和报告

工程采用 `power.system-network/2`，独立保存节点列表、连接列表和布局，自动迁移旧 `pcs.aux-workspace/1` 工程及原单元JSON。旧版软件可能无法读取新网络工程，应先确认合同版本。

报告ZIP包括供电网络总览Word、可放大的网络SVG、网络预算Excel、每个电源模块原有 Vinmin/Vinmax Word/Excel、工程JSON与交付清单。预算Excel按节点、连接、容量、电压/失电、二极管损耗和竞争工况分表。失电节点和单元计算失败均单独标明；架构停用不会删除该单元的独立设计文件。

## 维护

`power_network.py`：合同迁移、校验、拓扑顺序与竞争供电预算。

`system_workspace.py`：编辑操作、输入同步、端口减少、撤销与原子保存。

`system_workspace_ui.py` / `web_app/frontend/src/SystemWorkspace.vue`：桌面及网页编辑入口，均调用相同的 Python 预算模型。

`network_report.py`：网络总览和预算表；各变换器报告仍调用原设计服务。

`tests/power_network_check.py`、`tests/system_network_graph_check.cjs` 和 `tests/system_network_browser_check.cjs`：数值账目、图形关系和实际交互验证。
