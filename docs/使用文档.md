## 0. 这是什么

一个桌面（Tkinter）工具，按参考书的设计流程做**开关电源功率级、器件应力、磁件、环路、效率、电容纹波电流与 RCD 钳位**的分析与设计检查。支持拓扑：

- BUCK（降压）
- BOOST（升压）
- BUCK-BOOST（升降压）
- FLYBACK（反激）
- FLYBACK-QR（准谐振反激，BCM / 谷底开关，变频）
- ACF-FORWARD（有源钳位正激，低侧钳位、双二极管次级）

主界面共十页：①拓扑示意、②至⑨设计流程与⑩工程评审。设计检查在 GUI、API 与 Word 报告之间共用同一计算口径。

启动默认是用户的 40W CCM 反激配置：30V→30V、250kHz、Lm=8µH，保留原器件、磁件、补偿与钳位参数，不自动整定。左栏支持搜索、基础/高级显示和分组折叠。⑩提供后台可取消的 15 个固定硬件角点，以及冻结方案 A 与当前或 JSON 方案 B 的指标和 Bode 对比；输入变化后旧结果失效，有效结果可随 Word 导出。

2026-10 更新：柱状图长标签改为水平排列，电容频带按电容拆分小图。文件菜单可直接加载 **40W 有源钳位正激** 示例（30V → 30V / 40W / 250kHz）；L=68µH 是输出电感，独立励磁电感 Lm=220µH，钳位电容47nF。⑧ 页随拓扑自动显示有源钳位，环路带宽有谐振上限提示。完整计算范围与资料见 [有源钳位正激说明](ACTIVE_CLAMP_FORWARD.md)。本次功能仅针对 Python 桌面/API，未修改独立网页版。

## 3. 十个标签页

### ① 拓扑示意

- 六种拓扑的矢量参考原理图；位号表映射软件当前参数。
- Q1 对应功率级开通 / 关断图；输入输出第二只电容、防反二极管与 RCD 随配置显示。
- 有源钳位正激采用低侧 P 沟道 Q2 参考连接，需负栅压驱动；图中不展开栅极驱动。
- 图为工程示意，未展开 ESR/ESL 和寄生参数，不是可直接生产的原理图。

### ② 功率级 & 波形（书 ch.2/3）
- 输入规格（Vin/Vo/Po/f_sw）与 L / C_out。
- 输出占空比、CCM/DCM、输出纹波、L_min、C_min、电容纹波电流 RMS、ESR 损耗、效率、RHP 零点提示。
- **固定 2×3 波形板（按行）**：Q1 MOS 电流、D1 二极管电流、输出纹波、输出电压、Q1 开通 Vgs/Vds、Q1 关断 Vgs/Vds。
- 开通图对应 t1–t4，关断图对应 t5–t8，标明实际分段时长。默认阶段展开（非等时长），可勾选真实 ns 时间轴。
- t1/t2/t3/t6/t7/t8 使用损耗计算的同一结果；t4/t5* 为剩余栅电荷的补充估算，不改变损耗，缺少有效电荷时显示未知。详见 [MOS 分段波形说明](MOS_SWITCHING_CHARTS.md)。
- 图为分段模型重建，不是实测瞬态，不包含寄生振铃；QR/钳位图不代表实际谷底/ZVS。电容纹波计算与额定值检查仍保留，详细电容分析在⑦页。
- QR-Flyback：由 Vin/Vo/N/Lm/Coss/η 计算**变频 f_sw（BCM）**，对比 f_max 限制，超频红色警告；开通按谷底（Eon≈0）计。

### ③ 器件应力（书 ch.4）
- 开关管与二极管的电压/电流应力表 + 损耗分解柱状图。
- 开关损耗用**栅极电荷法**（Vgs(th)/Vgp/Qg(th)/Qgs/Qgd/Rg_drive/Rs_on/Rs_off/Rg/k），另含 Coss 损耗。
- 反激开关管稳态阻断 `Vds = Vin + V_reflect(N·(Vout+Vf))`；若选了 RCD（Kc>1），**Vds 峰值 = Vin + Kc·V_reflect**，并在说明行标出。
- 底部给出建议额定值（≥1.2~1.5 倍裕量）。“元件应力与损耗分解会随 RCD 选择变化”。

### ④ 磁件设计（书 ch.10~12）
- **二级磁芯目录**：先选形状，再选型号（EE/EI/EF/EFD/EPC/EP/ER/EER/ETD/PQ/RM/PM/PT/环型T/UU，60+ 型号，参照东磁 DMEGC/国际标准尺寸）。
- 面积乘积法选芯、匝数、气隙、线径；**电流密度 J 由线径×并绕数与计算出的 I_rms 派生**，不作为输入。
- 可手工输入每圈平均长度 MLT、原/副边匝数 Np/Ns、线径与**并绕数**（0=自动）。
- 磁芯损耗按波形选模型：方波/PWM（反激、QR 变压器）→**NSE**（书式 3.23~3.25，按实际 B(t) 波形数值积分）；直流滤波电感（三角磁通）→NSE 积分（与 iGSE 闭式等价）。
- 左图磁通 B(t) 与饱和界限 Bsat（裕量 %），右侧含温升 ΔT=P/(h·A)（可编辑对流系数 h）。
- 饱和/温升超标时页面红字提示。

### ⑤ 环路设计（书 ch.8/9）
- 对象 Gvc / 补偿器 Gc / 开环 Bode 图；给出相位裕度 PM、增益裕度 GM、穿越频率 fc。
- **type2 / type3 自动整定**，输入目标 fc / PM；显式类型不被 VM/PCM 覆盖，auto 保留 PCM→二型、VM→三型。保留原版五个零极点输入，二型只使用 KP/fz1/fp1。
- PI 新选项已撤回，旧配置迁移为 auto，需重新核对环路。二型含原点极点、一个有限零点与一个有限极点；三型含原点极点、两个有限零点与两个有限极点。
- **峰值电流模式（PCM）模型**（Buck/Boost/Buck-Boost/Flyback）：控制到输出 `Gvc = Fm·Gvd / (1 + Fm·(Fi·Gid + Fv·Gvd))`，其中 **Fi = Rs·A_sense**（采样电阻×采样放大倍数）进入电流内环反馈，Fm = fs/(Rs·A_sense·(ma+(M1−M2)/2))（参考 Ridley/Basso 模型；与参考实现逐点对比 0 偏差）。因此**环路增益与 Rs·A_sense 成精确反比**（Rs 翻倍 → 开环增益 -6dB）。新增参数：**A_sense（电流采样放大倍数，芯片内部 CSA 增益，默认 1）**与 **ma_slope（斜坡补偿, A/s，默认 0）**，均随配置文件保存。若 ma+(M1−M2)/2 ≤ 0（无斜坡补偿且该拓扑在此占空比下会出现），Fm 自动按上升/下降平均斜率近似并在⑤页提示。
- 注意：
  - **Boost / Buck-Boost / Flyback 有右半平面零点（RHP zero），fc 必须远低于它**（通常 fc < 1/5~1/10 f_RHP）。
  - **RHP 零点仅 CCM 存在**（公式 `f_RHPZ = Vin·(1−D)/(2π·Lp·Io·n)`, n=Np/Ns）；**DCM 与准谐振 BCM 均无 RHP 零点**。
  - ⑤ 页 Bode 的对象传函：**CCM 用 CCM 模型（双极点+RHP 零点）；DCM/BCM 用单极点 DCM 模型（不含 RHP 零点）**。
  - **输出电容 ESR 零点 ωz=1/(Rc·Cout)**：各拓扑小信号模型均按理想电容，未含该零点，页面上有提醒，如需精确请自行环路仿真。

### ⑥ 效率 & 优化
- 损耗分解柱状图：**半导体 + 磁件 + 电容 + 采样 + RCD + 输入/输出防反二极管**；效率-负载曲线。
- **防反二极管**：功率级勾选启用（默认开），输入防反管流过脉冲输入电流 `P=Vf·I_avg+Rd·I_rms²`，输出防反管在输出电容之后流过负载电流 `P=Vf·I_out+Rd·I_out²`；压降不折算进运行点（一阶模型）。
- 效率-参数扫描（f_sw/L 等）与**遗传算法（DE）优化**，可查找指定目标效率的参数。
- **效率口径（重要）**：输入 `eta_guess` 是固定预设设计效率（例如 0.93 表示 93%）。六种拓扑先由预设效率建立工作点，波形、器件应力、电容电流、磁件和环路使用同一工作点；保持实际输出电压、功率与负载电流不变。随后按半导体（MOSFET 导通/开关/Coss/栅极、二极管导通与反向恢复）、磁件（磁芯+铜损）、输入与输出电容 ESR、采样电阻、RCD、输入与输出防反二极管以及正激钳位电容损耗，独立核算最终 η=Pout/(Pout+ΣP)。损耗预算不再次加入 ΣP，最终效率不覆盖预设。**未计**温度效应、辅助/控制电路功耗、输入整流桥、PCB/连接器铜损、EMI 滤波及其他吸收电路等；**效率是模型估算，并非实物效率，不保证固定误差或实测上限**。预设与最终效率差距较大时，应调整预设、重新计算并复核环路。

### ⑦ 电容电流纹波
- 每只电容的纹波电流 RMS、频率分带（flat-top 窗 FFT）、电容组等效阻抗 Z1∥Z2，给出纹波电压与 ESR 损耗。
- 输出/输入电容默认两只并联（各带 C/ESR/ESL）；输出纹波按两只电容的**合成阻抗**计算，ESL 尖峰单独报告。

### ⑧ RCD 吸收（钳位）
- 反激/QR 原边漏感的 **RC 钳位**设计。
- 输入：耦合系数 **K**（→漏感 `L_leak=(1−K)·Lm`）、钳位比 **Kc = Vclamp/Vreflect**、钳位电压波动比例 **ΔC（0~1，默认 0.1）**。其余 `V_reflect / Lm / I_pk / f_sw` 取当前运行点。
- 输出：`Vclamp = Kc·Vreflect`、`ΔV_c = ΔC·Vclamp`、`P_res = 0.5·L_leak·Ipk²·f_sw·Vc/(Vc−Vr)`、`R_snub = Vclamp²/P_res`、`C_snub = Vclamp/(ΔV_c·R_snub·f_sw)`，并画 **Vclamp(t)**（快充漏感充能→慢放 RC 放电）与漏极钳位波形。
- **该选择会同步影响③器件应力（Vds 峰值 = Vin + Kc·Vref）与⑥损耗分解（计入 RCD 功率，降低 η）**。

### ⑨ 环路补偿电路参数
- **双向设计**，页顶可选方向：
  - **正向：环路参数 → 阻容值**。由⑤页 K 因子整定得到的 **KP / fz1 / fz2 / fp1 / fp2** 反推实际补偿网络的阻容值，只需填少量初始阻容（分压/LED/光耦参数）。
  - **反向：阻容值 → 环路参数**。输入补偿电路的**全部阻容值**（图上命名），反推 KP/fz/fp 并**自动写入⑤页**，环路 Bode 图、PM/GM/fc 随之更新。省略支路的电容填0；恢复原版1GHz缺失频率占位，不自动识别PI控制器。占位与消失支路不保证完全等价。
- 四种拓扑可选，页内**直接显示对应的参考电路图**（阻容命名与图完全一致）：
  1. **普通运放三型**（图"Ⅲ补偿"，命名 R1/R2/R3 + C1/C2/C3）：填 R1 与 Vref → R2(反馈串联)/R3(输入支路)/C1/C2/C3 + 下分压 R_lower；
  2. **跨导运放三型**（图 gm，命名 R1/R2/R3 + C1/C2/C3）：填 R2/gm → R1/R3/C1/C2/C3（原版简化支路需自填 R1）；
  3. **TL431+光耦三型（无快车道，LED 接独立偏置）**（图 p.45，命名 R1/R2/R3 + C1/C2/C3）：填 R1/R_LED/CTR/R_pullup/C_opto → R2/R3/C1/C2/C3 + R_lower，附光耦极点（应 ≥10×fc）与 R_LED 偏置校验；
  4. **TL431+光耦三型（快车道，LED 接 Vout）**（图 p.44，命名 R_pz/C_pz/C2）：填 R1/CTR/R_pullup/C_opto → C1/R_pz/C_pz/R_LED/C2 + R_lower。
- **原版二型简化支路**独立勾选：运放 C2=C3=0；跨导 C1=C3=0。这一元件简化不含⑤标准二型的高频极点，两者不一一对应。
- 结果附**回代校验**（仅检查 KP，不保证全部零极点逐项匹配）与设计提示。TL431 公式与命名按 TND381-D（Basso），两种形式 KP 相同：**KP = CTR·Rpullup/(R_LED·R_upper·C1)**（积分器增益；快车道在高频存在平坦增益地板 CTR·Rpullup/R_LED）；无快车道 fz1=1/(2πR2C1)、fz2=1/(2πR1C3)、fp1=1/(2πR3C3)、fp2=1/(2πRpullup(C2+Copto))；快车道 fz1=1/(2πR1C1)、fz2=1/(2π(R_LED+R_pz)C_pz)、fp1=1/(2πR_pzC_pz)。

## 4. 关键公式/单位约定

### 磁芯损耗
`Pv[mW/cm³] = k·(f_sw/kHz)^α·B[T]^β`，内部：`f_sw` 用 kHz、`B/ΔB` 用 T、`Pv` 用 mW/cm³；`1 mW/cm³ = 1 kW/m³`。

### 漏极电压（反激）
- 稳态阻断：`Vds = Vin + V_reflect`，`V_reflect = N·(Vout+Vf)`，`N = Np/Ns`。
- 有 RCD 时钳位峰值：`Vds 峰值 = Vin + Kc·V_reflect`。

### 右半平面零点（仅 CCM）
`f_RHPZ = Vin·(1−D)/(2π·Lp·Io·n)`，`n=Np/Ns`。`DCM 与 BCM 无 RHP 零点`。

### 输出电容 ESR 零点
`f_ESR = 1/(2π·Rc·Cout)`。环路模型按理想电容处理，页面上有提醒。

## 5. 注意事项 / 局限

- **磁芯库尺寸为典型值**，正式设计请按所选磁芯手册核对（尤其 PQ 各高度档、新增 EF/EFD/EPC/EP/ER/EER/PM/PT/环型/UU 等为估算）。
- DCM 运行时 ⑤ 环路仍按 CCM 近似？——不：已改为 DCM 用单极点 DCM 模型（不含 RHP 零点）。
- RCD 损耗来自漏感能量；若损耗偏大，提高耦合系数 K（更紧耦合）或适当增大 Kc。
- 参考书 PDF 不打包进 exe（避免体积）；`帮助→打开参考书` 会在 exe 旁和打包内查找。
- 环路分析是**小信号平均模型**，非开关级仿真；高频行为建议用 LTspice/PSpice 复核。

## 6. 配置文件
- 菜单 `文件 → 保存配置` 生成 JSON；`打开配置` 导入。版本信息写入配置。
- `文件 → 导出设计报告`（或顶部按钮 / `Ctrl+E`）默认导出完整 Word `.docx`：需求与当前设定、工作点/核查、关键波形、功率器件、电容纹波柱状图、磁件参数/磁通/损耗、Bode/裕度、钳位、效率与输入附录。可另选旧 Markdown 摘要。导出刷新当前参数并独立生成图表，不要求访问过页签。帮助菜单可打开随程序打包的《计算方法与公式说明.docx》。
- ⑧ RCD 页的 **耦合系数 K、钳位比 Kc = Vclamp/Vreflect、钳位电压波动比例 ΔC** 一并保存在配置中（键 `rcd_K` / `rcd_Kc` / `rcd_dC`），加载后自动恢复并联动③应力与⑥损耗；旧版配置文件缺少这些键时保持当前值不变。
- 控制器类型保存为 `controller_type`，缺少此键的旧配置恢复为 `auto`；⑨的**设计方向（正向/反向）、补偿器电路拓扑与已输入阻容值**（含单位）保存在 `__comp` 中，加载后恢复输入面板。旧 `type2` 布尔字段仅为兼容保留，不覆盖统一的控制器选择。

## 8. AI / 自动化调用（无头 API + CLI + MCP）

计算引擎完全可无头调用，供 AI 工具链或脚本批量使用（无需打开 GUI）。

### 8.1 设计 API（design_api.py）

```python
import design_api
report = design_api.run_design({
    'topology': 'BUCK', 'V_in': 12, 'V_out': 5, 'P_out': 5,
    'f_sw': 100e3, 'L': 47e-6, 'C_out': 100e-6, 'pm_target': 60})
for c in report['checks']:
    print(c['id'], c['value'], c['limit'], 'PASS' if c['pass_'] else 'FAIL')
```

- `run_design(spec)`：完整报告 —— 工作点/损耗/磁件/`checks[]`（每项 `{id, name, value, limit, pass_}`）/`warnings`
- `run_corners(spec, v_in_min, v_in_max)`：角点分析（输入范围 × 负载 10~100%），输出最坏 η、最大 I_pk、最大纹波、DCM 边界
- `load_transient(spec, di, fc)`：负载阶跃 ΔV 估算（ESR 阶跃 + 环路响应期容性跌落）
- `autotune_loop(spec, fc, pm)`：K 因子整定（BUCK），返回补偿器参数 + 回代实测 PM/fc
- spec 接受 SI 纯值或配置文件的 `{'v':..,'u':..}` 格式；未知键直接报错（防拼写错误静默通过）

### 8.2 CLI（cli.py）

```
python cli.py design    --spec spec.json --out report.json --md report.md
python cli.py corners   --spec spec.json --out corners.json
python cli.py transient --spec spec.json --di 2.0 --out t.json
python cli.py autotune  --spec spec.json --fc 10e3 --pm 60 --out comp.json
```

退出码：`0` 全部检查通过；`1` 有检查未通过（AI 可据此迭代设计）；`2` spec/计算错误。

### 8.3 MCP server（mcp_server.py，已配置好）

AI 客户端（ZCode / Claude 等）可直接把本工具接入为 MCP 工具。**本仓库已带工作区级配置**
`.zcode/config.json`（指向 `mcp_server.py`），在此项目目录下打开 ZCode 即自动连接；
如需全局（任何目录）可用，把同样的 servers 条目加进 `~/.zcode/cli/config.json` 的 `mcp.servers`。

```json
{ "mcp": { "servers": { "psu-designer": {
    "type": "stdio", "command": "python",
    "args": ["<本机路径，不随源码分发>"],
    "enabled": true, "timeoutMs": 30000 } } } }
```

提供 5 个工具：`run_design` / `run_corners` / `load_transient` / `autotune_loop` / `list_parameters`。
配置后重开 ZCode 会话，AI 即可"设计→看检查→改参数→再验证"多轮迭代。
