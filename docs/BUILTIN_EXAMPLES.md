# 内置电源与控制器示例

桌面文件菜单和网页版使用同一份示例目录。保留三个隔离电源入口，并增加三种 Buck/Boost 控制器示例。历史文件保留用于回归、既有链接和原始仿真证据。

| 入口 | 配置 | 说明 |
| --- | --- | --- |
| 三路有源钳位正激 · MP6005 · 小电感 | `33W_3OUT_ACF_MP6005_COMPACT.json` | 20–30 V、250 kHz，总额定输出33 W，OUT1主反馈 |
| 三路 CCM 反激 · 用户配置 | `40W_CCM_3OUT_FLYBACK.json` | 用户提供的“40W CCM 多路反激.json”原样复制，20–30 V，副边匝数12/5/2 |
| 准谐振反激 · L6565 | `90W_QR_L6565_300V.json` | 300V、60V/92W，采样增益1，计算与仿真有效漏极电容470pF，标准二型1kHz/60° |
| Buck 电压模式 · TPS40200 参考 | `24W_BUCK_VM_TPS40200.json` | 18–30V→12V/24W，50kHz，三型补偿；较长阶跃前等待，检查慢恢复尾段 |
| Buck 峰值电流 · LTC3864 参考 | `24W_BUCK_PCM_LTC3864.json` | 同一套 Buck L/C/Ron/DCR，50kHz，二型补偿，CS/ITH 分域 |
| Boost 峰值电流 · LM5022 参考 | `24W_BOOST_PCM_LM5022.json` | 9–18V→24V/24W，50kHz，二型补偿；斜坡也进入逐周期限制 |

新增三项使用原创可配置行为控制器，不增加独立原厂模型验证。快速闭环模式不验证结电容尖峰。每项均可导出可读 ASC、实际开关 FRA、半幅复核及 Word/证据 ZIP；详见 [使用与模型边界](BUCK_BOOST_SPICE.md)。

## 正激电感调整

| 输出 | 原示例 | 新示例 |
| --- | ---: | ---: |
| OUT1 | 1000 µH | 100 µH |
| OUT2 | 1500 µH | 330 µH |
| OUT3 | 220 µH | 47 µH |

励磁电感仍为220 µH，独立于上述滤波电感；主字段L与OUT1一致。选择较小电感以减少低功率方案的磁件负担，代价是纹波电流增加。计算复核两输入端的标称负载均为CCM；轻载允许DCM，不承诺全部负载仍为CCM。

非反馈路电压随匝比、漏感、整流压降及负载改变；沿用原匝数时不强制它们分别等于12 V和5 V。电感减小不能替代饱和电流、RMS温升、磁芯损耗和样机检查；原变压器窗口不足提示继续保留。

原大电感版 `33W_3OUT_ACF_MP6005.json` 及它的实测对比报告保持原样。旧报告的精度数字仅对应旧硬件参数，不能直接套用到小电感版。新原生仿真验证记录独立保存在 `artifacts/qa/example_catalog_20261028/`。
