# 通用反激闭环 LTspice 模型与对比报告

版本：GenericFlybackPWM-3.1，2026-10-25。支持固定频率反激、SSR、1–6 路输出，以及峰值电流或电压模式。模型独立实现，参考 MP6005 的公开时序，不是 MP6005 的完整硅模型。用户提供的原始 LIB、PDF 和 ASC 未被覆盖或整体打包。

3.0 补上逐周期检查、斜坡补偿来源、外部 CS 滤波、软启动结束后释放 COMP 临时上限，以及原副边电流、逐路纹波、原生开关闭环 FRA 和交叉负载角点的完整报告。详细测量口径见 [全面仿真对比](SPICE_COMPREHENSIVE_COMPARISON.md)。

3.1 统一节点：输出 outN 在防反管后，反馈和 FRA 功率级探针取防反管前 capN。主反馈参考为端口目标加该路固定防反压降；未启用防反管时两节点重合。详见 [输出与反馈节点](OUTPUT_FEEDBACK_NODES.md)。

## 1. 在设计软件中配置

桌面版在“文件 → LTspice 反激闭环仿真”进入设置；也可直接选择“仿真与设计计算对比报告 (Word)”。网页版在“报告”页设置。参数随项目 JSON 保存。

六组设置为：频率与 PWM、软启动逻辑、短路与过载保护、测试与对比报告、环路与交叉调整率、补偿与寄生。

- **频率**：0 表示跟随当前设计；非零为独立的芯片仿真频率。覆盖频率不修改设计计算；报告并列列出两者。
- **Vcs 钳位**：原始采样端逐周期限流阈值，不是放大后的比较器电压。0 根据两端计算峰值留 40% 初始余量，并非芯片规格。A_CS 只作用于调制比较。
- **斜坡补偿**：默认采用工程建议值，与已有设计斜坡取大值；也可跟随设计或手动指定。建议值为最大副边反射下降斜率的 0.75 倍，换算到放大后 CS 电压域，并非 MP6005 的实测规格。旧文件明确设置的非负手动斜率继续保留；旧 -1 自动项改用工程建议。
- **软启动**：输出参考缓升、CS 限流阈值缓升、COMP 上限缓升三种；使能、UVLO 或保护关断会复位软启动。
- **保护**：仅逐周期限流、关断后打嗝重启、故障锁存至关闭使能。SCP 高阈值与持续 OCP 的 OLP 延时独立配置。仅逐周期限流模式不触发打嗝或锁存。
- **短路测试**：可选输出编号、开始时刻、持续时间与等效电阻。对比报告额外运行故障工况，标称对比工况关闭短路注入。输出电容瞬时放电电流不等于 MOS 电流。
- **取消**：桌面及网页均在后台运行，可以取消当前任务；只终止本任务启动的 LTspice 进程。

“填入 MP6005 SSR 参考配置”不是型号锁定，所有值仍可改。它采用用户提供的 MP6005 Rev1.1 数据表第 5、6、18–19 页的典型值：

| 项目 | 参考配置 | 含义 |
|---|---:|---|
| 开关频率 | 250 kHz | 固定频率，不包含轻载变频/跳周期 |
| 最大占空比 | 70% | 每周期强制复位 |
| CS 逐周期限流 | 160 mV | 典型值，未扫描 140–180 mV 离散性 |
| SCP | 300 mV | 高于普通限流；未扫描 240–360 mV 离散性 |
| 前沿消隐 / 最小导通 | 250 ns / 250 ns | 正常比较与限流按各自规则处理 |
| 使能延迟 | 500 μs | UVLO/EN 有效后开始计时 |
| SSR 软启动 | 4.7 ms | COMP 上限从 1.5 V 线性升至 3.5 V |
| OLP | 4.8 ms | 软启动完成后，持续 OCP 触发 |
| OCP 保持窗口 | 50 μs | 每次 OCP 刷新；窗口内无新 OCP 则复位过载计时 |
| 打嗝关断期 | 340 ms | 期满重新启动并复位软启动 |
| SCP 独立消隐 | 250 ns | **可配置模型假设**，不声称为数据表明确给出的独立参数 |

预设把阶跃时刻至少放在 12 ms、结束至少 18 ms。较慢的环路仍可能需要延长。要观察完整的 340 ms 打嗝重启，应相应延长结束时间和每工况超时；不能把未观察到的重启写成已经验证。

## 2. 原生可读 ASC 与文件结构

解压整个 ZIP，用 LTspice 打开 Flyback.asc。ASC 采用原生元件、子电路符号和真实连线：输入在左，原边与 RCD 居中，各路副边在右，控制器在下，主反馈选择器和回路线清楚标出。Q1、LP、LS1..LS6、XD_O1..XD_O6 与各路电容均可定位。

图上的 {LP} 等是可配置参数；实际值在同目录 design_params.inc。元件显示为块时，内部电路在 LIB 中可查看。未启用的防反二极管在通用块内旁路，未启用的并联电容 ACT=0。

| 文件 | 用途 |
|---|---|
| Flyback.asc | 完整原生电路，1–6 路模板由 LTspice MCP 生成与校核 |
| Flyback.cir | 相同连接关系的网表入口，可独立运行 |
| design_params.inc | 设计派生值、控制器值、Vin 两端的 .step |
| power_stage.inc | CIR 的功率级及控制器实例；**ASC 已放置，不可重复包含** |
| coupling.inc | 全部绕组两两耦合，沿用有效的用户 kij 或由漏感推导 |
| support.inc | 可选短路注入开关、监测行为源 |
| analysis.inc | .tran、.save、.meas；没有用普通 AC 冒充 FRA |
| GenericFlybackPWM.lib / *.asy | 独立通用模型和本地符号，不依赖原作者电脑路径 |
| design.json / manifest.json | 计算输入、实际参数、冻结磁件、模型 hash 与假设 |

两端电压不同时，手动运行工程使用 .step param VIN list ...；Select Steps 可切换。自动报告为每个端点单独运行，避免不同 step 的 RAW 混为一组。磁件沿用同一组冻结几何、匝数与 DCR。

## 3. 可独立复用的控制器接口

### GFLY_CTRL2：闭环组合

引脚顺序：FB CS EN VCC GATE COMP RAMP SS FAULT COM。

FB 为隔离并缩放后的反馈；VSET 与 FB 同量纲。SS 为 0..1 的进度监测，FAULT=1 为保护关断。COMP 是带零电流偏置的绝对电压，RAMP 是调制比较量。

主要参数：FSW MODE DMAX VM A_CS SLOPE CS_LIM TBLANK TONMIN TPROP VG RDRV UVLO VSET TSS TYPE KP FZ1 FP1 FZ2 FP2 CMAX TEN SSMODE SSFRAC COFF SSCLO SSCHI SCMODE SCP SCPBLANK OLPEN TOLP THOLD TOFF CS_TAU。时间为秒、频率为 Hz、CS 和 COMP 为 V、SLOPE 为 V/s。CS_TAU 为外部采样滤波 RC 时间常数；MP6005 参考图的 1 kΩ 与 15 pF 给出 15 ns，不把它标作芯片内部规格。

### GPWM_CORE2：接任意补偿器或行为源

引脚顺序：COMP CS EN VCC GATE RAMP ILIM COM。ILIM 为外部给定的原始 CS 限流电压，可接行为源；COMP 可接用户自己的 B/E/G 源或误差放大器。MODE=1 峰值电流模式，MODE=0 电压模式。

每周期时钟置位，达到最大占空比或比较条件后锁存复位。电流模式比较 A_CS×Vcs + SLOPE×t_cycle 与 COMP−COFF；电压模式比较 VM×FSW×t_cycle。原始 Vcs ≥ ILIM 在前沿消隐结束后逐周期关断；正常调制比较还受最小导通时间约束。

### GPROTECT：独立保护状态机

引脚顺序：CS GATE EN VCC RUN SS ILIM FAULT OLPSTATE COM。RUN 控制允许开关，OLPSTATE 为归一化过载计时。持续 OCP 在 SS 完成后计时；SCP 不等待 OLP。SCMODE=1 自动重试，2 锁存，0 不进入故障关断。

### GCOMP 与兼容接口

GCOMP 保留二型与三型零极点补偿、积分状态、输出饱和及抗积分饱和。TYPE=2：KP×(1+s/wz1)/(s×(1+s/wp1))；TYPE=3 再乘 (1+s/wz2)/(1+s/wp2)。频率为 Hz，内部转换到 rad/s。旧 GPWM_CORE / GFLY_CTRL 接口保留。

## 4. 仿真与设计计算对比报告

导出 ASC 工程只导出文件；运行并导出对比报告会实际调用本机 LTspice。桌面版可选择 LTspice.exe；本地网页版使用已保存路径、环境变量 LTSPICE_EXE 或标准路径自动发现。

输出 Word 和同名 ZIP。ZIP 保留各端点与可选短路测试的工程、日志、comparison.json 与 Word。临时大 RAW 不打包，可用相同参数重跑。

报告包含控制器配置、每端点指标对比、连续 64 周期脉宽/峰值检查、启动/保护波形、原边电流、每路副边电流与输出纹波、环路 FRA 及交叉调整率。平均值、RMS、极值来自 .meas；展示用 RAW 重采样不用于判差。

标称判差前必须：日志与 RAW 完整到结束时间，必要测量齐全；相邻窗口输出均值变化不超过 1%（绝对下限 10 mV）、无保护，且连续时钟的脉宽及电流峰值满足逐周期重复性阈值。大小波、跳周期、缺测和失败分别标明，不再仅以平均输出电压收敛判断通过。默认偏差及周期提示阈值为 5%，均可改，属于提示而非硬件验收规范。

Vds 尖峰、整流反压和纹波涉及不同寄生与求解口径，仅并列展示，不机械判优劣。故障工况不对标称工作点判差。预设效率不重复乘进物理瞬态；不提供没有共同口径的效率误差。

## 5. 模型边界

MOS 为受控开关、Ron、常数 Coss 和等效门电容；二极管为固定 Vf 加通用结电容；不是从 Id–Vgs / Vgs–Qg / If–Vf 拼成的完整器件 SPICE 模型。尖峰依赖实际器件和布局寄生，需另行复核。

磁芯线性，不含饱和、磁滞、磁芯损耗；电容 ESR 保留，快速默认不含 ESL，可开启详细选项。反馈选择器为理想隔离信号，未建模光耦/TL431 的物理延时和 CTR。

已接入 LTspice 原生时域 FRA 与 min/max 负载角点，并增加独立的 L6565 逻辑参考单路 QR SSR 模型，见 [QR 说明](QR_L6565_SPICE.md)。尚未实现 MP6005 的 PSR 退磁采样、辅助绕组自供电、完整芯片突发调制、温度离散性和精确器件损耗。普通导出 ZIP 的 ASC 为瞬态入口；FRA 与交叉角点 CIR 在运行对比报告后附入 ZIP。软件会拒绝不支持的拓扑或 PSR。
