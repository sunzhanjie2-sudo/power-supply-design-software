# 隔离多输出与 MP6005 PSR

## 使用方式

启动默认仍为 40W CCM 单路反激。左栏启用 1–6 路多绕组，选择主反馈/PSR 基准 OUT；仅该路电压可编辑，其余路按实际整数副边匝数比估算。逐路填写功率、整流器、电容 A/B、防反和绕组参数。反激 L 是共享励磁电感；独立 L 仅用于正激输出电感。

输出与 MP6005 参数已集中到左栏，右侧①页为拓扑和只读结果；修改参数防抖后重算，不再依赖独立窗口的确定按钮。线径和股数旁显示实际 RMS 电流密度 A/mm²，DCR 由 MLT、匝数、总裸铜面积自动生成。详见 [绕组电参数说明](TRANSFORMER_ELECTRICAL.md)。

SSR 的“主反馈 OUT”指定唯一主反馈；PSR 的同一选择指定辅助绕组分压的标称输出基准，不表示有次级闭环。N 始终指 OUT1 的 Np/Ns。波形、器件、电容页显示所选路，①页输出结果与 Word 报告显示全部输出。总输出功率由各路功率之和决定，左栏单路 Vout/Pout 不覆盖输出表。

“反馈”选择 PSR-MP6005 后，固定频率反激采用 250kHz PWM、PCM 采样增益 11。点击“MP6005 参数”配置 Na（0 自动）、RfbH/L（下电阻 0 自动）、Rreg、Rcomp/Ccomp/Cpole 和 VCC。MOS Vgs 应与 VCC 匹配；内置 VCC 典型 8.5V。MODE 悬空。⑤页自动整定仅写回 PSR 物理 COMP 网络；⑨页原 SSR 阻容正反算不用于 PSR。

内置示例：`examples/6_OUTPUT_FLYBACK_SSR.json`、`examples/MP6005_PSR_FLYBACK.json`。文件菜单“打开配置”可载入，保存 JSON 保留全部输出及 PSR 参数。配置窗口修正版 EXE 位于 `dist/Multi_output_MP6005_UI_fix/SwitchingPowerSupplyDesign_V0/`，保留 `_internal` 文件夹。

## 计算口径

- 原边按总输出功率及预设效率求解；最终效率独立汇总，不覆盖预设。
- 反激/QR 次级按功率权重分流，保持总安匝和逐路标称电荷平衡；不是二极管抢流/交叉调整率仿真。
- 正激采用折算等效 L 汇总原边电流，各路输出电感独立计算；任一路 DCM 明确拒绝，不能在同一 PWM 下按独立稳压计算。
- 共享原边、磁芯、输入电容、采样和钳位只计一次；各路整流、电容、防反与副边铜损累计。辅助采样绕组加入窗口/分压负载铜损，不默认给完整 VCC 供电。
- 非反馈匝比电压不是独立目标，不把派生值再作取整误差通过项；耦合实际电压另列，不承诺稳压精度。每路器件参数在报告保留。
- 角点扫描同比例改变全部输出功率，固定所有绕组/磁芯；不是任意独立负载组合。方案对比检查全部输出的需求是否一致。

## MP6005 的独立边界

基于 [MPS 官方数据手册 Rev.1.1](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP6005GK/)，MP6005 的 PSR 支持 CCM，并非通用 DCM-only 控制器。

核算辅助分压、负向 FB 电流、Rreg+Rs 档位、33mV 最低峰值条件下的 0.7μs 导通建议、当前采样窗口、70% 占空比上限及电流限值裕量。仅固定频率反激支持此 PSR 配置，QR 和正激不套用。

PWM 环路用通用 PCM、内部采样增益 11、真实 gm-COMP 网络、辅助分压和半周期延迟近似。内部斜坡、采样保持、动态压降补偿没有精确 IC 模型，因此 Bode/FRA 仍须厂商模型或样机验证。它是候选补偿估算，不是器件稳定性保证。

轻载采用典型 36mV 固定峰值的 DCM 能量平衡降频估算，最低典型频率 30kHz；低于最小能量负载时提示预负载，拒绝假定空载稳压。PFM 清空旧 PWM 曲线与裕度，不提供 PWM Bode 或一阶负载阶跃。固定 PWM 频率不可作为优化变量，多输出的支路 C/负载参数也不接受左栏单变量扫描。
