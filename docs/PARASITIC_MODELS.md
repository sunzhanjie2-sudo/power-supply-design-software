# 寄生参数、振铃与吸收网络

更新：2026-10-29。入口为左侧“功率级与钳位 → 寄生参数与吸收”。桌面和本地网页版保存相同的 `parasitic_config`（SI）对象；旧工程缺少该对象时保持原有快速计算。

## 计算模式与适用范围

| 模式 / 拓扑 | 实际计算内容 | 仍未包含的内容 |
|---|---|---|
| 快速 | 原工作点、波形及钳位包络；不额外求解局部振铃 | 不能因图形平滑就认为实物没有尖峰 |
| 寄生瞬态 / 反激、单路 QR / SSR | 在已有平均工作点上独立计算 Q1 与各整流管的局部集中参数 RLC 端口；可查看 RC 吸收和理想钳位影响 | 不是完整多绕组同时换流，不重算直流交叉调整率、启动或低频环路；不拟合 LTspice |
| 寄生瞬态 / 有源钳位正激 / SSR | 使用既有两两互感 MNA 周期求解，将用户的 Coss、各管 Cj、绕组端间电容、串联布线 L/R 与 RC 吸收加入同一电路；必须开启非奇异 kij 矩阵 | 常数电容、线性磁件、理想开关边沿；不代表真实控制芯片或已证明 ZVS |

当前集中参数入口只用于反激、准谐振反激和有源钳位正激。Buck/Boost 等不展示该入口，不宣称它们已实现寄生精算。PSR 的逐周期采样逻辑未纳入此次局部模型。

## 参数含义与来源

- **Q1/Q2 Coss**：工作电压附近的常数等效值。填 0 时使用器件参数；QR 旧工程存在 `qr_cds_pf` 时先继承旧有效漏极电容。统一配置后 QR 谷底时间、损耗和导出共用该有效值。它不是 Coss(Vds) 曲线，也不是把 Qg 代入输出电容。
- **各路 Cj**：按 OUT 位号配置整流器件；正激另有续流管。原统一 Cj=20 pF、串联电容阻尼 0.1 Ω 现已显式列出，均为默认模型假设，不能当作实测器件值。
- **MOS 体二极管**：Coss 已包含漏极/体结电容；统一配置的计算与导出不再额外叠加一份默认 Cj。未采用统一配置的历史工程保持原结果，避免静默改变已有验证。
- **绕组端间电容**：每个绕组自身两端的集中等效电容；不是原副边安规隔离电容，也不是完整绕组间电容矩阵。0 表示尚未建模。
  电容折算到外部绕组端口；合并串联布线电感后，不保留电容在绕组内部的实际位置。需要内部节点、共模路径或布局精细模型时，应在 SPICE 中显式拆分，不能把此端口模型当作场求解结果。
- **串联布线 L/R**：折算到相应绕组端口的外部引线/布线串联量。不要把已经包含在所测变压器参数中的漏感再填一次。它不能描述公共源极电感、门极回路和所有 PCB 回流路径。
- **RC 吸收**：R、C 串联后并联在 Q1 或该路整流二极管两端；C=0 表示不装。它与原 RCD 钳位是不同支路。

变压器的自感/两两 kij 仍在磁件区输入。没有矩阵时，反激沿用历史 K，构造统一 kij=√K；多绕组时只是可见的默认近似。局部端口漏感使用其它绕组短路条件下的 Schur 补：Lσ,j=Ljj−LjR·LRR⁻¹·LRj。该短路驱动点量不是任意高频终端条件下的完整模态电感。

## 局部估算方程

以阻断平台为平衡点，v 为相对平台的电压，i 为串联电感电流，u 为 RC 支路电容的相对电压：

    L·di/dt = −v − R·i
    C·dv/dt = i − (v−u)/Rsnub
    Csnub·du/dt = (v−u)/Rsnub

未安装吸收电容时移除 RC 项。钳位触发后固定端口电压，积分剩余电流至释放，再恢复 RLC；不直接叠加人为衰减正弦。

Q1 从原有阻断平台及关断电流起算；整流管采用下一次 MOS 开通前的支路电流和 0 V→理想阻断平台的局部阶跃。观察窗口限于本次开关区间或 8 个 LC 周期。无漏感或无有效电容时不会编造一个振铃频率。f₀=1/(2π√LC) 只作无阻尼局部 LC 参考，不保证等于多端口电路的实际主频。

QR 另列“退磁后首谷底”曲线，使用励磁电感、有效 Coss 与原边端口电容；初始电流为零，电压从 Vin+Vr 向谷底变化。该低阶图不包含多谷底切换、真实 ZCD 延时与全部反射电容，不能据此宣称实际谷底电压或 ZVS 已被验证。

局部估算曲线单独列在功率级页，**不覆盖原有平均电流/电容纹波**。耐压初筛使用原应力与局部峰值中较大者；这仍非严格的实物应力上界。反激局部 RC 衰减不能换算成完整周期的吸收损耗，故不借此伪造效率改善。正激物理周期中新增布线 R、RC 的电阻损耗通过实际支路积分计入 `P_parasitic`，不与磁件几何铜损重复。

## 与 LTspice、报告的关系

导出完整电路使用同一套数值，CIR 与原生 ASC 都包含 `parasitics.inc`。其中列出新增绕组电容及 RC；各管 Cj/串联阻尼由参数文件提供。串联不耦合布线电感通过 Lii′=Lii+Lpcb,i 合并，而 Mij 保持原值，再计算 kij′=Mij/√(Lii′Ljj′)，电气上等效于原绕组串入独立电感；不把变压器本身的 kij 改成另一份实测值。

Word 与 Excel 共用第 2.2 节，包含各器件实际采用值、计算范围及局部曲线；Excel 仍保持 Vinmin/Vinmax 左右对照。正激已有物理周期振铃不会再被叠加第二份局部曲线。统一配置存在时，控制器窗口不再重复编辑旧 Cj/QR Cds 字段。

相同输入参数不表示两种模型的尖峰必然一致：反激计算器是独立端口近似，SPICE 是同时求解全网络；Coss/Cj 非线性、反向恢复、绕组分布电容、门极/公共源寄生和测量带宽均需进一步核对。

## 性能及验证

默认不增加求解。局部 RLC 按电气输入保留最多 16 项缓存，在原有可取消后台队列内运行，不增加常驻轮询；窗口滚动与图表刷新不会重新求解。同一个参数对象用于保存、计算、报表和仿真导出；未收敛抛出错误，不用假曲线补齐。

验证包含独立阻尼 RLC 解析解、能量衰减、钳位事件、RC 阻尼、零漏感、矩阵互感不变、三路输出归属、QR 有效电容时间、ASC/CIR 元件一致性及实际 LTspice 局部基准。局部基准验证的是集中参数方程，不是实物精度认证。

依据：[TI 振铃与 RC 吸收](https://www.ti.com/document-viewer/lit/html/SSZTBC7?keyMatch=SNUBBER)、[ADI 多路反激吸收](https://www.analog.com/en/resources/technical-articles/snubber-circuits-suppress-voltage-transient-spikes.html)。
