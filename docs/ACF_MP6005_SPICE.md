# MP6005 逻辑参考的有源钳位正激仿真

软件支持固定频率、SSR、最多六路输出的有源钳位正激。桌面版从“LTspice 电源闭环”进入；网页版在报告页配置。导出工程可单独复制到装有 LTspice 的电脑运行，不依赖 Python 或 MCP。

## 模型与物理电路

`GenericACF_MP6005.lib` 是原创通用行为模型，以 MP6005 公开控制逻辑为参考，依赖同目录的 `GenericFlybackPWM.lib`。它不是 MPS 原厂芯片模型。

- 主 N-MOS 为 Q1；辅助低侧 P-MOS 为 QA。C_ACTIVE 接在主漏极与辅助漏极之间，辅助源极接原边地。没有理想复位电压源。
- GATE 高电平开主管。SYNC 高电平关辅助管，低电平允许辅助管导通；AUXG 为 AC 电平移位后的负栅压。两个边沿保留死区，周期开始时不会重新插入辅助脉冲。
- 辅助驱动的 AC 电平移位和故障时栅极主动放电是理想化假设；未实现实际耦合电容下垂、栅源电阻放电或驱动钳位网络。
- 每路包括 LS、D_O 整流管、D_F 续流管、LO 输出电感、两颗可并联电容及可选 D_OUT 防反管。LO 当前为线性理想电感，未含其 DCR、饱和与独立磁芯损耗。
- LP 使用 `Lm_forward`，LS 自感按匝比平方确定。`L` 和每路 `outputs[].L` 是输出电感。不能将原反激励磁电感直接复制为 LP。
- 全部两两 kij 进入 SPICE。电感为线性互感矩阵，绕组 DCR 来自已冻结的 MLT、匝数、线径和股数。

## 配置与观察

MP6005 正激参考预设保留频率、COMP 软启动、逐周期 CS 钳位、SCP、OLP 与打嗝的可编辑参数。死区预设 100 ns；也可填写其他值，0 表示沿用左侧正激设计的死区。数据表的 MODE 档位为 100、150、200、300 ns；连续填写值属于通用模型假设。

补偿器采用计算器相同的 KP、零极点和类型；填 0 时沿用软件。SSR 的光耦/TL431 用等效补偿传递函数与理想隔离反馈替代，没有真实 CTR 与反馈延时。

输出和负载在防反管后 `outN`，反馈取防反管前 `capN`。端口目标加主路防反管压降构成反馈目标。非反馈输出不会被理想电压源强制稳压。

打开 `Flyback.asc` 或 `Flyback.cir`。文件名沿用已有导出接口，内部电路为有源钳位正激；manifest 中拓扑为 `ACF-FORWARD`。参数放在 `design_params.inc`；ASC 已直接放置功率器件，不能再包含 `power_stage.inc`。

建议查看：

| 目的 | 信号 |
|---|---|
| 主管和辅助管驱动 | V(gate,sense)、V(sync)、V(auxgate) |
| 主管电压与钳位电容 | V(drain,sense)、V(drain,aclamp) |
| 原边绕组与钳位电流 | I(LP)、I(C_ACTIVE) |
| 副边正向整流电流 | -I(LS1)、-I(LS2)… |
| 输出电感电流 | I(LO1)、I(LO2)… |
| 输出、反馈和保护 | V(out1,sgnd)、V(cap1,sgnd)、V(comp)、V(ss)、V(fault) |

LS 的正端朝向副边整流端，因此 SPICE 的元件电流方向与向负载送电相反。对比报告与默认绘图设置使用负号统一方向。

## 对比报告与有效性

“运行并导出对比报告”实际执行 LTspice，输出 Word 和同名证据 ZIP，包含：

1. Vinmin/Vinmax 下的启动、负载阶跃、周期重复性、原边电流和各路副边电流、输出纹波。
2. 主辅栅极交叠、最小死区、扣除原边 DCR 后的励磁伏秒残差，以及钳位电容电压和电流。
3. 每路输出电感及续流回路对比。
4. 开关闭环原生 FRA，并做相同频点的半幅复核；复核不通过时不发布有效裕度。FRA 期间使能保持有效，不因普通瞬态结束时间提前关闭。
5. 多路 min/max 交叉负载组合及收敛检查。正激对最多三个未收敛角点追加独立、固定负载的长时间启动复核，保持同一硬件和控制器，并保留原扫描曲线及日志；复核仍不通过时保留“未收敛”，不会当作稳态包络。
6. 可选输出短路注入与保护。340 ms 关断期未被完整覆盖时，只能报告已关断，不能宣称已验证自动重启。

启用两两 kij 后，计算器使用独立 MNA 物理周期解：完整互感、几何 DCR、每路输出电感与整流/续流、低侧钳位 C/ESR、恒定 Coss/Cj、有限导通电阻及死区。通过周期边界、各路电荷平衡和单路主反馈求占空比与实际输出电压；预设效率保留为设计参考，不再重复叠加到显式损耗电路。未启用矩阵及全部 kij=1 的奇异理想极限仍明确使用原标称近似。

环路从同一周期解线性化，连接每颗并联 C+ESR，斜坡定义与导出共用。高频电流网格敏感时不发布该点有效裕度；直流交叉包络另按电压网格检查。计算器仍把输出电容端看作周期内恒定直流，再重建纹波，MOS 门极边沿也是理想时序；不能把它当成完整开关器件模型。详见 [周期模型与精度边界](ACF_PERIODIC_MODEL.md)。

整流与续流反压不能替代实物尖峰测量。当前模型不含真实 PSM、频率抖动、OVP、内部 LDO、磁芯饱和、温度和完整反向恢复；不能据此保证 ZVS 或器件选型合格。
