# 自定义／非标准磁芯

在左侧“磁件与温升”的“磁芯型号”中选 **自定义（非标准）**，填写名称（可选）和以下四个计算用有效参数。无需修改标准磁芯库。

| 参数 | 输入单位 | 参与计算 |
| --- | --- | --- |
| 有效截面积 Ae | mm² 或 cm² | 伏秒匝数、磁密、饱和校核与损耗波形 |
| 有效磁芯体积 Ve | mm³ 或 cm³ | NSE 损耗密度换算为磁芯总损耗；独立电感经验散热模型 |
| 可用窗口面积 Wa | mm² 或 cm² | 绕组窗口填充率 |
| 平均每匝长度 MLT | mm 或 cm | 原边、各副边与辅助绕组的几何 DCR、铜损 |

四项均须为有限正数。没有这些有效参数时，不会自动用外形长宽高代替，也不会悄悄回退到标准型号。任意磁芯外形的包络尺寸不能唯一确定有效磁路参数；请按供应商有效参数或已核算的有效几何量填写。

## 使用与切换

- 面积的 cm²=100 mm²，体积的 cm³=1000 mm³，长度的 cm=10 mm。切换下拉单位时自动换算已有有效数值，不改变磁芯实际大小。
- 自定义 MLT 优先使用，不会被标准磁芯数据库或旧的全局 MLT 覆盖。旧 MLT 草稿保留，切回标准芯后恢复。正激仍有标准输出电感需要全局 MLT 时，其输入保持可见。
- 材料以及 k、α、β、Bmax、Bsat、Ku、导线电阻率、变压器热阻均保留原有设置；自定义几何不意味着软件知道新材料的损耗系数。
- 标准型号、自动选芯规则与原计算公式保持不变。
- 可绕制评估的骨架窗口宽、高仍独立设置；不会从 Wa 猜测窗口长宽、绝缘空间或绕制工艺。

## 正激与多路输出

变压器使用主“磁芯型号”下的尺寸。单输出正激的独立输出电感有自己的磁芯选择和尺寸；启用多路正激后，在左栏各 OUT 的“正激输出电感磁芯”处分别选择和填写。

反激、QR 的多个副边共用一个变压器，不显示正激输出电感尺寸。切换拓扑保留隐藏草稿，但不让它们参与当前拓扑的计算。

## 保存、工况和报告

自定义尺寸随设计 JSON 保存。内部数值一律 SI，另存显示单位，重新打开恢复原显示。Vinmin/Vinmax、固定硬件角点与耦合绕组预计算使用同一份磁芯几何快照，不根据工况自动改尺寸。

Word 和 Excel 共用报告内容：磁件模块记录名称、尺寸来源、实际 Ae、Ve、Wa、MLT；多路正激逐路列出各输出电感的尺寸。CLI / JSON 结果也保留 core_label、core_geometry、Ae、Ve、Wa、MLT、MLT_source。

配置示例（数值为格式示例，不是实际器件选型建议）：

```json
{
  "core_choice": "自定义（非标准）",
  "custom_core": {
    "name": "试制磁芯 A",
    "Ae": 0.000062,
    "Ve": 0.0000028148,
    "Wa": 0.000030,
    "MLT": 0.044,
    "display_units": {"Ae": "mm²", "Ve": "cm³", "Wa": "mm²", "MLT": "mm"}
  }
}
```

也接受单项显式单位对象，例如 `"Ae":{"v":62,"u":"mm²"}`。标准 JSON 其余字段保持原格式。正激独立电感用 `core_choice_L` / `custom_core_L`；多路时放在对应 `outputs` 条目内。

## 回归验证

运行 `python tests/custom_core_check.py`，覆盖单位换算、无效输入、与同尺寸标准芯的数值等价、尺寸敏感性、DCR、耦合硬件、固定双端点、逐路正激、报告来源，以及透明自有 Tk 窗口的选择／保存／恢复。测试不控制其他应用。
