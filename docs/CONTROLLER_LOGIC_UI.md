# 控制器逻辑框图与参数说明

2026-10-27。桌面“通用反激控制器配置与仿真对比”窗口右侧新增可滚动逻辑框图，本机网页版“报告与检查”采用同一份模块及参数说明。适用于现有固定频率反激SSR通用SPICE模型。

## 使用

左侧选中输入框/选项，或点击右侧模块，查看该量的用途、当前暂存值、单位和适用条件。修改数字、填入MP6005参考配置或恢复默认后，框图中的代表值同步更新；未完成数字输入时显示“编辑中”，不执行求解。切换页签高亮相应模块；桌面可拖动中间分隔条，左右分别滚动。小窗口图形随右侧视口缩放，仍可纵向浏览。

说明区会提示当前模式没有使用的参数，例如非打嗝模式的重试等待时间、非COMP缓升模式的起终点、未选手动模式的手动斜坡。0的含义逐项说明：频率跟随设计、补偿零极点沿用软件、Vcs/COMP上限由导出器确定，并非全部都表示禁用。

框图只解释暂存设置，沿用原有导出和保存流程，不把半输入值写入工程，不启动后台仿真。测试时长、负载阶跃、短路注入、FRA/交叉调整率、线程和报告阈值放在外部试验模块；电容ESL和二极管Cj放在外部功率级模块。

## 与芯片、模型的关系

主链路：反馈/等效补偿 → COMP命令；采样端 → 可选RC滤波/消隐 → PWM比较；时钟置位、比较器/限流/占空比等条件复位锁存，再经延时与驱动到GATE。EN/VCC、SS、SCP/OLP及故障状态约束允许输出。箭头表示主要信号流，不是晶体管级实现。

特别区分原始CS电压量纲与放大后比较量：逐周期Vcs阈值和SCP阈值使用采样端电压量纲；正常峰值电流PWM比较使用放大后的采样加斜坡与COMP减偏置。模型中的CS滤波也作用于保护输入，消隐与传播延时会影响实际峰值。最小导通时间并不阻止所有保护路径。

根据[MPS MP6005官方资料](https://www.monolithicpower.com/en/mp6005.html)Rev1.1，SSR的内部误差放大器关闭，由外部反馈作用于COMP。因此KP/fz/fp与理想隔离反馈被放在“外部反馈与等效补偿”区域，不画成MP6005内部正在工作的误差放大器。框图依据当前`resources/spice/GenericFlybackPWM.lib`重新组织，是通用行为模型说明，不是复制的数据手册框图或完整MP6005硅模型。

## 维护与验证

`controller_logic.py`维护所有SPICE设置的模块归属、解释、条件和图形结构；`spice_logic_ui.py`用原生Tk Canvas绘制；网页`ControllerLogic.vue`消费同一份元数据。显示过程不导入求解器、不开图像生成进程，不增加计算公式。重绘合并为单次80ms任务，关闭窗口清理所属任务。

`tests/controller_logic_check.py`检查设置覆盖、内外模块边界、严格JSON及自动/未启用状态；`tests/spice_ui_check.py`核对焦点/值联动、小窗口图形范围和异步ASC导出；`tests/spice_export_check.py`验证原有控制设置及仿真文件导出。网页经TypeScript/Vite构建及本机浏览器检查。另修复网页预设按钮对Vue响应式对象调用structuredClone导致无法应用配置的问题。

便携程序位于`releases/Windows-x64/20261027-controller-logic/`，保留历史发布目录。应复制完整程序目录，不能只取EXE。
