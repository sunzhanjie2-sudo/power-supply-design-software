# QR 采样增益与标准二型补偿修正

当前可见的 L6565 QR 示例采用 A_sense=1，输入300V、输出60V/92W。总漏极有效谐振电容在计算与SPICE中均为470pF（常量近似），不再出现计算Coss=0、仿真470pF的工作点差异。主界面输入的100kHz仍是频率上限，工作频率由QR周期求得。

## 问题原因

截图中自动整定在fc=1kHz、PM=60°时得到fz1约296Hz、fp1约3.38kHz，顺序正确。旧补偿页仍把二型未使用的fz2=10kHz、fp2=500kHz代入三型参考网络，误报快车道极点低于零点，并尝试以500kHz光耦极点反推负电容。普通运放和gm网络虽然可返回数值，也会多实现一组不属于二型的零极点。

## 修正后的统一规则

标准二型只使用 KP、fz1、fp1，传递函数为 `KP*(1+s/wz1)/(s*(1+s/wp1))`。原点极点和有限高频极点都保留。fz2/fp2可以保存在旧配置中，但不参与二型的计算、阻容反推、核验或环路。

| 参考网络 | 标准二型处理 |
| --- | --- |
| 普通运放 | 保留反馈R2/C1及并联C2，省略输入R3/C3支路 |
| gm | 保留输出R3/C2和并联C3，省略上分压并联C1；R1未指定时按2.5V基准计算并提示 |
| TL431无快车道 | 保留R2/C1反馈，省略上分压R3/C3支路；光耦总电容实现fp1 |
| TL431快车道 | 保留直接反馈C1，由Vout至LED形成fz1；省略第二反馈R_pz/C_pz支路；光耦总电容实现fp1 |

四种理想网络均通过独立阻抗式与目标复数传递函数核验。阻容反算后可识别实际二型，写回二型容器，无需用1GHz零极点假装抵消。桌面、网页和报告共用 `compensation_snapshot`，不再维护两套正向求解。

旧版“C2/C3不装”等简化仍可显式选择，现明确标注“不含高频极点”；它不能等同于标准二型。执行标准二型自动整定时取消该旧简化选项。

光耦寄生电容、Rpullup不允许被忽略：当 `1/(2*pi*fp1*Rpullup)-Copto` 为负，仍标记真实不可实现。旧字段不再制造错误，但物理限制继续检查。

## 环路模型和边界

QR仍使用变频BCM周期电荷模型，不套用固定频率PWM。对峰值电流、电容端电压的导数经独立差分核验；每颗并联电容保留自己的ESR。A_sense只影响电流采样增益，不改变由功率级求出的设计工作点。

当前Gvc输入为放大后CS等效控制指令，通用SPICE与之对应。此处阻容实现该理想Gc，不能直接认定为真实L6565 COMP管脚的完整参数；实际COMP前馈缩放、电平转换、误差放大器/光耦动态需另外纳入。尚未包含跳谷、突发模式、采样延迟与非线性寄生的完整小信号模型，不能以高频理想曲线证明实物稳定。

旧增益11的隐藏仿真补偿覆盖文件和历史FRA数据继续保留为回归资料，未改写成增益1的新证据。新实际验证在 `artifacts/qa/qr_type2_20261029/`，复核说明在 `output/QR_采样与二型复核_20261029/`。

新配置实际瞬态：输出约59.9985V，开关频率约41.6kHz，直流与逐周期检查通过。实际FRA穿越频率1004.94Hz、相位裕度57.43°；同频点计算约1000.23Hz、59.68°。半幅关键频点差异最大约0.083dB、1.03°，通过核查。此处数据属于本次新运行，不是修改历史测量。

依据：[ST L6565数据手册](https://www.st.com/resource/en/datasheet/l6565.pdf)、[TI SLVA662](https://www.ti.com/lit/pdf/slva662)、[onsemi TND381](https://www.onsemi.com/pub/collateral/tnd381-d.pdf)。TL431推导采用理想虚地及设定CTR/Copto，不等同于完整器件模型。
