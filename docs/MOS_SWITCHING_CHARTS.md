# 拓扑首页与 MOS 分段波形

界面顺序为①拓扑、②功率级、③器件、④磁件、⑤环路、⑥效率、⑦电容、⑧钳位、⑨补偿、⑩工程评审。

## 功率级图形顺序

按行从左至右：Q1 MOS 电流、D1 二极管电流、输出纹波、输出电压、Q1 开通 Vgs/Vds、Q1 关断 Vgs/Vds。原电流计算未删除，原边 / 电感电流和电容电流仍用于磁件、电容与报告计算；本次替换的是功率级展示面板。

开通与关断图默认按阶段等宽展开，让短分段也可辨识，明确标为“非等时长”；每段显示计算时长。可切换真实 ns 时间轴。Vgs 为相对源极的电压，不是高侧 MOS 栅极对地电压。

| 分段 | 电压过程 | 时长来源 |
|---|---|---|
| t1 | Vgs: 0 → Vth；Vds 保持阻断 | 损耗模型 / xlsx LN 公式 |
| t2 | Vgs: Vth → 开通平台；Vds 近似不变 | 同上 |
| t3 | Vgs 开通米勒平台；Vds 下降 | 损耗模型 / Qgd |
| t4* | 平台后续充，Vgs 接近驱动电压 | 补充 3RC 估算 |
| t5* | Vgs 从驱动电压降至关断平台 | 补充 RC 放电估算 |
| t6 | Vgs 关断米勒平台；Vds 上升 | 损耗模型 / Qgd |
| t7 | Vgs 降至 Vth；Vds 保持阻断 | 损耗模型 / xlsx LN 公式 |
| t8 | Vgs 在阈值以下继续放电 | 损耗模型 / 3RC |

六个已有时长直接取 `res['semi']['switch']`，不在 UI 重算。交叠损耗仍只用 t2+t3、t6+t7。

令 Qpost=Qg−Qgs−Qgd，Ron/Roff 均含驱动、外部与 MOS 内部栅阻。用于绘图的补充估算为：

- t4*=3·Ron·Qpost/(Vdrv−Vgp_on)。终点仍有平台至驱动电压差值的约 5%，不是严格充到 Vdrv。
- t5*=Roff·Qpost/(Vdrv−Vgp_off)·ln(Vdrv/Vgp_off)。关断上平台电容为独立近似。
- Qpost≤0 或平台不满足驱动电压条件时，不伪造时长；t4/t5 标为未知，真实时间模式回退到明确标记的阶段示意。Vgp_off≥Vdrv 时不绘制虚假的关断曲线。

这些时长依赖把不同工作点下的栅电荷合成常量电容，是补充工程估计，不是新增精确器件模型。Vgs 采用端点约束的 RC 形状，米勒区 Vds 线性变化；Vds 阻断幅值取损耗模型的保守 V_sw_max，未把尖峰振铃单独求解。Vds 导通值取边沿电流与 Rds_on 的乘积。

QR 与有源钳位仍按现有损耗假设计账：显示的栅电荷参考图不意味着已仿真实际谷底或 ZVS 谐振换流，也不自动减免损耗。

## Word 报告与页面同步

`power_charts.py` 同时供 GUI 和 `report_docx.py` 使用，四张稳态图和两张 MOS 分段图的采样、曲线、标签、单位与时间来源一致。GUI 的 2×3 面板在 Word 中拆为前四图（2×2）和末两图（1×2），保证打印文字可读；不再导出旧的原边 / 电容电流展示板。原电流仍用于磁件与电容的计算。

导出时读取页面“真实时间轴”选项；直接调用 `export_design_docx(..., mos_real_time=True)` 可使用相同 ns 时间轴。默认仍为阶段展开，缺少 t4/t5 时长时不伪造数据。t1–t8 逐项列在报告第 2.1 节，t4/t5 标为补充估算，模型说明与图同步。

## 拓扑与器件位号

`topology_diagram.py` 共用器件注册表绘制图与参数表，保证出现的位号可对应到软件参数。支持 Q1、T1/L1、D1、并联输入/输出电容、采样电阻、防反二极管；正激另有 Q2、C_CL1、D2；反激启用 RCD 时显示 D_SN1、R_SN1、C_SN1。

有源钳位参考图对应已有低侧复位模型，采用接地源极 P 沟道 Q2，其体二极管方向向下。负栅压驱动、时序与寄生换流必须另行设计验证；示意图不等于可投板的完整原理图。器件位号仅作本软件参考标识，不是用户 PCB 位号。
