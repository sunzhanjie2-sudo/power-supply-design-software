# Buck、Boost 与 Buck-Boost 的成品电感选型

Buck、Boost、反相 Buck-Boost 可以使用一体成型或其他外购成品电感，不必先设计磁芯。桌面左侧“磁件与温升”和本地 Python 网页的磁件输入中，取消“启用电感磁芯与绕组设计”即可。感值 **L 始终保留在功率级输入**，仍参与占空比、CCM/DCM、纹波、电流及环路计算。

## 两种工作方式

| 方式 | 输入与结果 |
| --- | --- |
| 启用设计，旧工程的默认方式 | 保留磁芯选择、自定义尺寸、k/α/β、匝数、线径、MLT、几何 DCR、磁损和原温升模型 |
| 取消设计，使用成品电感 | 隐藏磁芯与绕组设计参数；填写成品 DCR，选填厂家 RMS 额定电流、饱和电流 Isat、当前工况附加损耗 |

厂家、型号、封装仍在“关键器件 BOM 与降额”中管理 L1。感值和选型参数在主输入侧管理，避免从虚构的磁芯尺寸推导厂家器件。

## 参数与损耗

新字段在 JSON 中使用 SI 单位，亦兼容原有 `{v,u}` 数量级格式：

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `inductor_design_enabled` | 是否设计磁芯与绕组，仅作用于这三种非隔离拓扑 | `true` |
| `L` | 必填正电感量，H | 沿用原工程 |
| `inductor_dcr` | 成品 DCR，Ω | 0，未提供，暂不计铜损 |
| `inductor_rated_current` | 厂家额定 RMS 电流，A | 0，未提供 |
| `inductor_saturation_current` | 厂家定义的 Isat，A | 0，未提供 |
| `inductor_extra_loss` | 当前工况的磁芯及交流等附加损耗估算，W | 0，未提供 |

直流铜损 `Pdc = Irms² × DCR`；已计入电感损耗 `PL = Pdc + Pextra`。例如 Irms=2 A、DCR=35 mΩ、Pextra=0.12 W，得到 PL=0.26 W。Pextra 不能再包含已计入的直流铜损，避免重复统计；它是用户估值，在不同输入端点与效率扫描中按同一输入值使用，不自动按频率、电流或温度缩放。

DCR 或附加损耗为 0 时，报告明确注明相应损耗未覆盖，效率可能偏高；这不表示真实器件没有损耗。成品模式不生成磁芯尺寸、匝数、气隙、磁通密度或温升，未计算结果使用空值而非零或“通过”。

额定电流与实际 Irms 比较，Isat 与实际峰值比较。未填额定值时标记未计算，超出时提示复核。该初筛不建模 L(I)/L(T)，也不能替代厂家的温升、频率和环境温度降额曲线。

## 电路与报告一致性

Vinmin 与 Vinmax 使用同一 L、DCR 和额定值，只更新运行电流及直流铜损。Word/Excel 的磁件模块改为成品电感参数、实际电流和损耗表；磁密/绕制/温升不再给出虚构计算，Excel 继续按两端输入左右比较。

启用 TPS40200/LTC3864/LM5022 参考控制器的 Buck/Boost 物理周期模型时，成品 DCR 同时进入周期工作点、环路和 LTspice 导出；此时主界面成品 DCR 优先于控制器窗口的旧自制电感 DCR 覆盖。其他经典拓扑模型维持原有工作点/环路近似，DCR 在损耗阶段计入，没有在本功能中另行改变其公式。

SPICE 仍使用线性 L 和 DCR；用户 Pextra 只用于设计损耗账本，没有对应经过验证的磁芯损耗 SPICE 模型。生成工程的说明和元数据保留这一边界。本次没有新增 Buck-Boost 的闭环仿真支持。

新开关对反激、QR 反激及有源钳位正激不生效，这些拓扑仍保留原磁件设计。旧 JSON 缺少新字段时默认启用设计；从成品模式打开旧工程也不会继承上一个工程的停用状态。切换模式保留原磁芯输入草稿。

## 实现与验证入口

共享输入与选型损耗入口为 `inductor_selection.py`、`magnetics.py`、`loss_model.py`；电气求解复用现有 `power_stage.py`、`nonisolated.py`，无 UI/报告独立公式。检查使用 `design_checks.py`；报告沿用共享快照与 Word 到 Excel 内容捕获路径。

针对性检查为 `tests/purchased_inductor_check.py` 和 `tests/purchased_inductor_ui_check.py`。本次覆盖个人桌面与本地 Python 网页/API；独立 TypeScript 浏览器内核和公司部署未同步此功能。
