## 资源与关闭检查

数值任务单进程串行、原生数值线程保留既有受控默认；当前仅保留一个完整数值快照，作业记录最多 4 个、输入队列最多 32 个。前端图像卸载时释放 Blob URL、终止旧 HTTP 请求，过期计算不回写。图表在附近才请求，生成的报告按当前计算与格式复用，临时文件完成后原子替换，避免并发下载读取正在重写的 ZIP。

关闭时由父进程统一取消/回收工作进程，并对未消费的任务队列使用 `cancel_join_thread()`。另外用真实短进程测试未消费的 1 MiB 输入再关闭，进程正常退出。上述是资源控制和响应机制，不是对总内存、耗时或物理计算精度的保证。
