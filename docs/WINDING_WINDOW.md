# 变压器可绕制评估与后台计算说明

磁件页可导出每段和每匝每束的 SI 坐标、原工程、等比例截面和来源清单。骨架轨迹、端子与同名端可另行补充，详见[三维建模数据交付](TRANSFORMER_GEOMETRY_EXPORT.md)。

本功能用于检查一个指定的分层绕制方案能否放进骨架净绕线窗口，并给出等比例截面、层数与高度余量。它使用当前电气和磁件计算得到的实际匝数、裸铜直径与并绕股数，不自动优化绕法，也不代替试绕、工艺确认或绝缘安规评审。

## 入口与建议操作顺序

在右侧 **④磁件 → 变压器可绕制评估** 打开。该子页仅对反激、QR 反激和有源钳位正激显示；非隔离拓扑不显示。

1. 先在左栏设置磁芯、原边及各路副边绕组，并完成一次有效的电气与磁件计算。`0=自动` 输入先由磁件计算解析成实际值，再送入绕制评估。
2. 根据所选骨架的尺寸图，输入单侧净窗口宽度和高度，界面长度单位均为 mm。
3. 按实际线材、绝缘材料和工艺填写留边、含漆外径增量、层间绝缘、绕组间绝缘与间隙。
4. 检查实际匝数、单根股数、线圈并绕根数和裸径。逐绕组选择线材类型、每根线内分束数、整束外径、压扁倍数、疏绕 / 密绕靠左 / 密绕靠右及每层匝数；用“所选绕组上移 / 下移”调整径向顺序。
5. 若需要同一绕组分布在第 1、3 等不连续层，启用“手动物理层序”，从自动排层生成草案后拆层、移动或编辑各层；确认每个绕组的匝数分配完整。普通连续绕制可保持自动模式。
6. 查看“可放下 / 超出窗口”、所需总高、高度余量和截面图。输入会在短暂合并后局部重画，也可点击“重新评估 / 重画”。
7. 在截面中点选某一匝的线束，左右拖动或按 ← / → 微调轴向中心，步长可设（默认 0.01 mm）；Shift×10、Alt÷10，Ctrl+Z 撤销。首次移动固定当前物理层 ID。“一键均匀排布”保留交错层序并重新均布，之后仍可调整。松手时保存位置、检查重叠/净隙与留边，冲突标红；不限制成自动均布形式。

如果电气参数已经修改但新计算尚未完成，页面会注明当前截面仅对应上一有效计算。应等待新结果后再作判断，不要将旧截面当作新参数的结论。

## 净窗口宽高与磁芯 Wa 的区别

这里的宽 W 是骨架单侧净绕线区域的轴向长度，高 H 是同一截面的可用径向高度。应使用扣除骨架实体后的绕线空腔尺寸，不能输入磁芯的外廓尺寸。

磁芯目录中的 Wa 是面积，W 和 H 是有方向的几何尺寸，两者不能互相替代。即使两个骨架的窗口面积相同，窄而高与宽而矮的窗口也可能得到不同的排匝数、层数和是否超限结果。软件不会从 Wa 猜测 W/H。

窗口宽高未填写或任一为 0 时，功能保持“未配置”，不输出可绕制结论。扣除两侧留边后的有效宽高必须为正数。

## 输入与默认值

默认工艺值只是可编辑的计算初值，不是线材等级、耐压、爬电距离或量产工艺的推荐值。

| 界面项目 | 默认值 | 含义 |
|---|---:|---|
| 窗口净宽 / 窗口净高 | 未填写 | 用户按实际骨架填写 |
| 左右留边 | 每侧 0.25 mm | 从 W 两侧各扣除一次 |
| 上下留边 | 每侧 0.10 mm | 从 H 两侧各扣除一次 |
| 含漆外径增量 Δd | 0.03 mm | 加在裸铜**直径**上，不是每侧漆膜厚度 |
| 同绕组相邻层绝缘 | 0.05 mm | 相邻物理层属于同一电气绕组时的厚度，例如 P–P |
| 不同绕组相邻层绝缘 | 0.15 mm | 相邻物理层属于不同电气绕组时的厚度，例如 P–OUT1 或 OUT1–OUT2 |
| 束 / 匝间隙 | 0 mm | 同匝相邻束及同层相邻完整匝组的最小间隙 g，不用于束内逐根排丝 |
| 单股含漆外径 | 0=自动 | 自动时为裸径加 Δd；非 0 时采用指定的单股外径 |
| 线材类型 | 自动 | 每束多股时自动视作利兹线；每束单股时始终为不压扁铜线 |
| 线圈并绕根数 b | 1 | 在左侧电气参数中配置，相同完整线并联绕制；增加总铜面积与截面数量 |
| 每根线内分束数 | 1 | 旧 parallel_bundles，须整除单根线股数；只重新分组，不增加铜 |
| 束内填充系数 k | 0.75 | 等效外径的可编辑估算，不是材料通用常数 |
| 整束原外径 D | 0=估算 | 未压扁的整束含绝缘外径；有实测值时优先采用 |
| 利兹线压扁倍数 a | 1.5 | 宽乘 a、高除 a，保持等效包络截面积；普通铜线固定 a=1 |
| 绕法 | 疏绕 | 疏绕按完整匝组均布，或选择密绕靠左 / 靠右 |
| 每层匝数 | 0=最大容量 | 手动值为不超过窗口容量的正整数 |
| 手动物理层序 | 关闭 | 开启后按物理层逐层分配绕组和匝数，可交错排布，最多 1000 层 |

单股含漆外径不能小于裸铜直径。实测整束外径不能小于束内全部含漆单线面积对应的等效圆直径 `do·sqrt(nb)`；压扁后束高 `D/a` 若小于单股含漆线径 `do`，软件拒绝该配置。这些只是必要下界，并不充分保证实际圆线堆积、绞合或压制可行。填充系数范围为 0<k≤1，压扁倍数不小于 1。匝数和总股数使用磁件结果中的正整数；每束单股时，即使手动选择利兹线，也保持圆形不压扁。

原边标记为 P，功率输出绕组为 OUT1–OUT6；存在有效 MP6005 辅助绕组时另列 AUX。没有有效变压器结果时，只提示先完成计算，不用占位值绘出虚假绕组。

## 多股等效与利兹线压扁

每匝总铜股数 `n=b×nstrand`，每匝总绘制束数 `B=b×parallel_bundles`，每束股数 `nb=n/B=nstrand/parallel_bundles`。旧 parallel_bundles 仅在一根完整线内重新分组，不增加铜；新的 b 才表示增加相同完整线。例如 b=2、单根 40 股、每根不分束，6 匝画 12 个利兹线截面，匝比仍按 6 匝。b=1 时，**3 束×20 股**对应总股数 **60**。每束只画一个等效轮廓，不绘制内部铜丝。

设单股含漆外径为 do，束内填充系数为 k，则多股束未压扁等效外径为：

```text
每束股数 nb = n / B
估算整束外径 D = do · sqrt(nb / k)    nb>1 时
单股外径 D = do                      nb=1 时
```

默认 k=0.75 只是明确可编辑的几何假设，没有针对某种线材校准。优先输入实测整束原外径；填写后不再按 k 推算。外径是压扁前整束含绝缘外形，不是单股裸径或压扁后宽度。

自动线材类型把每束多股视为利兹线，每束一股视为普通铜线。如果实际是多股但非利兹线、且不希望压扁，应手动选择不压扁的普通圆线束。利兹线采用可配置的等面积近似：

```text
单束宽 bw = a · D
单束高 bh = D / a
椭圆包络面积 = π·bw·bh/4 = π·D²/4
```

默认 a=1.5，即宽增至 1.5 倍，高降为原直径的 1/1.5。普通铜线强制 a=1；单股铜线不压扁。保持的是等效包络截面积，不表示软件完成了线材压制或真实形变分析，也不改变电气铜截面积、DCR 或铜损。应按实测线材形状和试绕结果校核这一估算。

## 自动分层与疏密绕排布

每匝的 B 束相邻放置，作为完整组排入同一层，不把同匝中的束拆散或跨层。设每侧左右留边为 mx、每侧上下留边为 my、该绕组匝数为 N、层间绝缘为 tl：

```text
有效宽 Wu = W − 2·mx
有效高 Hu = H − 2·my
每匝总宽 wt = B·bw + (B−1)·g
每层最大容量 qmax = floor((Wu + g) / (wt + g))
每层采用匝数 q = 手动匝数，或 qmax（手动值为 0）
层数 l = ceil(N / q)
该绕组叠厚 hj = l·bh + (l−1)·tl
```

`floor` 向下取整，`ceil` 向上取整。每层手动匝数不能超过 qmax；可用较小值实现跨多层的疏绕。如果 qmax=0，表示一匝完整束组已经超宽，直接判超限，不以 N/0 继续计算。图上仍画一匝一层的超宽示意帮助定位，但不是可实施绕法。

每一层实际排 s 匝，末层可少于 q；该层的占宽为 `wocc=s·wt+(s−1)·g`。

- **疏绕**：s>1 时将完整匝组均匀分布到有效窗口左右两端，组起点间距为 `(Wu−wt)/(s−1)`；s=1 时整组居中。同一匝内的多束仍按最小间隙 g 相邻。
- **密绕靠左**：第一匝从左留边开始，以 `wt+g` 为组起点间距排列。
- **密绕靠右**：第一匝从 `mx+Wu−wocc` 开始，以 `wt+g` 为间距排列，末层同样靠右。

密绕方向影响横向位置，不自动改变层数或叠高。若每层采用最大容量，疏绕与密绕的外观可能很接近；减小每层匝数可得到更明显的稀疏层，但层数和叠高会增加。

自动模式按界面顺序连续叠放每个完整绕组，相邻绕组之间加入一次绕组间绝缘 tw。仅对这种不穿插的连续分组方案，若有 nw 个绕组：

```text
所需总高 Hreq = 2·my + sum(hj) + (nw−1)·tw
高度余量 ΔH = H − Hreq
```

每个绕组均满足 qmax≥1，且 ΔH≥0，才判定这个指定层绕方案“可放下”。顺序调整会改变截面位置；在自动模式的统一绝缘厚度、完整绕组连续叠放假设下，单纯交换完整绕组的顺序不应被理解为自动改善总叠厚。手动物理层序不能套用 `(nw−1)·tw` 简化，须按下述每个真实相邻界面计算。

## 手动物理层序：同一绕组在不同层穿插

电气绕组和物理层是两种概念。原边 P 共 6 匝，可以是第 1 层 P 3 匝、第 2 层 OUT1 2 匝、第 3 层 P 3 匝；P 仍是一个总计 6 匝的电气绕组，不是两个新增原边，也不会重复增加铜面积。层号按骨架向外从 1 连续编号，软件按这份层序绘制同源截面。

启用“手动物理层序”后，可以从自动排层重建草案，并新增、删除、拆层或上下移动物理层；逐层选择绕组、填写本层匝数及疏绕 / 密绕方向。每层缺省绕法继承所属绕组的默认设置。此功能配置的是径向层序；同一匝内的并绕束仍保持完整组，不拆成不同层。

手动层序须同时满足：

- 当前全部有效绕组都要出现，包括存在时的 AUX；不能引用未启用的 OUT 或不存在的绕组。
- 各层匝数为正整数，每层不超过对应绕组的窗口容量，也不能超过该绕组非零的“每层匝数”设置。
- 分配给同一绕组的各层匝数之和，必须精确等于磁件结果中的实际总匝数；不足或超配均报错，不静默补匝或截断。
- 最多 1000 个手动物理层，避免无界的表格、绘图和文档开销。

设第 ℓ 层下沿为 yℓ、线束高度为 hℓ、前置绝缘厚度为 tℓ。首层前置绝缘为 0；从第 2 层起，相邻两层属于同一电气绕组时用层间绝缘 tl，否则用绕组间绝缘 tw。

逐层表中“前置绝缘类型”和“厚度 / mm”显示当前评估实际采用的值，窗口设置下方同时列出同绕组、不同绕组界面的数量。修改绕组分配、移动层序或修改绝缘数值后，会按新评估刷新。输入尚未通过评估时显示“待评估”。

例如层序为 P → OUT1 → OUT2 → OUT1 → P → P，同绕组绝缘为 0.30 mm、不同绕组绝缘为 0.02 mm。第 2–5 层的前置绝缘均为 0.02 mm，第 6 层为 0.30 mm。把同绕组值增至 0.40 mm，只会使第 6 层向外移动 0.10 mm；若要扩大 P–OUT1 等界面，则调整不同绕组值。两个输入填成相同厚度时，全部五个相邻层界面采用该厚度。

```text
每个绕组总匝数 Nj = sum(分配给该绕组的本层匝数)
首层下沿 y1 = my
其后下沿 yℓ = y(ℓ−1) + h(ℓ−1) + tℓ
所需总高 Hreq = 2·my + sum(每层线束高 hℓ) + sum(前置绝缘 tℓ)
高度余量 ΔH = H − Hreq
```

例如 **P–OUT1–P 有两处异绕组界面**，应计两次 tw；不能因为 P 已出现过，就漏掉回到 P 的绝缘。连续的 P–P 用一次 tl。实际几何层数直接来自层序行数，不再按某个固定 q 反推。用户改变穿插顺序，可能改变绝缘界面数和总叠高。

汇总表的“本绕组占厚”只加该绕组自身线层高，以及物理相邻同绕组层之间的 tl；“首末层跨高”从首次出现的下沿到最后一次出现的上沿，包含中间穿插的其它线层。二者不是同一指标，不能把各绕组跨高相加得到总叠高；总高必须按全局物理层计算。

关闭手动模式时，当前界面保留草案供切回，但有效配置 `layer_plan=[]`，保存 JSON 不把停用草案当作当前方案。要把草案保存到文件，先重新启用手动模式并通过检查。变更输出路数、匝数或线束宽度后，旧层序可能不再满足约束，应重新编辑或按自动方案重建，不能沿用旧结论。

交错功能不生成分段引线、跨线或电气连接图；同一绕组各段的串联方向、引出空间和绝缘工艺须人工确认。它不自动改善漏感、不回写 kij / DCR，也不保证磁耦合、铜损或量产可行性。

### 旧矩形束配置兼容

旧 JSON 某绕组仅保存非零 `strand_columns`、没有新线束字段时，保留旧矩形束宽高，避免悄悄更改旧设计结论；图例和报告标为“旧矩形束”。旧方案只画每匝矩形轮廓，也不逐根绘制细铜丝。`strand_columns=0` 或没有该字段时使用新等效束模型。

非零旧列数不能与新线束设置混用。要切换新模型，先清除旧列数，再填写线材类型、束数等新字段；该切换属于几何方案变化，不应把新旧余量视为同一算法。

## 读图与结果判读

截面的横纵坐标均为 mm，采用相同尺寸比例。每个圆或椭圆为一束等效外轮廓，不将内部当成实心裸铜；层间绝缘以色带示意。灰色边框是窗口边界，虚线表示留边后区域。左右挡墙和底座仅在净窗口外示意，不占输入的 W/H，也不代表实际骨架壁厚。各电气绕组使用独立颜色，同一绕组穿插到不同物理层时保持同色；可读范围内在每层右侧标注全局物理层号与绕组编号。

超宽或超高部分会保留显示并用红色虚线标识，不把它裁掉来制造“刚好放下”的视觉效果。高度余量为负时，应增加窗口、减小束厚或修改实际绕制方案；不能只看面积占比。

裸铜面积占比采用所有绕组的 `匝数 × 股数 × 单线裸铜截面积` 之和除以 W·H。它不包括漆层和绝缘，也不是可绕制的充分条件：面积占比低的粗线束仍可能超宽，或者分层后超高。

当全部绕组的等效束截面总数 `sum(N×B)` 超过 **12000**，或总物理层数超过 **256** 时，图上不再逐束画椭圆，以限制绘图开销。手动模式仍按实际物理层画带状顺序，自动模式显示各绕组整体包络；大量手动层采用批量图形集合发布，不逐层创建大量独立控件。阈值不再是微细铜丝总数 `sum(N×n)`；例如一束包含 1000 股，仍只画一个截面。匝数、电气总股数、排层、叠厚和超限判断始终完整计算，不因显示简化而漏算。

## 配置保存与报告

手调轴向中心存入 `winding_config.turn_positions`，例如 `{"P_A":{"2:1":0.0032}}` 表示 P_A 物理段内第 2 匝、第 1 束中心 X=3.2 mm；Y 由物理层决定。稳定段 ID 在移动或插入其它层后保留。改变匝数/分束后失效的位置会明确提示，可一键均布重新生成，不能静默沿用旧结论。大于 12000 个截面或 256 层时保留包络显示，不能应用逐匝编辑；数值计算不截断。

桌面拖动仅更新一个临时图元，松手后合并几何刷新；网页用 SVG 更新选中截面，松手后仅请求几何检查，适用时不再生成 PNG。编辑后工程文件保存当前配置；正式 Word、Excel 和建模 ZIP 应先重新计算以取得新的不可变快照。三种输出复用同一位置迭代器，报告附手调中心表。两端电压使用相同机械位置。

保存设计 JSON 时，使用独立的 `winding_config` 对象。界面用 mm，JSON 中的所有长度均为 SI 单位 **m**；`order` 是自动模式从骨架向外的绕组编号，`overrides` 保存逐绕组线束与绕法；`layer_plan` 为空时自动排层，非空时优先采用完整手动物理层序。例如，以下自动方案的 P 需要电气总股数能被 3 整除，若总股数为 60，则是 3 束 × 20 股：

```json
{
  "winding_config": {
    "window_width": 0.012,
    "window_height": 0.004,
    "margin_x": 0.00025,
    "margin_y": 0.0001,
    "diameter_allowance": 0.00003,
    "layer_insulation": 0.00005,
    "interwinding_insulation": 0.00015,
    "wire_gap": 0.0,
    "order": ["P", "OUT1", "OUT2"],
    "layer_plan": [],
    "overrides": {
      "P": {
        "outer_diameter": 0.0,
        "wire_type": "litz",
        "parallel_bundles": 3,
        "packing_factor": 0.75,
        "bundle_diameter": 0.0,
        "flatten_ratio": 1.5,
        "winding_style": "dense_right",
        "turns_per_layer": 2
      },
      "OUT1": {
        "outer_diameter": 0.00023,
        "wire_type": "solid",
        "parallel_bundles": 1,
        "winding_style": "sparse",
        "turns_per_layer": 0
      }
    }
  }
}
```

示例仅说明字段和单位，不是推荐的骨架或线材设计；每层匝数仍须在实际计算的窗口容量内。`wire_type` 可为 `auto`、`solid`、`litz`，`winding_style` 可为 `sparse`、`dense_left`、`dense_right`。`outer_diameter` 是单股含漆外径，`bundle_diameter` 才是整束未压扁外径，不能混淆。旧配置缺少整个对象时保持窗口未配置，不从磁芯数据补造尺寸。

下面仅展示 `winding_config` 内的手动层序字段，应与有效窗口和逐绕组设置一起保存。它适用于实际只有 P 6 匝和 OUT1 2 匝、且各层容量足够的示例；若还启用了其它 OUT 或 AUX，必须把它们也分配到层序中。

```json
{
  "layer_plan": [
    {"winding_id": "P", "turns": 3, "winding_style": "dense_left"},
    {"winding_id": "OUT1", "turns": 2, "winding_style": "sparse"},
    {"winding_id": "P", "turns": 3, "winding_style": "dense_right"}
  ]
}
```

已填写有效窗口、且存在有效变压器结果时，Word 设计报告同步增加窗口与绝缘表、线材和整束参数表、逐绕组排层表、同源等比例截面和可放下/超限说明；手动模式另附完整逐物理层表，记录层号、绕组、本层匝数、绕法、前置绝缘及线束高，跨页重复表头。未配置窗口则不输出虚假的绕制结论。线材表记录外径来自实测输入或填充系数估算。导出采用当前绕制设置和有效设计结果，而不是截图；计算说明中的公式保持原生可编辑 Word 数学形式。

## 与电气模型的边界

调整含漆外径、整束外径、并绕束数、压扁倍数、疏密绕、顺序或窗口尺寸，只改变几何预评估，不自动回写绕组 DCR、漏感、两两 kij、铜损或电气工作点。电气总股数不会因为几何分束被改写。实际绕法会影响电气参数，但本功能没有由截面反推它们的电磁场模型；需要用户依据工艺、测试或独立仿真更新电气输入。

本模型支持分段穿插的径向层序，但不包括分段引出线和跨线的走线、端部连接空间、绞线鼓包、骨架圆角、槽内形变及制造公差。绝缘厚度只是几何占位，没有执行爬电、电气间隙、耐压或绝缘体系认证。几何可放下不等于满足安规、散热、漏感指标或可量产。

## 后台计算与界面响应

较耗时的设计计算使用一个后台数值工作线程，并且最多保留一个待算请求。用户连续输入时合并编辑：普通模式约等待 450 ms，支持的耦合矩阵模式约等待 700 ms，再提交最新参数；新的请求会替换尚未开始的旧请求，不排成长队。

计算开始时使用独立的参数快照。输入变更后旧结果标为无效，过期的成功结果或错误均不会覆盖新输入。长耦合求解在可取消检查点退出；已进入的单次数值库调用可能需要先返回，所以取消是协作式的，不承诺任意指令处立即终止。

⑥效率与优化页的“取消计算”可取消未完成的设计、负载曲线或参数分析；已完成且仍对应当前输入的有效设计可保留，尚未完成的新参数则没有可用结果。重新计算或重新进入需要的分析页面可再发起计算。

相同数值参数采用有限缓存，避免重复求解；缓存只在本次程序运行中使用，不等于保存了工程文件。效率负载曲线以及参数扫描、目标效率查找和优化也交给同一数值工作线程，避免与设计计算同时堆积；编辑参数后旧曲线不会写回新设计。求解失败的负载点保留空缺和失败信息，不画成有效效率。

Tk 控件与图形发布仍在界面主线程进行。窗口缩放、字号调整只更新布局，不重新求电气工作点；本页的窗口和绝缘设置只触发局部几何计算与重画，不触发耦合电路求解。

这些措施主要改善“计算时仍可操作、连续输入不排队、结果不串版”的响应。它们不代表物理方程变简单，也不保证每次多路非线性求解本身更快；较多输出、困难工况和图形发布仍可能需要时间。
