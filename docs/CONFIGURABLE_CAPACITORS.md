# 可配置并联电容组

输入与各路输出的电容不再固定为一颗或两颗。桌面左侧“电容”分组和网页对应分组均可设置数量、增加、删除，并分别填写每颗容量、ESR、ESL。至少保留一颗；增加数量时复制末颗参数，可逐颗改动。桌面列表自带滚动条，选中行后编辑下方数值；网页版在表格中直接修改。

## 数据与兼容

新配置使用 SI 列表：

```json
{
  "input_capacitors": [
    {"C": 0.0001, "ESR": 0.02, "ESL": 0.000000001},
    {"C": 0.00001, "ESR": 0.01, "ESL": 0.000000001},
    {"C": 0.000001, "ESR": 0.005, "ESL": 0.000000001}
  ],
  "output_capacitors": [
    {"C": 0.00022, "ESR": 0.035, "ESL": 0.000000005}
  ]
}
```

多路输出分别在每个 `outputs[i].output_capacitors` 保存独立列表。旧 `Cin1/Cin2`、`C_out/C_out2` 和第二电容开关仍可读取；新列表存在时以列表为准，前两颗投影到旧字段仅供兼容，不能截断第三颗及以后的电容。未编辑的旧配置保持原电容选择与计算结果。

## 参与的计算

- 纹波通过每颗复阻抗 `Zj=ESRj+jωESLj+1/(jωCj)` 分流，保留每颗 RMS、频段与 `I²×ESR` 损耗。
- 输出总容量、初筛、负载阶跃估计、每颗应力、BOM 与降额检查覆盖全部支路。
- 现有 C+ESR 状态模型（Buck/Boost 原型、耦合反激、QR、正激环路）接受全部输出支路。零 ESR 电容共用理想电压状态。原有简化环路仍采用总容量与低频等效 ESR，不因增加数量而被宣称为完整高频模型。
- 桌面图表随电容数量增加高度，使用现有滚动窗口；报告逐颗列出参数与损耗，Excel 同步按模块输出。
- LTspice 第一、第二颗继续在原生 ASC 图上；第三颗及以后以明确的额外支路放入 `support.inc`，ASC/CIR 同时包含这个文件，电气模型不会只取前两颗。

## 拓扑图随输入更新

软件①页按输入电容组、每一路输出电容组分别绘制。1～3 颗逐颗显示位号；4 颗及以上显示首颗、末颗，中间以省略号表示其余并联支路。每组标注实际数量与总容量 ΣC，下方器件表继续列出所有电容的位号、容量、ESR、ESL。

更改数量并点击“设置数量”，或增加、删除、修改电容后，沿用软件原有的自动重算流程刷新拓扑；删除的位号会从图中消失。多路输出分别显示，数量较多时仍按完整列表计算，不因图形省略而减少计算支路。超过三路时图内端口标题采用精简形式，完整路名保留在器件表。桌面、网页与 Word 报告共用绘图函数，拓扑示意同步更新；LTspice 原生 ASC 的符号展开方式仍按上一节说明。

## 验证

专项测试涵盖 3/4/5/7 颗的分流、损耗、状态数、主反馈与各路隔离、旧文件兼容、保存重载、无效输入、实际 Tk 图表和 Word/Excel 参数表。实际 LTspice 验证三颗输入、四颗输出的 Buck 工程，到达 18 ms 结束时刻；电感 RMS 相对计算误差约 -0.232%。此项验证不代表完成了所有拓扑、所有任意数量的硬件或 FRA 签核。

日志：`artifacts/qa/capacitor_banks_20261030/`。另一个旧测试对切换反馈后的非反馈派生电压固定期待 12 V；冻结的上一版也返回约 11.16 V，属于已确认的既有测试口径问题，未以修改电压模型混入本次功能。

拓扑联动专项：`tests/capacitor_topology_check.py` 覆盖六种拓扑、单组 1/2/3/4/27/1000 颗、三/六路输出、独立数量、首末位号、完整器件表以及真实 Tk 编辑后的增删与总容量更新；桌面/报告实际画幅检查电容注释与其他文字不相交。预览与日志保存在 `artifacts/qa/capacitor_topology_20261030/`。
