# 多路输出最小功耗与交叉调整率

左侧各路需求新增 `P_out_min`（W），原 `P_out` 明确为最大输出功率。主反馈路也需要最小功耗，因为它的负载会影响其余输出。约束为 `0 ≤ P_out_min ≤ P_out`。最小功耗应包含实际永久预负载；软件不会擅自添加预负载。

旧 JSON 未声明最小功耗时，按该路最大功耗迁移，保持原工作点，不自动假定 10% 负载。首次填入实际轻载功耗后才会产生相应负载组合。最小值仍与最大值相等时，修改最大值会同步跟随；已单独设置较小最小值后不跟随。

## 计算入口和边界

①拓扑 → 交叉调整率与电压范围 → 扫描最小/最大负载组合。扫描在后台执行，支持取消；修改参数使旧结果失效。每路独立取最小、最大两档，相等档位去重。三路最多 8 种组合，六路最多 64 种组合，再与 Vinmin / Vinmax 交叉；两端相同只求解一次。不因每个被观察输出重复求同一工况。

当前扫描入口支持固定频率 SSR 反激、准谐振 SSR 反激与有源钳位正激，至少两路输出，并检查实际非理想正定耦合矩阵。三种拓扑调用各自的求解路径；下述完整算例专门说明定频反激的分段 RL 周期稳态方法，不能把固定周期条件套给QR或正激。PSR及全部 kij=1 的理想分配模型明确标记不支持，不生成虚假的0%交叉调整率。

先在 Vinmin 的各路最大功耗下固定同一套磁芯、整数匝数、MLT、裸铜线径、股数与几何 DCR。扫描中不重新选磁件、不修改 kij、L、电容、器件和钳位硬件、不重新整定补偿器。主反馈维持理想直流目标，其余输出由耦合 RL 电路的二极管换流、周期电流及电荷平衡求解。

负载为恒阻：Rj = Vref,j² / Pload,j。Vref,j 是主反馈电压或整数匝比参考电压；实际功率为 Vactual,j²/Rj，不能将设定功耗理解为恒功率负载。0 W 真空载缺少泄放/寄生/控制器间歇模式，当前明确记为未计算，不用 ε W 偷换。

## 准谐振反激的独立求解

QR启用实际非理想耦合矩阵后，使用各绕组的自感、互感、几何DCR、固定整流/防反压降及同一套RCD硬件。导通及关断分段求解 `L di/dt + Ri = u`，依次检测各二极管导通和电流归零，直到全部储能传导支路退磁；每路独立积分二极管电荷，再与其负载电流乘本周期时间相等。所选主反馈路的防反管前电容电压是唯一输出电压约束，非反馈电压由联立解给出，不能沿用理想匝比结果作为交叉调整率。

参考名义点按Kc选RCD的R/C并冻结，角点不按负载重新选电阻，也不强制同一Kc电压。增加平均钳位电压Vclamp作为未知量，用矩阵所得钳位电荷Qclamp联立 `Vclamp·Qclamp/T=Vclamp²/R`。Vclamp相对输入母线，并非完整Vds。`Qclamp/C`仅为忽略充电时电阻泄放的纹波上界估算；大纹波下平均恒压换流精度下降，不能称为完整RCD瞬态。没有冻结硬件的独立名义工作点仍保留恒Kc兼容路径，不能代替固定RCD的完整扫描。

周期为导通、矩阵退磁和谷底等待三者之和。恒定有效谐振电容下，退磁完成后的第n谷等待为 `(2n−1)π√(Lres·Ceff)`，n从1开始；Lres取矩阵原边自感。Ceff优先取正值 `spice_config.qr_cds_pf`，否则取 `Coss`，再加折算原边的 `cw_primary`。根据周期CS一阶滤波、比较器延时和稳态电流指令反推L6565参考COMP，再由关断消隐选第一个允许谷底；不是固定频率PWM。所需CS指令超过VFF修正钳位、导通时间不满足约束或没有单周期自洽谷底时明确失败。界面 `f_sw`仅为设计上限检查，不强行把周期延长到 `1/f_sw`。每个角点的实际频率、退磁和谷底信息须与电压一起保留。

该模型为直流输出电容端、恒定Ceff与固定RCD平均电压的工程近似。不完整解析谷底负向原边电流、真实ZCD RC/阈值/衰减、启动定时器、VCC、限流或保护动态，不把完整LTspice瞬态等同于这一稳态模型。每颗电容仍由原支路重建分流和纹波；独立跨调求解不自动把QR低频环路变成完整多端口线性化。没有启用有效矩阵时仍为标称匝比约化，不能发布独立跨调计算值。

设计计算完整、实际仿真完整和二者均完整分别判定。角点求解失败、仿真未稳定或缺失时保留观察值与原因，不计作完整包络；仅计算可用或仅仿真可用均不冒称完整对比。实际频率超过设计上限时可保留已解工作点，但须另标超限；完成求解不等于全部设计约束合格。旧工程各路min=max时保留原值，软件不擅自填10%轻载；需用户填写真实最小功耗后才有相应负载变化。

物理依据：[ST AN1326第3页式(4)、第4页QR时序与能量推导](https://www.st.com/resource/en/application_note/an1326-l6565-quasiresonant-controller-stmicroelectronics.pdf)、[L6565数据手册ZCD及轻载频率折返](https://www.st.com/resource/en/datasheet/l6565.pdf)、[TI SSZTD98图1至3的漏感台阶与轻载峰充](https://www.ti.com/document-viewer/lit/html/SSZTD98/GUID-56A31413-780F-4984-B393-18DC28330328)。厂家资料支持物理机制，矩阵求根、稳态消隐指令换算和数值验收为项目实现，不是原厂认证模型。

固定RCD的依据见[TI SLUP261第32页VI.A/图35](https://www.ti.com/seclit/ml/slup261/slup261.pdf)，其第13、16页也展示钳位电压对跨调的影响；矩阵Qclamp求根为项目实现。

## 结果定义

- 观察电压范围：成功扫描角点中的直流 Vmin 与 Vmax。
- 相对参考偏差：100 × (Vmin/max / Vref − 1)。不是相对额定满载解的误差。
- 包络跨度：100 × (Vmax − Vmin) / Vref，同时包含本路负载改变与其他路负载影响。
- 纯交叉跨度：固定 Vin 与被观察路自己的负载，仅改变其他路负载得到的最大电压跨度，再除以 Vref。输入端点变化不混入这一指标。

每个最低/最高结果都关联角点编号、输入电压和全部输出负载。被观察路轻载、其他路重载是需要检查的组合之一，不预设为必然最大值。也扫描全轻载、全重载及其他混合组合。

存在不收敛、未支持真空载或其他失败角点时，保留原因；成功角点的数值只叫“观察范围”，并标记不完整。已收敛也只覆盖声明的离散输入端点和负载角点，不构成连续负载范围、温度/容差范围的严格极值保证。范围不包括开关纹波、负载阶跃过冲和控制器限流失调。

## 报告和自动化

Word 双工况报告自动加入各端点的最小/最大功耗表、电压范围/偏差/跨度、包络图、极值工况及全部组合明细。Excel 新增“13 交叉调整率”工作表，保持左 Vinmin、右 Vinmax 的现有结构。报告快照缺少扫描结果时明确说明，不以标称值代替。

Python API：`design_api.run_cross_regulation(spec, progress=..., cancelled=...)` 返回 JSON 安全的完整端点扫描结果。`calculate_input_endpoints` 默认附带扫描，可用 `include_cross_regulation=False` 跳过；报告默认不跳过。

模型背景参考：[TI 多输出反激漏感与交叉调整率技术说明](https://www.ti.com/document-viewer/lit/html/SSZTCW3/GUID-9BE5B4A2-3166-4329-A3F0-4F836580FCC7)。资料说明漏感与轻载的影响，不是当前数值算法精度或所有最坏工况的验证证据。
