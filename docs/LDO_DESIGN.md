# LDO 线性稳压设计与系统架构

本功能加入个人开关电源计算器的桌面版和本地网页版。LDO 是电源单元的一种类型，使用独立线性模型。

## 使用顺序

1. 在系统架构中点“增加 LDO”。将输入源或开关电源的 OUT 连接到 LDO 的 IN，再把 LDO 的 OUT 连接到负载或其他电源。节点、负载和二极管支路仍可拖动、删除及编辑。如需查看示例，可用“打开工程 / 原配置”打开随程序附带的 `examples/SYSTEM_LDO.json`。
2. 进入 LDO 单元，填写输出电压、轻载/满载电流、最大压差、最大接地 Iq、器件身份和热设计条件。推荐输入范围、额定电流及规格书电容限制未知时留空，检查显示“资料待补充”。
3. 默认跟随上游输入范围：进入单元和生成系统报告时，自动同步已连接上游的可用电压范围，包含竞争二极管的固定 Vf 压降。取消勾选后使用单元保存的输入范围。
4. 可调输出填写 Vref 和上电阻 R1，软件计算下电阻 R2；固定输出无外部分压。EN、PG、反向电流保护记录芯片能力，实际接线须查规格书。
5. 点“计算 LDO”。网页修改输入后禁止导出旧结果；桌面导出前自动重算。返回系统架构回存参数，顶部“保存系统工程”另存整个网络 JSON。
6. 单元可导出 Word、Excel 和 JSON。系统报告包包含网络总览、预算及 LDO 独立报告；Excel 将 Vinmin/Vinmax 的轻载/满载结果左右并排。

## 公式与量的定义

所有内部数值采用 SI 单位，界面按 mA、µA、mV、µF 等显示。Word 中公式使用可编辑的原生数学公式。

设 Iout 为外部负载，Idiv 为外部分压电流，Iq 为芯片接地电流：

```
R2 = R1 × Vref / (Vout − Vref)
Idiv = Vout / (R1 + R2)                 （固定输出取 0）
Iin = Iout + Idiv + Iq
Pin = Vin × Iin
Pout = Vout × Iout
Pchip = (Vin − Vout) × (Iout + Idiv) + Vin × Iq
Pdivider = Vout × Idiv
Pin = Pout + Pchip + Pdivider
η = Pout / Pin
Tj = Ta + Pchip × θja
```

θja 必须是实际 PCB 铜面积、层数、散热条件对应的有效结至环境热阻。软件不能从封装名推导真实温升。未勾选热条件已核对时，保留估算并提示资料待核对。

压差裕量采用 `Vin − [Vout × (1 + 精度百分比/100) + 最大压差]`。最大压差与 Iq 应覆盖所用负载和温度。每个输入端点分别计算轻载与满载，共四角点。若压差不足，保留失败角点；输出电压、损耗、效率和结温标为未定义，不冒充稳定输出。

例如通用假设 5 V→3.3 V、100 mA、Iq=50 µA：输入功率 0.50025 W、芯片耗散 0.17025 W、输出功率 0.33 W。输入升到 12 V 时，芯片耗散升至 0.8706 W；可见 LDO 不能沿用固定效率预算。

## 系统预算与器件检查

系统每个供电工况用实际 LDO 输入电压计算 `Vin × (最大负载 + 分压电流 + Iq)`，与保存的预设效率无关。下游负载占用 LDO 额定输出能力，不再次重复加到 LDO 的输入预算。下游超过容量时单独提示；不会自动提高设计电流。

压差不足的 LDO 不向下游声明可用稳压输出。电流、温升、输入范围及资料缺失分别给出待核对提示；该模型不模拟芯片过温或限流保护动作。开关电源模块继续使用原有预算与计算路径。

芯片共用厂家/型号/封装；电容填写耐压和类型，分压电阻填写额定功率，沿用项目的规范分区与降额规则。默认电阻平均功耗不超过额定功耗的 20%。U1 按推荐工作范围、电流和结温检查，不套用 MOS 耐压降额因数。示例均为通用假设，不代表已选定、已验证芯片。

## 模型范围与维护位置

目前是正电压、共地、单路输出、静态线性稳压模型。输出精度为用户填写的规格书包络；功耗、温升及系统下游传播使用标称 Vout，未叠加未知的线性/负载调整率、FB 偏置电流和元件容差。有效容量与 ESR 仅检查已填规格书边界，不构成稳定性证明；不预测 PSRR、噪声、动态纹波、负载瞬态或回灌过程。

- `ldo.py`：纯计算、参数约束、四角点、BOM 与检查。
- `ldo_report.py`：共用计算结果生成 Word/Excel/JSON。
- `ldo_ui.py`、`web_app/frontend/src/LdoWorkspace.vue`：桌面与网页输入呈现。
- `power_units.py`：分派线性与原开关电源配置。
- `power_network.py`、`network_report.py`：网络预算、上游电压和系统报告。
- `examples/SYSTEM_LDO.json`：5 V→3.3 V、MCU 与 ADC 供电示例。

系统工程沿用 `power.system-network/2`，LDO 单元以 `design_type=ldo`、`topology=LDO` 标识；独立结果为 `power.ldo-result/1`。计算内核和报告不依赖 UI，后续复用浏览器内核时应以相同能量守恒及角点用例验证。
