# 输入电压范围与双工况报告

更新日期：2026-10-18。

## 输入与界面

电路需求使用 Vin min 与 Vin max，必须满足 0 < Vin min ≤ Vin max。选择“Vin min”或“Vin max”后，右侧拓扑、功率级波形、损耗、电容、磁件和环路均对应所选电压；显示工况和实际电压需要同时核对。切换后须等当前计算完成，不沿用上一工况的图表。

旧配置只有 V_in 时，迁移为 Vin min = Vin max = 原 V_in，不自行添加百分比范围。保存配置保留范围和所选工况，同时保留 V_in 标量，供旧计算入口兼容使用。原来的低频临时带宽门槛仍停用。

## 同一套硬件

自动磁芯、整数匝数、线径及每路绕组先在 Vin min 解析，再将这套硬件用于两个端点。显式的器件、电容、采样、耦合矩阵、补偿器与预设效率不随端点自动改变。PSR 辅助绕组及偏置配置也使用同一硬件。

切换显示不是重新选型，也不为每个输入电压单独整定补偿。某端点的电流、磁密、温升、纹波或稳定性不满足要求时，应修改这套共同硬件后重新核算。仅选择 Vin min 作为自动设计基准，不表示它一定是所有指标的最坏工况；最坏端点由计算结果分别判断。

数值任务使用现有后台队列和有限缓存；不在启动时计算所有图像。修改范围或器件会取消旧任务；未成功计算的端点不得用旧波形或默认结果补齐。

## 报告怎样阅读

报告先给出输入范围、共同硬件、计算完成状态及双端点对照，再分别提供 Vinmin 和 Vinmax 的完整设计报告。

- 对照表将两端的实际输入电压、工作模式、占空比、器件电压电流应力、纹波、损耗效率、磁密温升和环路指标放在相邻列，注明各指标较不利的端点。
- 对比图采用固定的端点配色和同一坐标尺度；波形和 Bode 只作可比性展示，不以颜色代替数值或稳定性核验。
- 各端点的完整部分保留需求、拓扑、所有输出、电容频带、磁件、环路、补偿电路和模型边界。章节与图题标记端点，避免跨页后混淆。
- 没有有限穿越、缺少环路模型或某端点计算失败时，报告明确说明，不填零或自动判定通过。两端电压相等时仍保留两种工况标签，并说明数值相同。

完整报告始终包含两个端点，不受界面当前选择影响。工程评审的输入角点范围沿用需求页，不再另设一个互相矛盾的 ±10% 范围。端点比较不代替输入区间内的连续扫描、器件容差、温度角点、控制器模式切换或样机测试。
