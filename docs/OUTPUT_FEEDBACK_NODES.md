# 输出端口与反馈取样节点

2026-10-25 起采用统一约定：Vout 是输出防反二极管之后的端口电压，负载功率与交叉调整率也在该端口统计；SSR 反馈取所选一路防反管之前的电容端电压 Vcap。没有防反管时，两节点重合。

## 参数与节点

| 项目 | 节点与含义 |
| --- | --- |
| 用户输出设定 V_out | 防反管后端口目标，只有反馈路可独立设定 |
| V_out_cap 与 V_feedback | 防反管前电容端实际直流电压；只有选中一路接入反馈 |
| V_feedback_target | 反馈路端口目标加该路固定防反压降 |
| V_in | 输入连接器电压，在输入防反管之前 |
| V_in_bus | 输入防反管之后的功率级母线电压 |
| SPICE outN | 防反管后端口 |
| SPICE capN | 电容端，反馈选择器和 FRA 功率级探针均接此处 |

例如 Vout 设为 30 V、输出防反管固定压降 0.7 V，则电容端反馈目标为 30.7 V。SPICE 的 VSET=(30+0.7)×FB_SCALE，补偿电路分压按 30.7 V 计算，不直接使用 30 V。固定压降下两节点的小信号电压增量相同，但直流偏置不同。

## 匝比参考与负载

非反馈路不独立稳压。其参考电压按实际整数匝数、整流与防反固定压降估算：

    Vj,ref = (Vb,target + Vblock,b + Vrect,b) × Nsj/Nsb − Vrect,j − Vblock,j
    Rload,j = Vj,ref² / Pj,rated
    Pj,actual = Vj,port² / Rload,j

无效负压参考明确报错，需调整匝数或压降。旧 JSON 不增加新的可编辑电压字段；已有显式 Ns 时，非反馈路参考会按新公式更新，进而更新由其换算的恒阻负载。旧报告和旧程序保持原样，不能与新模型的结果直接混用。

用户三路配置 12/5/2 匝、主反馈端口 30 V、各整流和输出防反均 0.7 V 时，参考值由旧的 30/12.5/5 V 改为约 30/11.6833/3.8333 V；这是负载换算参考，不是耦合求解结果。实际非反馈输出另列。

## 物理耦合模型

耦合模型以电容端电压为状态，二极管换流端电压为 Vcap+Vrect，输出负载电流为 (Vcap−Vblock)/Rload。主反馈固定所选 Vcap，其他路按周期与电荷平衡求解。输入方程使用 Vin−Vin,block。

源端能量平衡同时包括输入防反、各路输出防反、整流、铜阻、MOS、采样和钳位损耗。恒压防反管前后纹波增量相同，直流电压不同。电容耐压与降额检查使用电容端电压及纹波，不能沿用防反管后的端口电压。

低频周期映射以 Vcap 为电容状态，以端口电压计算负载电流；SSR 单一反馈仍来自所选电容端。交叉调整率的电压范围始终在端口统计。

非耦合标称模型仍是预设效率的等效负担近似，并未增加精确器件换流求解；它也区分这两个直流节点，但不能把这一近似当成详细 SPICE。If–Vf 曲线继续用于损耗后处理，固定 Vf 用于换流与节点偏置；没有将损耗曲线静默当成完整器件模型。

## 显示与报告

桌面与网页将输出标为防反后端口，并列电容端电压。拓扑图的 SSR 箭头接在防反管之前。补偿器分压与 MP6005 PSR 的辅助绕组反推使用电容端及整流压降，预测端口值时再扣输出防反压降。

Word/Excel 共用节点说明、端口与电容端对照、含压降的匝比公式。SPICE 对比报告分别测量 outN 与 capN；FRA 在取样通道注入，功率级探针也使用 capN。实际完整负载角点、FRA 和瞬态继续各自显示完成状态，不复用旧模型的测量结论。
