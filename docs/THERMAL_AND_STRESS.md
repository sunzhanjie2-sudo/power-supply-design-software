# 变压器热阻与器件应力

## 变压器至环境热阻

左侧⑦输入 Ri-a（`Rth_transformer`），单位 K/W（数值等同 ℃/W）。

ΔT = (Pcu + Pcore) × Ri-a

Pcu 包含原边、全部输出副边以及已建模 PSR 辅助绕组的铜损。修改热阻不改变电流、线径和损耗；本版未迭代温度相关铜阻。Ri-a 表示整体至环境的等效稳态热阻，不是铜线电阻，也不是局部热点热阻。缺少环境温度时只输出温升，不声称计算绝对温度。

默认100 K/W只是可编辑初值，不是所选磁芯的厂家保证值。旧 JSON 缺少该字段时也采用此初值，必须自行校核。旧 `h_conv` 继续读取以兼容文件，但只用于独立电感；反激界面将其隐藏。有源钳位正激的变压器和独立输出电感分别采用各自模型。

## 反激 MOS 钳位应力

Kc = Vclamp / Vreflect；Vds,limit = Vin + Kc × Vreflect。

Vclamp 相对输入母线，而不是完整 MOS 漏源电压。主 MOS 的上限与模拟波形峰值分别显示，不再叠加旧 `ring_margin`。快速模型在漏感能量不足时不能达到钳位上限；没有漏感时不画出虚构尖峰。矩阵模型使用其理想钳位电压和真实求解峰值中较高的应力上限，不重复添加尖峰。

Kc 须大于1才代表有效钳位。未配置有效钳位时，程序只知道理想阻断平台，明确提示不能据此认为已经覆盖尖峰。Kc 不是器件额定耐压的降额系数；寄生过冲、钳位器件容差和温度仍需实测。其他拓扑保留 MOS 电压裕量，不能将反激的 Kc 定义直接套用到有源钳位正激。

## 整流二极管

反向电压为当前计算模型给出的值，不再乘以 MOS 振铃裕量。单路、多路输出以及整流/续流器件的界面和报告均说明：未考虑寄生尖峰应力，具体应力需实测，建议选型时留有耐压余量，并核对温度降额和反向恢复。耦合矩阵会计算理想换流过程，但不代表已经模拟结电容及布线寄生造成的尖峰。

Word 和 Excel 使用同一报告计算快照；两端输入工况共享用户填写的 Ri-a 和同一套器件。
