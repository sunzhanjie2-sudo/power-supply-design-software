# 网页与桌面功能核对：补齐验收

日期：2026-10-23。环境：Windows、Python 3.13、Node 24.19.0、Edge。原 EXE 不替换，不部署公网。

## 本轮新增

- 环路：Venable 候选整定、实际裕度/闭环校验、显式应用；多路参考/负载响应入口。
- 补偿：四种原有物理网络，阻容正反算、回代、参考图、保存配置。旧文件单位格式必须明确解释，不按数值大小猜测。
- 效率：5–41 点扫描、目标效率查找、最多三变量有界优化；不把候选自动应用为当前设计。
- 评审：固定硬件角点、最坏工况、冻结真实双工况 A/B 与对比 JSON。
- 磁件：标准形状/型号、自定义几何单位、材料 k/α/β、电流密度、DCR、全部输出电感、磁通与饱和界限。
- 绕制：净窗口/绝缘、疏密绕、左右靠齐、利兹线分束/压扁、逐层交错、局部截面预览。
- 结果：器件应力与分项损耗、每路整流/防反、电容参数与总/分颗/频带 RMS、MP6005、RCD/有源钳位。
- 易用性：默认 16px，18/20 可选；桌面模块换行避免末页被挤出视野，窄屏导航可横滑；参数抽屉有明确关闭按钮。曲线可预览和按位号显式复用，内置 Word 公式文档可下载。

所有电气计算仍复用既有 Python 模块。前端仅做单位显示、几何配置编辑与已有结果展示。

## 保留边界

- 不声明完全覆盖桌面所有历史配置与全部交互。详细映射见 [功能核对](WEB_DESKTOP_PARITY_20261023.md)。
- 新增角点/A-B 图表与明细未追加进 Word/Excel 新章节；正式报告只读取已经应用并重算的设计快照，A/B 另有 JSON。
- 固定硬件角点各输出同比例缩放，不替代独立负载组合的交叉调整率；优化也不等于所有硬件约束的全局可行解。
- 绕制几何预览不反写漏感、kij、DCR 或铜损；改电气匝数/线径后需重算。几何与磁芯模型仍须工艺/实物验证。
- 无项目数据库、多用户会话或云端权限系统；同一服务共享一个最新运行时。关闭服务前保存配置、报告与所需对比 JSON。
- 取消为协作式，按需绘图与预算限制改善资源调度，但未做本轮总内存/全工况耗时基准，不承诺任意六路耦合配置实时完成。
