# 在其他电脑运行联合仿真

适用：Windows 10/11 x64 桌面版。便携包自带 Python、Gmsh、meshio 和变压器提取内核；不需要安装 Python 或复制另一套变压器研究工程。Elmer 和 LTspice 使用目标电脑上的完整安装。当前实现不表示已支持 macOS、Linux 或任意电磁求解器。

## 第一次配置

1. 复制完整 `PowerDesignDesktop` 目录，保留 `_internal`，双击主 EXE。打开工程中的电源单元，再进入右上角联合报告中心。
2. 在“工具与模型”选择 Elmer 安装根目录（包含 `bin/ElmerSolver.exe`、`bin/ElmerGrid.exe` 和运行库）；也可选择其 `bin` 或 `ElmerSolver.exe`。不能只复制两个 EXE。
3. 选择 LTspice 可执行程序。两种求解软件的路径属于本机设置，换电脑后可以重新选择；显式配置优先于旧环境变量。
4. 选择当前磁芯的 STEP/STP/BREP 封闭实体，登记型号、装配方式和坐标来源。也可以直接导入另一台电脑导出的“模型配置包”。STEP 采用文件内声明单位；BREP 需选择 mm 或 m；STL 不作为实体输入。
5. 核对绕组内侧半径 r0、轴向起点 z0、CAD 平移/旋转。已有工程的绕组定位优先，不能被旧模板覆盖。单半芯中柱磨隙模式还需要中柱半径及气隙中心 Z；已装配实体的实际气隙必须与当前设计一致，程序不会再次磨隙。新型号首次需要核对这些几何关系；任意 STEP 不能仅凭文件名自动定位。
6. 点击“检查运行环境”，再保存配置。回到“联合运行与结果”，选择保存目录、裕量倍数并开始。程序依次检查实体/干涉、网格、场解、矩阵、设计计算、电路仿真和报告；运行环境检查通过不代表场解收敛或器件合格。

## “提取设置”现在由谁提供

旧提取 JSON 包括原几何 ZIP 路径、CAD、气隙、材料、端口接线、求解软件路径等，容易引用旧电脑的目录。默认流程现在根据当前设计自动生成这份 JSON；匝数、完整线并绕、逐匝位置、层序、窗口、绝缘、材料/磁导率及物理气隙由当前工程提供。已有接线保留，完全空白的接线可以生成明确标为假设的同向串联参考，部分填写的接线不会被偷偷替换。

每次运行建立独立输入目录，包含 `models/core.step`（或对应扩展名）、当前绕制输入 ZIP 和自动提取 JSON；CAD 和 ZIP 引用使用相对路径。Elmer 路径单独属于当前机器。原始冻结项目、文件哈希及所有阶段日志保留，不能把旧场解当成本次完成。

“兼容已有外部提取器与旧提取设置”只服务于老工程调试，默认关闭。新电脑正常联合流程不需要填旧工具目录，也不需要先用另一个软件建提取工程。

## 换电脑时带什么

- **程序**：整个 `PowerDesignDesktop` 文件夹；不是单独一个 EXE。
- **工程**：保存的系统工程或单元 JSON。模型包不包含电气设计。
- **磁芯**：在配置页点击“导出模型配置包”，得到仅含 CAD 与装配/坐标配置的 ZIP；另一电脑导入后选择其本机 Elmer/LTspice。包不夹带第三方软件、用户绕制或旧结果，导入校验型号、大小、路径和 SHA-256。
- **结果**：要追溯旧报告时，复制整个对应联合运行目录。

保存模型时，软件优先在 EXE 旁的 `simulation-models` 以相对路径登记 CAD，复制整个程序目录即可携带。安装目录只读时回退到本机用户目录，此时需通过“导出模型配置包”带走模型。软件运行缓存、Elmer 启动副本和 Matplotlib 缓存使用任务工作目录，不要求修改安装目录或安装版 Elmer。

## 模型范围

目前内置场解与原提取器一致：圆形闭合等效匝、线性零偏置静磁场；不含真实螺旋跨层引线、涡流、非线性偏磁或寄生电容。网格档位、空气域和单工况超时可配置。网格/空气域收敛和样机验证分别说明，不因“便携”或“环境检查通过”而宣称已验证。

## 开发边界

`simulation_environment.py` 管理机器路径和可搬移模型；`simulation_environment_ui.py` 为集中设置页；`portable_transformer_project.py` 从当前快照生成输入；`field_worker.py` 在独立进程运行 `transformer_field_runtime/`；原 Job Object 保证停止任务时连同 Elmer 子进程终止。默认 `tool_root='builtin'`，外部提取器接口仅兼容保留。内置求解源码来源、逐文件哈希和修改说明见 `transformer_field_runtime/SOURCE_MANIFEST.json`。
