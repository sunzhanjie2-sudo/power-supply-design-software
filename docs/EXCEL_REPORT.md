# Excel 模块对照报告

多路输出新增“13 交叉调整率”：最小/最大功耗、非反馈直流电压观察范围、归一化偏差与包络/纯交叉跨度、包络图、极值工况和全部扫描明细。左侧为 Vinmin 的负载组合，右侧为 Vinmax 的负载组合，不将两端混成相同范围。失败/真空载/不支持模型保留状态。见 CROSS_REGULATION.md。

顶部“导出报告”、文件菜单“导出设计报告”或 Ctrl+E 打开保存窗口。文件类型选择“Excel 模块对照报告”，输出 `.xlsx`，无需安装 Excel 才能导出。查看工作簿可使用 Excel、WPS 或兼容阅读器。

## 模块和两端工况

每个适用模块对应一个 Sheet：需求与工况总览、拓扑与多路输出、功率级与开关波形、功率器件与损耗、电容纹波、磁件与绕制、环路与补偿电路、钳位与复位、损耗与效率、MP6005 PSR、模型与评审、输入参数快照。PSR、钳位等模块随拓扑和反馈方式决定是否输出，不适用时不创建空页签。

每页 A–H 为 Vinmin，J–Q 为 Vinmax，I 列留空分隔。相同章节起始行对齐，工况标题冻结在前四行。总览给出两端主要数值和较不利端，并提供同轴曲线；详细图表分别保留在两侧，不能只凭不同坐标范围比较峰值。

计算继续共用 Vinmin 确定的磁件、全部绕组和同一补偿器。导出不重新整定，也不会将界面当前显示结果复制到另一端。某端失败则明确显示失败原因；环路未定义、不适用或存在模型限制时保留原说明。

## 数字和图表

单个数值保存为 Excel 数字，单位通过单元格格式显示。百分比按比例值保存，便于复制和二次分析。复合量（例如原副边匝数或多参数组合）保留为文字。总览数值保留原计算精度，详细表格沿用工程报告显示精度。

波形、Bode、电容柱状图、磁件截面和补偿参考电路复用 Word 报告的绘图源，以高清 PNG 嵌入。数学关系为可读公式说明，不将非线性求解器伪装成单元格公式。工作簿是导出时的报告快照，修改数字不会刷新图像或重新运行电源模型；调整需求或器件请回软件计算并再次导出。

打印使用 A3 横向、一页宽、纵向自动延伸，并保留模块工况标题。长模块在章节边界增加分页，屏幕查看仍可连续滚动。Word 版保留原生数学公式与自然分页，仍可选择导出。

帮助菜单只保留“计算方法与公式说明”。项目中的手册、设计流程实现和参考资料未删除。
