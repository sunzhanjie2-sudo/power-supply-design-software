# 多路输出主反馈与各路响应

更新日期：2026-10-25。耦合反激环路加入独立并联 C/ESR 网络，不自动改动旧补偿器。

## 使用方法

1. 在左栏选择主反馈 OUT。只设计这一路的闭环；其他路并没有独立控制器。
2. 打开⑤环路。“主反馈 Bode”显示唯一回路的对象、补偿器、开环及 PM/GM/fc。
3. 切到“各路响应”。上排是主参考变化到所有输出电压的归一化跟踪；下排选择 OUTk 负载，查看增加该路下拉电流对所有输出的局部频率响应。单位 Ω 即 V/A。
4. 耦合反激的临时低频带宽限制已停用，不再按该上限降低目标 fc。自动整定仍验证候选闭环极点与所有穿越后才写回，原有开关频率保护保留。请先等待当前工作点计算完成。
5. 导出 Word 自动包含同源响应图及直流负载灵敏度矩阵。不需要先滚动或打开全部页签。

## 两种模型不要混用

未启用矩阵或全部 kij=1 时，保留旧刚性匝比、总负载与折算电容模型。它仅提供近似参考跟踪，没有独立负载模型，不显示虚构的交叉调整率。多路正激的独立 LC 动态并不由此得到完整验证。

固定频率 SSR 反激的非理想矩阵模型使用已收敛周期电路解。从周期映射中提取绕组状态、平均整流电流与峰值采样导数，仅将绕组核作双线性低频连续等效，再与每颗独立 C+ESR 支路联立。两颗有限 ESR 电容保留两个内部电压状态，支路电流、端口电压、负载及峰值内环共同求解。并联产生的附加极点、ESR 零点和负载直通项均保留；只在 ESR 严格为零时合并直接并联理想电容的共享电压状态。详见 [并联 ESR 模型](PARALLEL_ESR_LOOP.md)。

G_j 表示控制到第 j 路电压，G_jk 表示第 k 路负载电流到第 j 路电压；b 为主反馈。所有输出共用 T=Gc·G_b 和分母 1+T。各路参考传递为 G_j·Gc/(1+T)，闭环负载响应为 G_jk−G_j·Gc·G_bk/(1+T)。直流矩阵是积分控制下的局部导数，不是大信号负载阶跃或全负载交叉调整率。

## 保护与边界

- 两档归一化差分步长 2e-5、1e-5，最大相对差异超过 3% 拒绝；接近 CCM/DCM 或周期倍化边界时拒绝。
- 充放电纹波超过实际直流电压的 10% 不输出该模型 Bode。
- 已停用新增的 fs/20、最小 ESR 零点/5 频带截断，以及频带/2、数值 RHP 零点/5 的强制整定上限。Bode 保留 0.01 Hz 至 max(10fs, 1 MHz) 的原扫描范围；独立 ESR 网络已纳入，但高频仍属于未验证的近似外推。
- GM 只在扫描范围检测，未检出不表示无限裕量。原有开关频率整定保护、RHP 带宽建议、闭环极点和周期谱半径检查保留；实验模型的检查通过不等于硬件稳定认证。
- 周期初始的原边电流为零，延续现有钳位复位假设；比较器假定当前导通末端是首次有效阈值交点。固定输入、恒阻额定负载，扰动为额外小信号负载电流。内环周期谱半径仍描述原恒电容端绕组核；快速 RC 连续极点经双线性变换靠近 −1 不解释为真实 PWM 次谐波。
- 本次 ESR 网络修正环路功率级及各路小信号响应；原直流/周期整流电流仍取刚性电容边界，未因 ESR 修正而消除 Coss/Cj 参与换流导致的电流脉冲差异。原损耗和开关纹波计算不重复叠加本网络的功率或纹波。
- 不含完整光耦/TL431、驱动延迟、采样消隐、限流、Coss/Cj、ESL、钳位电容动态、磁饱和或大信号模式切换。不将本模型移植到 QR、MP6005 PSR、正激。
- 未新增加权反馈或多路独立调制。需要更高精度时应引入实际反馈链和厂商开关模型，并做独立负载角点及样机 FRA。

## 计算与验证

⑤页按需交给现有单数值线程，取消和最新结果校验继续生效，不会在启动时建立所有环路。GUI、API、角点、Word 使用同一工厂；GUI 与 Word 共用各路响应绘图函数。

测试：`tests/output_capacitors_check.py`、`tests/multi_output_loop_check.py`、`tests/multi_output_loop_ui_check.py`。覆盖精确复阻抗、不同容量/ESR、理想电容、第二支路开关、三路/六路反馈切换、复数 KCL 独立求解、独立直流重算、后台错误、补偿验证和图表。未宣称完成全器件/全工况开关仿真对标。

- [TI 反激设计应用简报](https://www.ti.com/document-viewer/lit/html/SLVAFK6/GUID-0B3C241B-688B-44BB-847B-682F017BB8A9)：RHP 零点、光耦带宽及选择主反馈的工程考虑。

上述资料是物理与架构依据；本程序的绕组周期核与连续 RC 网络联立、差分门限属于工程近似，不是完整复现这些原厂模型。
