# 本地网页版与桌面版功能映射

核对日期：2026-10-23。项目：`<本机路径，不随源码分发>`。

本文用于说明“首版本地网页缺少哪些交互、本次接入了什么、还差什么”，不是声称完全覆盖 EXE 的声明，也不是物理模型精度认证。浏览器实测与截图另见 [第二阶段验收记录](LOCAL_WEB_QA_20261023.md)；日常使用见 [网页版说明](../web_app/README.md)。

## 1. 版本与数据边界

- 当前网页入口是项目根目录 `启动网页版.cmd`，源码在 `web_app/`。历史独立 `web/` 目录不是这一版工作台。
- FastAPI 固定面向本机回环地址，未发布公网、未配置云服务、没有多人账号或项目数据库；原 EXE 保留。
- Vue 负责表单、动作调度和展示；电气求解、损耗、磁件、环路与报告继续复用 Python。新增网页交互不等于换了模型，也不提高原模型的物理精度。
- 已计算的 `Vinmin` / `Vinmax` 共用固定硬件。切换查看不会重新选芯；改参数后需重算，不把旧图当成新结果。
- 高级动作基于已完成快照，返回候选或只读分析，不直接修改 `DesignRun`。适用的候选必须显式应用，再重新计算。

| 工程角点 | 输入电压×同比例负载、固定同套磁件、失败工况与最坏值/对应角点 | 不替代非反馈输出独立轻/重载组合的交叉调整率分析；本次结果尚未追加到 Word/Excel 角点章节 |
| 冻结 A/B | 从服务端获取真实双工况快照，保留 snapshot_id/输入/硬件/摘要，逐指标显示 A、B、B−A 与输入差异；可导出对比 JSON | 浏览器内存保存，刷新会清空；需求不同提示不可直接判断优劣；尚未追加到 Word/Excel 对比章节 |

这里的“已接入”表示当前源码有实际界面、请求与结果路径，不表示每种拓扑、每组参数和每个历史配置均已通过浏览器逐项核验。

## 3. 新增交互怎样使用

### 环路整定与补偿网络

1. 完成当前工程的双工况计算，选择 `Vinmin` 或 `Vinmax`。
2. 在“环路”页输入目标 fc、PM 与 auto/type2/type3，运行候选整定。auto 是类型选择规则，不等于输入框改动后自动整定。
3. 检查是否可实现、候选的实际穿越、全部穿越最小 PM 与闭环稳定性。不可实现时不提供写回参数。
4. 点击“将候选参数写入输入区”，然后重新计算，核对另一输入端点，而不是只检查被整定的工况。
5. 在“补偿参考电路”选择网络和方向。正向由已算零极点求阻容，反向从阻容求零极点；计算值可带入反向表单，检查目标与回代差异。
6. 正向配置要保存到正式报告时，也需显式应用 `__comp` 并重算。TL431 光耦固有极点或快车道增益地板造成的不匹配会保留，不用“看起来接近”的参数替代。

旧补偿配置存在数值与显示前缀的兼容差异，页面提供两种明确解释：默认按桌面 `v × u`，例如 20 与 k 为 20 kΩ；只有确认旧文件 `v` 已经是 SI 时，才主动选择“前缀仅作标签”。不按数量级猜测。新网页状态使用 SI、空前缀和 `encoding: "si"`，避免重复乘前缀。

### 效率扫描与搜索

- 参数列表按拓扑适用性筛选；多路支路参数仍应在每路配置中编辑，不把一个顶层电容值误当成全部支路。
- 扫描最多 41 点、最少 5 点；目标查找显示目标值与扫描曲线，不达到时不提出虚假解。
- 多变量优化最多 3 个变量、1–20 次迭代、5–10 种群倍率，固定种子用于可重复探索。低预算未收敛时显示当前候选，不称为全局最优。
- 模型效率仅包含当前所建模损耗。改善效率候选仍须复查应力、磁饱和、温升、纹波及稳定性，不能凭最高 η 直接定型。

### 绕制编辑

可设置净窗口 mm 尺寸、留边、漆膜外径增量、同绕组层间绝缘、绕组间绝缘与线间隙。每个绕组可选疏绕、密绕靠左/靠右、普通铜线或利兹线，以及每匝分束数、束内填充系数和实测整束外径。

利兹线按原等面积假设默认宽×1.5、高÷1.5；单股/普通铜线不压扁。分束只分配已有电气总股数，不重复增加铜量。手动层序支持新增、拆层、删除、上下移动和同绕组跨非连续层；匝数分配不完整时显示错误，不误判成单纯窗口不够。

“评估/刷新截面”调用后端当前实际绕组。自动排层方案也取自后端，自动匝数尚未求出时不猜测容量。仅当结果对应当前几何配置时使用其容量；改变匝数/线径后先重新计算。所有几何设置应保存配置，正式报告读取重算后的有效设置。

### 评审与 A/B

固定硬件角点最多选择 8 个负载比例，全部支路同比例缩放。它与可选的独立负载组合交叉调整率是不同分析；失败点保留错误，最坏值只来自成功点，因此不能声称失败区域也被覆盖。

A/B 冻结真实已算摘要，不只冻结输入；后台重新计算不会清除已冻结 A。浏览器刷新前应导出 JSON。相同的 Vinmin/Vinmax 标签若对应不同需求，界面会提示不可直接判断优劣，比较时还应核对实际电压与负载条件。

## 4. 阅读与曲线操作

- 顶部字号选择 16、18、20，并在当前浏览器本地记忆。窄屏可从参数区访问字号设置。PNG 图内文字不是 Word 文字，不会因页面字号选择重新排版；可放大查看图表。
- 导入曲线弹窗可预览候选，已存曲线也可再次预览；Y 对数轴仅为预览选项，不改变原坐标数值。
- 预览显示当前保存的 SI 坐标；原图 n/u/m 等数量级仍须在导入时明确选择，不以曲线名称猜单位。
- 二极管只有在用户选择目标位号并确认后才复用曲线；需核对型号、温度和测试条件，不自动覆盖所有二极管。
- “公式说明”通过白名单本地接口下载项目内 Word 文档，用本机 Word/兼容软件打开，不上传到云文档服务。

## 5. 报告与尚未迁移的边界

当前 Word、Excel 继续按已经完成的正式快照导出，保持原来的 Vinmin/Vinmax、模块表格、图、检查与模型说明。MOS 时间轴选择也随导出传入。应用的补偿参考电路配置可沿用原报告的对应内容。

**本次新增高级角点与冻结 A/B 的表格、图表结果尚未追加进现有 Word/Excel 角点或对比章节。** 扫描/整定/优化未应用候选也不会自动出现在正式报告中；A/B 对比另有 JSON。浏览器有某个分析页面，不代表报告已增加该章节。

其他明确边界：

- 没有完全重做桌面的所有快捷键、辅助弹窗、批处理和历史报告组合；不称完全覆盖 EXE。
- 没有云部署、多用户隔离、自动项目数据库或持久保存。一个本机服务共用一个最新数值作业；其他标签页重算会使旧作业链接失效。
- 独立器件截图描点/PDF 提取程序未并入网页，网页负责导入其已有 CSV/JSON 数据。
- 没有 PCB 布局、热/电磁联仿或自动安规验证。所有已有物理近似、曲线外推限制与试验模型适用范围继续有效。
- 取消是协作式，不保证立即中断当前原生数值调用。数值计算、图表、报告和高级动作串行执行；低预算与按需绘图控制工作量，但不承诺所有机器/任意配置下的固定内存或实时速度。
