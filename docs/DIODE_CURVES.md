# 二极管正向曲线与导通损耗

## 导入和器件对应

在左侧独立的“器件计算方式与曲线”中，先在清单选择器件，再点击“导入 / 替换所选”。表内列出当前拓扑已启用且有独立损耗模型的二极管；导入对话框再次显示位号、输出路和用途。全局或逐项选择固定值时，已存曲线不参与损耗、但会保留；选择曲线却缺失数据时不静默回退。详见 [统一入口](DEVICE_CURVE_HUB.md)。

| 拓扑与用途 | 图上位号 | 使用的电流 |
| --- | --- | --- |
| 单路整流或 Buck 续流 | D1 | 该器件的周期 i_d(t) |
| 单路有源钳位正激续流 | D2 | 周期 i_free(t)，不与 D1 共用曲线 |
| 多路输出或 MP6005 PSR 整流 | D_O1…D_O6 | 对应 OUT 的实际周期整流电流 |
| 多路正激续流 | D_F1…D_F6 | 对应 OUT 的续流电流 |
| 共享输入防反 | D_IN | 脉冲输入 i_in(t) |
| 单路输出防反 | D_OUT | 电容之后的直流 I_out |
| 多路或 PSR 输出防反 | D_B1…D_B6 | 对应 OUT 的直流 I_out |

原边 RCD 钳位二极管 D_SN1 暂无独立器件损耗模型，不在此列。RCD 功耗仍按原钳位整体模型统计，不能把其导入为 D1 并叠加。

## 文件与数量级

只导入正向 If–Vf 特性：**X=Vf（V），Y=If（A）**，不是 Qrr、Cj 或反向漏电曲线。每条温度/测试条件曲线由用户命名区分，导入时选择其中一条，不自动混合。

CSV 仅需 x,y 两列；JSON 仅需 [[x,y],…] 点数组，也支持带名称的曲线集合。V1.3 提取程序已将 n/u/m 等数量级乘入数值，因此导入倍率 X/Y 都选 1。旧文件若保存原图 mV/mA 数值，才选择对应的 10^-3 倍率。

每条至少两个不同 If 的有效点。允许有限非负坐标；同电流重复点合并。按 If 排序后，允许最大累计 Vf 回退不超过原曲线 Vf 跨度的 3%，使用最小二乘单调拟合整理小幅描点噪声，不改变 If。界面、设计 JSON 和报告保留调整点数及最大 Vf 修正量，原 CSV/JSON 文件不修改。连续小步倒退也按累计回退检查，明显反向或错分数据仍拒绝导入。曲线与原文件名称、哈希一起嵌入设计 JSON；重开设计无需再次寻找 CSV，不根据文件名猜测器件绑定。

## 计算口径

有曲线时，对当前 Vin 和负载下每个正向电流样本，按相邻点对 If 反查 Vf，然后平均瞬时功率：

`Pcond = (1/Ts) ∫ Vf(If(t)) If(t) dt ≈ mean[If[k] Vf(If[k])]`。

这不同于用平均电流查一次压降。关断、反向电流不计入正向导通；零电流的功率严格为零。输入电流采用现有周期等步长波形，未额外模拟反向恢复尖峰。

低/高电流超出图线时按相邻端点的线性趋势外推，外推负 Vf 截为零；在界面、API 和报告中提示超出范围，不把外推解释为数据手册覆盖。

无曲线时采用 `Pcond=固定 Vf × Iavg`。动态电阻 Rd 已从输入界面、损耗和换流模型中停用；旧 JSON 的 Rd 键仅为兼容读取，计算为零，不再暗中叠加 `Rd × Irms²`。因此旧设计没有曲线时，最终损耗/效率可能与此前版本不同。

反向恢复仍按原 `Prr=Qrr × Vr × fs` 单列。导入 Vf–If 不提供 Qrr；没有结温迭代，典型曲线不等于最差条件额定值。

## 模型边界与报告

曲线仅用于损耗后处理，不直接改变占空比、波形、交叉调整率或 Bode。耦合周期/小信号仍采用用户固定 Vf 和几何 DCR；若需要二极管非线性同时参与多绕组换流，须另行改造事件求解，不用本次损耗估算冒充。

Vinmin/Vinmax 各自用对应电流重新计算，曲线和硬件不随输入电压自动更换。Word/Excel 第 3 模块增加器件位号、曲线名称、导通/恢复损耗、实际电流、来源、外推说明及原图坐标曲线，双输入版本保留两端对比。

公式依据：[ST AN604 Calculation of conduction losses in a power rectifier](https://www.st.com/resource/en/application_note/cd00003894-calculation-of-conduction-losses-in-a-power-rectifier-stmicroelectronics.pdf)，式 10 为周期平均瞬时功率。本软件使用分段线性曲线和周期采样近似，并非器件动态仿真。
