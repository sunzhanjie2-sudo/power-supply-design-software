# 有源钳位正激周期计算与精度复核

本模型用相同电路假设统一计算器与 LTspice：同一套匝数、完整 kij、几何 DCR、输入/输出防反压降、整流/续流、输出电感及物理钳位。它独立求解电路，不读取或拟合仿真结果。

## 使用入口

选择有源钳位正激与 SSR，在左侧启用“两两 kij 物理周期计算”。最多六路输出。只有所选反馈路为电压设定值，其他路由相同占空比下的电路和负载求得。关闭矩阵后使用明确标注的原标称近似；全部 kij=1 的奇异理想极限也回退至该近似，不伪造非理想解。

## 从输入到工作点

1. 按预设计选定磁芯、整数匝数、线径与股数，冻结硬件。DCR 由 ρ·MLT·N/A 得到，不随最终 RMS 自动换线。
2. 建立 Lii=Lp·(Nsi/Np)²、Lij=kij·√(Lii·Ljj)，正激 Lp 使用 Lm_forward。所有副边对之间的 kij 都参与，不是只取最小值或平均值。
3. 在周期内按主开关、死区、辅助开关、死区分段；用修改节点分析联立绕组 v=L·di/dt+R·i、每路 LO、主辅 Coss、二极管 Cj 及其 0.1 Ω 串联阻尼、钳位 C/ESR。理想开关的有限 Ron、MOS 体二极管及输出整流/续流的分段导通状态同时求解。
4. 联立周期状态重复 x(T)=x(0)、每路 ⟨iLO⟩=Vport/Rload 和唯一主反馈约束，求出整个周期状态、占空比和各路输出电压。负载电阻由匝比参考电压与指定功耗确定，并在对比和角点中冻结；实际功耗随未反馈路电压改变。
5. 电容端在该周期解中取恒定直流值。用每路实际 LO 电流减去负载电流，分别连接用户启用的 C+ESR/ESL 支路重建纹波，不把两个电容简单合并后丢掉 ESR 动态。

输出电压与负载均在防反二极管后；反馈取所选路的防反管前。预设效率继续保存为设计参考，但物理矩阵电路不再叠加等效效率压降，避免与显式损耗重复计入。最终效率仍是独立的器件、磁件和电容损耗估算；磁芯损耗、绕组 AC 增阻等尚未迭代回电路工作点。

## 环路

周期传播和平均输出电感电流对初值、电容端电压、占空比作解析分段灵敏度计算，将周期核转换成低频连续等效，再与各路每颗 C+ESR 支路联立。峰值采样核使用原边磁链与反射输出电感电流包络，排除恒定 Cj 的高频位移振铃，并包含 CS 低通状态。

人工斜坡与 SPICE 共用同一函数：支持沿用设计、工程自动建议、手动输入三种来源。自动建议仍为反射下降斜率的 0.75 倍，是工程起点，不是 MP6005 的实测内部斜坡。补偿器 KP、零极点不为贴合仿真自动修改。

只有所选一路反馈闭合，其他输出通过同一功率级参与动态。该模型用于低频设计，不包含真实光耦/TL431、CS 消隐、传播延迟、限幅与模式切换；高频需要实际 FRA。未验证的峰值或未出现的裕度不会填成零或无限大。

## 数值检查与资源占用

- 周期和电荷平衡采用归一化残差检查；能量账本另列数值耗散，不把隐式积分的误差当作真实损耗。
- 逐级加密周期网格。电压的最后两档差异超过 0.5% 时拒绝输出；高频绕组电流 RMS 的网格差异超过 2% 时保留已收敛的直流电压、标注电流仅供参考，并拒绝该角点的有效环路裕度。相邻网格差异是敏感性检查，不是对真值误差的严格上界。
- 最多保留 16 个电气周期解的缓存。BOM、热参数、补偿器或图表变化不会重复计算不变的电气周期；缓存键保留电压、负载、全部互感与物理参数。计算仍在原后台任务中执行并响应取消。
- 阶跃前增加 8 ms 长窗口、16 个时间加权均值分箱，分别检查漂移和低频摆幅；不会仅凭两段很短的平均值相同就认为启动结束。未通过时不发布有效标称偏差和 FRA。固定时间导出的独立 ASC 仍按用户的阶跃时刻运行；此检查不会暗中移动激励。

## 已完成的参考复核

以 `examples/33W_3OUT_ACF_MP6005.json` 为例，对照原 20/30 V 实际 LTspice 数据。功率级、两两互感、两份器件库和全部电气参数逐项相同，因此保留真实 .meas、FRA 复数数据及 16 个角点，只重算独立预测。修订前计算也保留在新证据 ZIP，报告没有改写仿真值。

结果与误差明细在 `output/ACF_计算精度复核_20261028/`。原 33 W 反激转正激示例的骨架窗口不足仍保留；数值模型不能代替可绕制评估和硬件审核。此前的启动排查也仍成立：静态角点收敛不是启动过冲/掉压合格。

## 仍需器件资料或实测的部分

当前对照电路的二极管为固定 Vf+Ron+恒定 Cj，MOS 为理想定时开关、Ron、常数 Coss 和等效门电容；数据曲线损耗估算不等同于完整晶体管/整流管 SPICE 模型。真实非线性电容、温度、反向恢复、驱动寄生、控制器 PSM、芯片启动供电、磁饱和和 PCB 寄生仍未完整覆盖。输出电感在本次对照中保持与原 SPICE 一致的理想 L，未含它的 DCR。

开通重叠损耗仍采用保守栅电荷法，使用代表性的反射负载电流；不因理想开关刚开通瞬间电流小或为负就自动赋予 ZVS 收益。原通用补偿器软启动时变钳位尚未完整跟踪到积分状态，不能把其启动曲线认定为真实 MP6005 的必然表现。
