# MOS 米勒平台与曲线导入

## 2026 年 10 月 20 日更新

平台和栅电荷的导入、预览及来源切换已集中到左栏“器件计算方式与曲线”。Q1 两行分别标明 X=Vgs/Y=Id、X=Qg/Y=Vgs。可全局选择固定值或曲线，也可逐项混合；切换不清除数据，待导入不会静默回退。详见 [统一入口](DEVICE_CURVE_HUB.md)。

手动模式改为左侧四行独立输入：Vinmin 开通、Vinmin 关断、Vinmax 开通、Vinmax 关断；每行有 Vgp / V 与 Qgs / nC。实际电流由电路计算，按“四工况”查看。两个电压相同但手动参数不同，仍分别计算 MOS 损耗。报告与波形使用相同事件数据，保留 XLSX 的 LN 时间公式。

### 推荐简洁曲线文件

文件不需要物理量名称、单位、测试电流、测试电压、温度或 schema。单条 CSV 只需两列，可以有 x,y 表头，也可以没有表头：

```csv
x,y
0,0
5.2,4.4
7.3,4.4
15,10
```

相同的 JSON 可以只有 `[[0,0],[5.2,4.4],[7.3,4.4],[15,10]]`。多条曲线也支持 `{"curves":[{"name":"曲线一","points":[[0,0],[5.2,4.4],[7.3,4.4],[15,10]]}]}`。

示例仅说明结构，不是真实器件数据。①入口将 X/Y 解释为 Vgs/Id，②入口解释为 Qg/Vgs；导入时由用户选择数量级。例如 Qg 图的横轴原数值为 nC，选择 X=10^-9、Y=1。同样的文件格式不表示两类曲线可以混用，坐标含义由导入入口确定。

简洁格式按线性趋势插值和外推。②入口会建议平台起止点，用户可修改；这两个位置仍是区分 Qgs 与 Qgd 的依据，不能只靠两端点推断未观察到的平台。需要保留对数插值、Vgs 分组与完整测试元数据时，仍可使用下文旧版带条件格式。保留提取工程可追溯原图、标定和描点整理过程。

提取程序 V1.2 默认输出简洁 CSV / JSON，自命名即可。Qg 图从高栅压端反向追踪独立支路，共用前段不额外计数；微小像素倒退用单调整理，明显倒退仍要求核对。真实图例、同色交叉和大段遮挡仍可能影响曲线身份，导出前须校核。

## 新增 Vgs Qg 电荷曲线

左侧“栅电荷来源”新增 **Vgs–Qg 曲线直接读取**。此时不使用手动 Qg、Qg(th)、Qgs、Qgd 或等效 Cgs；这些手动草稿在界面隐藏。平台来源仍可手动输入，或导入电流曲线计算。

必须区分两类曲线：

| 导入位置 | 原图坐标 | 用途 |
| --- | --- | --- |
| ① 电流–栅压 | 横轴 Vgs、纵轴 Id；或带 Vgs 标签的 Id–Vds 曲线族 | 按每个事件实际电流求 Vgp |
| ② 栅电荷 | 横轴 Qg、纵轴 Vgs，标出平台起止电荷 | 从 Vgp 反查 Qgs，并读取 Qg(th)、Qgd、总 Qg |

按用户指定，不同电流复用所选的同一条 Vgs–Qg 参考曲线。平台前支路的反函数记作 Fpre，平台后支路为 Fpost：

- Qg(th) = Fpre(Vth)。
- Qgs,on = Fpre(Vgp,on)，Qgs,off = Fpre(Vgp,off)，只用平台前上升段。
- Qgd = Qplateau,end − Qplateau,start，不是从零到平台的 Qgs。
- Qg,total = Fpost(Vdrive)，只用平台后上升段。

Vinmin / Vinmax 分别计算开通与关断事件，共四组电流、Vgp 和 Qgs。左侧“四工况”按钮可后台并列核算，修改参数后旧结果清除；Word 与 Excel 概览也列出四事件。Qgd、Qg(th)、总 Qg 在复用同一参考曲线时可能相同，不强制产生四个不同值。

Vgp 超过参考平台前支路时，沿该支路末端的线性趋势延长；不会读取平台后支路冒充 Qgs，也不改回等效 Cgs。总 Qg 在平台后支路按相同规则外推。实际使用外推时在界面读数和报告中提示；估算负电荷取零下限，驱动电压不高于平台等物理不成立的条件仍需检查。

### 栅电荷文件格式

独立提取程序 `<本机路径，不随源码分发>` 选择“MOS 栅电荷曲线 Vgs–Qg”，标定 Qg / nC 与 Vgs / V，逐条确认测试 Id、VDD 及平台两端，校核后自命名导出 CSV + JSON。图上不同 VDD 的曲线须明确选一条，不自动混合。VDD 是规格书的栅电荷测试电压，不是电源 Vin。温度未注明可留空，保存为 null，不默认 25°C。

旧版带条件 CSV 的七列（仍兼容；新默认简洁格式见本文前面的说明）：

```text
Qg_C,Vgs_V,Tj_C,Id_test_A,Vds_test_V,Qgs_ref_C,Qplateau_end_C
```

JSON 使用 `schema: power-design.mos-gate-charge.v1`，包含 `points: [[Qg_C,Vgs_V],…]`、`Id_test_A`、`Vds_test_V`、`Tj_C`、`Qgs_ref_C` 和 `Qplateau_end_C`。集合格式为 `power-design.mos-gate-charge-collection.v1`，`curves` 内放多条完整曲线，导入时人工选择。它与平台电流曲线 schema 不同，不能互相导入。

测试 Id、VDD、Tj 和原文件 SHA256 随设计保存并进入报告。不同电流复用同一参考曲线是工程近似；不会根据电流或实际 Vds 自动重建 Qgd，亦未修正温度、寄生参数或反向恢复。

下文“等效 Cgs”只用于未导入栅电荷曲线的旧模式。

## 操作方式

左侧③ MOS 与整流器件 → 米勒平台来源，常规使用两种模式：

1. **手动四事件 Vgp / Qgs**：在左侧四行表分别填写 Vinmin 开通、Vinmin 关断、Vinmax 开通、Vinmax 关断的平台与零伏至平台电荷。Qg(th)、Qgd、总 Qg 为公共参数；选曲线电荷时四行 Qgs 草稿停用，按各自 Vgp 查曲线。旧文件将原平台和 Qgs 复制为两端初值，之后可独立修改。
2. **导入曲线查值**：导入 CSV / JSON，按当前电路实际 Id,on 与 Id,off 分别查出近似平台。切换 Vinmin / Vinmax 后更新读数、时间、损耗和波形。输出曲线族还需填写 `Vds,read`。

左侧实时显示换流电流及查得平台。更改输入后清除旧读数，待新计算完成再显示。曲线点及来源信息内嵌保存在设计 JSON，换电脑不用寻找原文件。导入失败或取消选择不覆盖现有曲线；“清除曲线”仅清除当前设计数据并切回手动，不删除原文件。

## 哪种曲线可以使用

- **Id–Vgs 转移曲线**：直接按电流反查 Vgs。须记录温度、测试 Vds 与脉冲条件，使用覆盖实际换流电流的单调数据。
- **Id–Vds 输出曲线族**：至少两条标明 Vgs 的曲线。用户指定固定 `Vds,read`，在各条曲线上读取 Id，再从 `(Vgs, Id)` 切片反查 Vgs。单独一条 Id–Vds 曲线不能唯一确定平台。
- 静态/脉冲曲线得到的是**栅压近似**，不保证等于动态栅电荷测试中的米勒平台。固定 Vds 切片不是对实际整段 Vds 摆幅的模拟。须结合栅电荷曲线、温度、驱动和实测校准。

不同温度、测试 Vds 或脉冲条件的数据不要混为一条曲线。目前不自动做温度修正，也不自动选最接近条件。器件提取程序 JSON 含多条转移曲线时，弹窗要求明确选一条。

## 旧版带条件 CSV 格式与单位

UTF-8（允许 BOM）、逗号分隔，首行表头大小写如下。电压为 V，电流为 A；可附同一数值的 `Tj_C` 列。

转移曲线：

```csv
Vgs_V,Ids_A,Tj_C
3.5,2,25
4,5,25
4.5,8,25
```

输出曲线族（每个 Vgs 至少两个 Vds 点，总共至少两个 Vgs 分组）：

```csv
Vgs_V,Vds_V,Ids_A,Tj_C
4,1,3,25
4,2,5,25
5,1,7,25
5,2,12,25
```

CSV 默认线性坐标。需对数插值时使用下面的 JSON，明确设置坐标类型。不要把图上的 mA 数字直接写入 `Ids_A`。`examples/MOS_CURVE_DEMO_TRANSFER.csv` 与 `MOS_CURVE_DEMO_OUTPUT_FAMILY.csv` **均为虚构格式/回归示例，不对应真实器件，不得直接用于设计或选型**。

## JSON 与器件提取程序

自有规范转移曲线示例：

```json
{
  "schema": "power-design.mos-miller-curve.v1",
  "kind": "transfer",
  "name": "器件与曲线名称",
  "conditions": "请填写真实测试条件",
  "Tj_C": 25,
  "Vds_test_V": 20,
  "x_scale": "linear",
  "y_scale": "linear",
  "points": [[3.5, 2], [4, 5], [4.5, 8]]
}
```

以上点同样只是格式示例。`points` 顺序为 `[Vgs_V, Ids_A]`。输出曲线族改为 `kind: "output_family"`，以 `traces` 代替 `points`：

```json
"traces": [
  {"Vgs_V": 4, "points": [[1, 3], [2, 5]]},
  {"Vgs_V": 5, "points": [[1, 7], [2, 12]]}
]
```

族内点顺序为 `[Vds_V, Ids_A]`。`x_scale`、`y_scale` 各可为 `linear` 或 `log`，须按原图设置；对数轴不允许零值。族内各条曲线使用同一套坐标类型，在 Vgs 标签之间的反查为线性插值。

支持 `semiconductor-datasheet-studio` 导出的 MOSFET 器件 JSON 中 `mosfet_transfer` 曲线，要求轴量为 Vgs / Ids；支持明确的 V/mV、A/mA 单位换算。多条候选曲线逐条选择，不合并。该程序当前的输出曲线条件是自由文本，不能可靠自动解析 Vgs，因此输出曲线族请先整理为上述三列 CSV 或规范 JSON。这里导入的是已数字化数据，不直接解析 PDF 或截图。

导入记录原文件名及 SHA256，保留可用页码、条件、温度等元数据，报告记录同一来源。原本的本地 PDF 路径不会随曲线传播。来源摘要不代表数据经过厂家认证。

## 时间与电荷计算

普通硬开关开通电流取 `max(I_sw_on, 0)`，关断取 `abs(I_sw_off)`；未显式提供时退回电感谷值/峰值。有源钳位正激采用主开关边沿电流，不使用输出电流代替。QR 保留既有理想谷底开通损耗减免，关断用原边峰值。不额外增加未建模的反向恢复或位移尖峰电流。

曲线模式得到 `Vgp,on = F(Id,on)`、`Vgp,off = F(Id,off)`。精确零电流取 Vth 作为数学极限，不假称零负载有真实平台。

未导入 Vgs–Qg 的旧模式中，`Vgp_on` 输入改名为 `Vgp,ref`，与 `Qgs,ref`、`Qg,th` 必须取自同一条栅电荷曲线。它不是本工况的实际开通平台。阈值以上等效 Cgs 近似：

`Cgs,inc = (Qgs,ref − Qg,th) / (Vgp,ref − Vth)`

`Qgs,on/off = Qg,th + Cgs,inc × (Vgp,on/off − Vth)`

继续使用用户确认的 XLSX 自然对数时间公式。t2 用开通 Qgs、Vgp；t3 用开通 Vgp；t6/t7 用关断 Vgp，t7 用关断 Qgs。t1/t8 仍使用 Qg,th。总栅阻仍含驱动器、外部和内部栅阻。

t4/t5 使用 `Qg − Qgs,on/off − Qgd`；剩余电荷不为正时显示对应时长未知，不伪造正数，不计入交叠损耗。Word 原生公式和 Excel 两端数据均来自相同结果，不另算一套平台。

## 校验与限制

- 文件不超过 5 MiB，每条曲线至少 2 点，总点数不超过 20000，输出族最多 100 条。所有数字有限且非负。重复坐标、含多种温度、非单调数据明确报错，不自动拟合或平滑。
- 反查要求电流严格随 Vgs 递增，不能有多义平台/重复电流值。输出族的 Vds 切片也须满足此条件。
- 默认支持端点趋势外推，包括转移曲线的电流反查、输出曲线族的固定 Vds 截面，以及平台前后电荷支路。范围外结果在界面和报告中标注，不宣称实测；内部规范可设置 allow_extrapolation=false 禁用。
- 栅电荷参考点须 `0 < Vth < Vgp,ref < Vdrv`、`Qgs,ref ≥ Qg,th ≥ 0`。正电流的自动平台须高于 Vth、低于 Vdrv，驱动不足时明确报错，不限幅掩盖问题。
- 曲线状态仅声明导入类型、条件与范围内查值，不构成实测验证。旧模式的 Qg/Qgd 仍取手动常数；新电荷模式改为所选参考曲线读取。Coss、Rds(on) 仍取输入常数。未模拟完整电压/温度依赖、源极寄生电感、恢复、雪崩或完整 ZVS。

## 旧配置兼容

缺少 `mos_miller_mode` 时按旧规则：gfs=0 为固定平台，gfs>0 为 `Vgp = Vth + Id/gfs` 及上述等效 Cgs。旧跨导模式仅在加载对应设计时显示，可切换到手动或曲线。新文件若明确手动/曲线，则残留 gfs 不参与计算。

旧有效跨导近似参考：[TI SLUA618A](https://www.ti.com/lit/ml/slua618a/slua618a.pdf)，第 2.3 节式 (8) 及第 2.5–2.6 节。曲线查值同样是工程近似，不承诺等于真实动态米勒平台。
