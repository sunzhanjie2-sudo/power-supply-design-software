一、工具简介
────────────────────────────────────────────
本工具按参考书的设计流程组织, 支持六种拓扑:

  • BUCK (降压)        • BOOST (升压)
  • BUCK-BOOST (升降压) • FLYBACK (反激)
  • FLYBACK-QR (准谐振反激, BCM/谷底开关, 变频)
  • ACF-FORWARD (有源钳位正激, 低侧钳位, 双二极管次级)

界面最多十个标签页，①拓扑首页、②至⑨设计流程与⑩工程评审；不适用页面隐藏，保留流程编号，并内置
对应的设计检查(电容纹波电流 / 器件应力 / 磁件饱和与温升 / 环路稳定)。

说明: 功率级参数(L、C_out 等)由用户自行输入 —— 本工具不做"自动
设计", 而是提供公式与检查, 让用户亲手验证计算。

运行方式:
  • 源码: 在项目目录执行  python main.py
  • 打包版: 双击 dist/Multi_output_loop_update/SwitchingPowerSupplyDesign_V0/ 中的 exe，保留 _internal。
  • 自检:   python tests/quick_check.py
配置导入/导出: 菜单 文件 → [保存配置] 写入自命名 JSON; [打开配置] 从 JSON 恢复全部参数(含单位)。旧 RCD K、Kc、ΔC 与新 coupling_config 分开保存；K 的历史漏感定义不是 kij。顶部 [导出报告] 或 Ctrl+E 可选择完整 Word 工程报告、Excel 模块对照报告或 Markdown 摘要。Excel 每个适用模块一张 Sheet，左 Vinmin、右 Vinmax，包含同源图像及数字表格，是不会自动重算的报告快照。帮助菜单只保留《计算方法与公式说明》。

报告保留逐路表与支路波形，MOS 时间轴选项继续生效；打印时分组排版，t1–t8 时长、来源和补充估算限制随图记录。波形、钳位和所用计算模式保持一致；GUI 卡片布局不等于报告分页。

资源与响应：图表按当前页面/滚动视口绘制，移出视口释放可重建的图像缓冲，滚回后显示最新计算结果；连续输入/缩放合并刷新。数值缓存最多 3 项、估算共 64 MiB，超大结果正常计算但不缓存；这不是整个程序的内存上限。数值库默认单线程，仅影响本进程，保留用户显式的库线程环境设置。首次进入⑤环路或⑩评审按需加载环路库，拓扑首屏不再后台预加载；环路检查在这些页面完成前显示待算，不会默认视为通过。计算公式、波形采样及报告图表质量均不降低；复杂耦合求解仍需时间，可取消过期计算。详情见 docs/PERFORMANCE.md。

规格区预设效率 eta_guess（0~1，默认0.93）。原标称模型按 Pin,est=Po/η₀、U=Vo/η₀、Req=R/η₀ 求工作点，实际 Io=Po/Vo 不变；最终按损耗另算效率，不覆盖预设。矩阵模式中预设仅用于初值/设计参考，物理方程不再叠加等效效率压降，以免与显式电阻、二极管和钳位损耗重复计入。电容 ESR 等附加估算仍列入最终总损耗，矩阵 RL 周期能量平衡不是完整实物损耗平衡。

工程评审版（2026-10-09）：启动默认40W CCM反激，30V→30V、250kHz、Lm=8µH，保留附件的补偿及钳位，不自动整定。仅内置扫描范围修正为50–500kHz。
左栏支持参数搜索、基础/高级显示、点击分组标题折叠。温升评审上限可编辑（默认40K）；GUI/API/Word共享检查口径。
Word报告新增⑨页当前补偿网络、阻容、参考图、原生公式及全部零极点回代对照；负电容、近似抵消与未匹配目标明确提示，不写回⑤页。多路输出电容详细结果统一放在第4节，各路RMS/损耗与FFT只列一次，支路电压纹波仍保留。

   隔离拓扑另有“变压器可绕制评估”子页：按骨架图输入单侧净窗宽 W / 高 H（mm），
   不能用磁芯 Wa 面积代替。读取磁件结果中的实际匝数、电气总股数和裸径，逐绕组配置
   单股含漆外径、线材类型、并绕束数、每层匝数、疏绕/密绕靠左/密绕靠右与内外顺序。
   每束多股线画一个等效截面，同匝的多束保持一组；总股数=束数×每束股数，不能重复乘股数。
   利兹线默认宽×1.5、高÷1.5，保持整束包络截面积；单股铜线不压扁。填充系数默认0.75
   仅为可编辑估算，优先输入实测整束未压扁外径；多股但非利兹线应手动选择不压扁圆线束。
   压扁后束高不能小于单股含漆线径；整束面积下界和束高检查只是必要条件，不保证真实堆积可行。
   可设置留边、层间/绕组间绝缘和束间隙；横纵等比例，显示叠高、余量及超宽/超高。
   挡墙仅在净窗口外示意；等效束截面超过12000个或总物理层数超过256时简化绘图，
   手动保留逐层带状顺序、自动显示绕组整体包络；数值仍覆盖全部层数及电气股数。
   旧配置显式非零束列数沿用旧矩形束，不与新线束字段混用；切换新模型先清除旧列数。
   勾选“手动物理层序”可让同一绕组出现在第1、3等不连续层；逐层编辑匝数和疏密绕，
   并可新增、删除、拆层或上下移动。全部当前有效绕组都要分配，各层匝数之和必须等于
   对应绕组实际总匝数，每层不超容量及非零的每层匝数上限，最多1000层。
   相邻同绕组用层间绝缘，不同绕组每次用绕组间绝缘；P–OUT1–P有两处绝缘界面。
   关闭手动后界面保留草案，但保存的有效layer_plan为空；要保存草案需重新启用手动。
   Word同步逐物理层表和截面，不生成跨线/端部连接，也不自动降低漏感或更改kij。
   该几何评估不回写DCR、漏感、kij或铜损；可放下不等于满足安规或可量产。
   设置以SI长度保存在JSON的winding_config中；有效窗口与变压器结果同步加入Word报告。
   未填写窗口时不猜测尺寸、不输出绕制结论。完整步骤与限制见docs/WINDING_WINDOW.md。

⑧ RCD吸收 (钳位)  只读显示反激/准谐振反激原边漏感的 RC 钳位。左栏②输入历史漏感系数 K
   (Lσ=(1−K)L，不是 kij)、钳位比 Kc=Vc/Vr、钳位电压波动比例 ΔC。
   快速模型以漏感/常数Coss首波瓣估算尖峰，到达钳位后按(Vc−Vr)/Lσ复位；
   矩阵模式用实际周期Vds与钳位电流。零漏感不画假尖峰，能量不足时不假定钳位导通。
   稳态平台、物理峰值和工程选型裕量分开；不把峰值画成整个关断区间的平台。
   P_res=average(Vc·iclamp)只记一次；R=Vc²/P_res，C≈P_res/(fs·Vc·ΔVc)。
   Vclamp(t)为小纹波RC近似，非完整暂态电容模型；不含二极管恢复与寄生振铃。
   栅极电荷法t1–t8保持不变，钳位复位超出t8时单列“钳位恢复”，不改变t7/t8。
   正激切换为有源钳位核算；非隔离拓扑隐藏本页。
   饱和或温升超标时页面红色提示。

⑨ 环路补偿参数  仅 SSR 显示，由⑤页整定的 KP/零点/极点反推实际补偿网络阻容值。
   MP6005 PSR 隐藏本页，物理 COMP 在左栏配置并在 MP6005 结果区核算。
   四种拓扑: 普通运放三型 / 跨导运放三型 / TL431+光耦三型(无快车道、
   快车道两种, 公式参考 TND381-D)。已恢复原版元件计算。
   “二型简化支路”独立勾选：运放C2=C3=0，跨导C1=C3=0（需填R1）。
   此简化支路不含标准二型高频极点，不能视为与⑤type2完整一致。
   只需输入少量初始阻容(分压/LED电阻/光耦CTR与结电容), 其余全部解出;
   结果附KP回代校验（不保证所有零极点匹配）与提示(光耦极点≥10×fc、TL431偏置、
   快车道高频增益地板警告)。

⑤ 环路设计  (书 ch.8/9)
   Gvc / Gc / 开环 Bode 图, 相位裕度/增益裕度/穿越频率;
   K因子自动整定: 输入目标 fc 与 PM → [自动整定] 写回补偿器参数。
   控制器选项 auto/type2/type3；显式选择不受VM/PCM覆盖，保留原版五项输入。
   auto保留旧行为: PCM→二型，VM→三型；控制器类型随JSON配置保存。
   二型为原点极点+一个零点+一个有限极点；三型为三极点（含原点）+两零点。
   旧PI配置迁移为auto，需要重新整定。补偿元件反向缺失角点仍用1GHz占位。
   反激峰值电流模式: 内环含 Fi=Rs·A_sense, 环路增益与 Rs·A_sense 成反比
   (Rs 翻倍 → 开环 -6dB); 新参数 A_sense(采样放大倍数) 与 ma(斜坡补偿)。
   注意: Boost/反激有右半平面零点 (RHP zero), fc 必须远低于它;
   DCM/BCM 工况采用低频单极点近似，未建模完整采样动态。

⑥ 效率 & 优化  (书 ch.3)
   损耗分解柱状图 + 效率-负载曲线 + 参数扫描/查找目标/差分进化优化。
   注意: 计算η仅计入半导体/磁件/电容ESR/采样/RCD/输入输出防反二极管(如启用)损耗,
   未计温度效应(热态Rds增大)、
   辅助与控制电路、输入整流桥、PCB/EMI滤波、其它吸收电路、绕组邻近效应等附加损耗
   —— 效率为模型估算，并非最终实物效率（误差需实测确定，不保证固定百分点或实测上限）。

⑦ 电容电流纹波
   输入/输出默认各 2 个并联电容(每个有 C、ESR、ESL, 可关掉第二个)。对输入电流、
   输出电流做傅里叶分解：整周期采样按全 DFT 频点分流，Parseval 校核能量；
   非整周期采用平顶窗近似。各频点按阻抗 Z=R+j(ωL−1/ωC) 分流后汇总至谐波频带。
   输出电压纹波按两电容并联阻抗 Z1∥Z2 共同计算。
   多路时共享输入电容只列一次，再依OUT显示各路输出电容的总RMS、
   每颗电容各频带RMS与ESR损耗，使用右侧滚动条浏览，不按主反馈筛选。
   两电容相位不同会形成环流(个体电流可大于总额)。共享输入损耗不重复累计。

绕组耦合实验模型（固定频率 SSR 反激）：
在⑦勾选“启用绕组耦合矩阵计算”，填写每对kij；DCR由MLT/匝数/线径/股数自动计算，默认关闭。
一个原边+三路输出共6对，一个原边+六路共21对；副边之间的k也要填写。
Lp为其它绕组开路时原边自感。优先实际Np/Nsi，否则由N和目标电压生成固定设计匝比。
Lii=Lp/(Np/Ni)²，Mij=kij√(LiiLjj)。对称矩阵需物理半正定，本版数值求解要求正定。
全部kij=1显式回退理想标称模型，不声称电流分配唯一；其它奇异组合报错。
负载R=V目标²/P额定。主反馈直流稳压，未反馈路实际V/P允许偏离需求；支路可以局部DCM。
按完整RL/二极管/理想定压钳位求周期电流和平均电容电荷平衡，不按功率比例复制波形。
输出电容在周期内视为恒定直流，未模拟大纹波、启动、负载阶跃和控制器动态。
矩阵不含Coss/Cj、恢复及寄生振铃；几何DCR与损耗使用同一硬件，不重复计铜损。
任意互感矩阵不能唯一识别公共磁芯磁通，B(t)、饱和与磁芯损耗仍是工程参考。
⑤环路不再套用原标称Bode；基于当前周期解后台建立低频实验模型，保留唯一主反馈和各路独立电容。

五、计算方法核验 (V0.0.0)
────────────────────────────────────────────
本版本对照参考书与厂商应用笔记核验了以下计算:
  • CCM/DCM 占空比与电流: Erickson ch.2/5 (能量守恒推导);
    Buck DCM 占空比 D=√(2·Io·L·Vo·f/(Vin·(Vin−Vo))),
    所有拓扑先取 U=Vo/η₀、Pin,est=Po/η₀、Req=R/η₀；反激 DCM 按 ½L·Ipk²·f=Pin,est 求解。
  • 输出电容: 电荷纹波 + ESR 纹波双约束 (TI SLVA477/SLVA630A),
    纹波电流 RMS 与 ESR 损耗直接由 i_c(t) 计算。
  • MOSFET/二极管损耗: 导通 + 开通/关断 + Coss + 栅极 + 反向恢复
    (Infineon/MCC 损耗计算应用笔记的简化形式)。
  • 磁件: 面积乘积法、Steinmetz/NSE(式 3.23~3.25)/iGSE 磁损(按
    波形自动选择)、集肤效应 Dowell 近似、饱和按真实峰值磁密 Bpk=L·Ipk/(N·Ae)(安匝关系)
    Bpk=L·Ipk/(N·Ae) 校核 (Erickson ch.10~12)。
  • 环路: Venable K 因子、相位裕度/增益裕度 (Erickson ch.8/9)。
自检脚本 tests/quick_check.py 含 60+ 项数值断言(含 DCM 能量守恒
与饱和磁密回归项), 全部通过后工具才可交付。

六、常见问题 (FAQ)
────────────────────────────────────────────
Q1. 为什么 Buck 12V→5V、4.7µH@100kHz 显示 DCM?
A. 该工况电流纹波 > 2×负载电流, 确实工作在 DCM, 这是正确物理结果;
   增大 L(如 22µH)即可进入 CCM。

Q2. Boost/Buck-Boost 自动整定提示"不可行"?
A. 这两类拓扑有右半平面零点 (RHP zero), fc 必须远低于 RHP 零点频率
   (通常 fc < 1/5~1/10 f_RHP)。把 fc 目标调低即可。
   反激的 RHP 零点仅存在于 CCM 模式, 公式 f_RHPZ=Vin*(1-D)/(2*pi*Lp*Io*n)
   (n=Np/Ns); DCM 与准谐振 BCM 模式均无 RHP 零点。⑤ 页 Bode 的对象传函
   在 CCM 用 CCM 模型 (双极点+ RHP 零点), 在 DCM/BCM 用单极点 DCM 模型
   (不含 RHP 零点, Erickson 表 15.3 近似) —— 程序已按运行模式分别处理。

Q3. 磁件页显示"饱和"或"温升超 40K"怎么办?
A. 饱和: 增大磁芯/降低 Bmax/增加匝数; 温升: 换更大磁芯、降低
   损耗(电流密度 J (A/mm^2)、频率、磁通密度)或加强散热 (h 提高)。
