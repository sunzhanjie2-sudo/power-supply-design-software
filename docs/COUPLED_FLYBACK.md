# 多绕组反激：两两耦合与 Vds 钳位

更新日期：2026-10-16。适用固定频率 FLYBACK + SSR 的实验性稳态模型。它用于研究漏感换流、轻载支路提前截止及交叉调整趋势，不是 SPICE 替代品，也不是已完成硬件验证的电路模型。

## 1. 如何启用

1. 在左栏①需求与方案选择反激；启用 1–6 路，选择主反馈 OUT，只输入该路电压和各路额定功率。
2. 在左栏⑧反馈与补偿选择 SSR 及主反馈 OUT。
3. 完成各路整流器件、电容和⑦绕组配置。建议填写实际 Np、各路 Ns；自动匝比只是设计起点。
4. 在左栏⑦磁件与温升填写 MLT、匝数、裸铜线径和并绕股数。其他输出电压由实际副边匝比更新；DCR 自动显示。展开“绕组两两耦合 / 漏感（实验模型）”，勾选启用，只填写两两 kij。
5. 左栏②设置钳位比 Kc>1。钳位电压还必须高于所有输出的目标反射电压，否则计算会要求提高 Kc。
6. 重新计算，先检查收敛、能量与电荷平衡，再查看各路实际电压、支路电流、局部 CCM/DCM、损耗和电容纹波。内容较长时使用结果页纵向滚动条。

矩阵默认关闭，保留原 40W CCM 单路反激启动配置。关闭矩阵恢复原标称快速模型，不抹掉耦合草稿。QR、MP6005 PSR、有源钳位正激及非隔离拓扑不启用此求解器；切换后相关输入隐藏且不参与计算。原 SSR 标称 Bode 不能用于证明混合导通模式稳定。⑤页改为按当前周期解建立低频实验性线性化，可查看唯一主反馈回路和各路参考/负载响应；不再隐藏整个环路页，详见 [多路环路说明](MULTI_OUTPUT_LOOP.md)。

## 2. 应该输入什么

| 输入 | 含义与使用方式 |
|---|---|
| 原边 L（启用时视为 Lp） | 原边自感，即其它绕组开路条件下的自感；不能同时当作另外独立的励磁支路和漏感重复加入 |
| Np、各路 Ns | 使用已解析的实际整数匝数；旧 Ns=0 文件用原电压比例初始化匝数后保存。非反馈电压=反馈电压×副边匝数比，求解时不随实际电压重算匝比 |
| P ↔ OUTi、OUTi ↔ OUTj 的 kij | 正向同名端约定下的两绕组耦合系数。输入 0–1，kij=kji，对角线固定为 1 |
| MLT、裸铜线径、股数及 ρ | 自动求 DCR=ρ×MLT×匝数/(股数×πd²/4)，不手填 DCR。MLT=0 时取所选磁芯目录估计；旧 JSON dcr 不再覆盖几何电阻 |
| 主反馈 Vout、各路 Pout | 仅主反馈电压为设定。其他路近似电压按副边匝比推算；Rload=V近似²/Prated，是固定电阻，不是恒功率负载。实际非反馈电压由电路求解 |
| Kc、ΔC | 定义有限电压的理想 RCD 钳位及电容纹波初选；不是完整二极管恢复/电容纹波参与的暂态钳位模型 |

一个原边加三路输出共 4 个绕组，需要 6 个独立 kij；一个原边加六路输出共 7 个绕组，需要 21 个独立 kij。输入包含副边与副边之间的耦合，不只包含原边与副边。当前矩阵不另增加 MP6005 辅助采样绕组。

界面初始 kij=0.995 是可编辑占位，不是所选磁件实测值。应结合实物结构、测量或可信电磁仿真修正。DCR 由输入几何自动计算，不再使用统一 20mΩ 占位；MLT、引线、端接和温度等假设仍需复核。自动线径先按标称电流预设计并冻结，再用物理解的实际 RMS 更新 J 和铜损，避免重新选线造成工作电阻与图表不一致。

## 3. 自感、互感和物理检查

内部先确定每个绕组的自感，再构造完整矩阵：

    Lii = Lp / (Np/Ni)²
    Mij = kij · √(Lii · Ljj)
    v = L · di/dt
    W = ½ · iᵀLi

这版只接受统一同名端定义下的正 kij。绕组电路方向由反激接线处理，不能通过随意填写负 k 模拟反接。

仅保证每个 kij≤1 不够：完整对称矩阵必须半正定，才能避免出现负磁储能。本版数值求解要求正定矩阵，另外显式支持“全部 kij=1”的理想极限；其它奇异或近奇异组合会给出错误，不会悄悄改 k 或加假漏感。

全部 kij=1 时，采用实际整数匝比下的理想变压器标称模型并明确提示回退；不求逆奇异矩阵，也不声称零阻抗理想模型能唯一分配各路电流。非反馈电压随该匝比定义，不再施加互相冲突的独立目标。理想回退没有漏感尖峰和 RCD 漏感功耗，器件选型仍应保留独立裕量。

矩阵显示的原边等效短路漏感为：

    Lσ,p = Lpp − Lps · Lss⁻¹ · Lsp

它只是所有副边端口短路条件下的参考值，不是各漏感简单求和。两绕组特例为 Lp(1−k²)。不要把它与历史 RCD K 的 Lσ=(1−K)L 混用。

## 4. 计算过程与结果含义

求解器逐段处理 MOS 导通、关断钳位和各路二极管导通/截止，电流由整个自感/互感矩阵、电阻、输出电压和钳位共同决定，不再按输出功率比例分配同一条三角波。

在一个开关周期内，各路电容直流电压被视为恒定，但通过求解周期边界与平均电荷平衡确定这些电压：

    i(T)=i(0)
    average(iD,j)=Vactual,j/Rload,j
    Vactual,main=Vtarget,main

主反馈路由理想直流稳压约束确定占空比，其它输出电压由电路得到。因此未反馈路的实际 Vout 和 Pout=Vactual²/Rload 可能偏离匝比近似电压和额定功率，不应把近似值强行覆盖回结果。主路稳压是稳态边界，不等同于已模拟控制芯片、补偿器和动态反馈环路。

全局 CCM/DCM 参考原边磁链/Lp 对应的电流；支路局部 DCM 表示该路在能量传输区间提前截止，不是因为它在原边 MOS 导通期间正常为零。原边全局 CCM 与某路局部 DCM 可以同时出现。k 变小会改变换流和交叉调整，但并不保证任意电路在 k=0.995 都必然出现同样的轻载脉冲。

输出纹波从已求得的支路电流进入原电容阻抗分析。平均电荷平衡在此之前已检查，不能靠减去平均电流掩盖电压漂移。这仍是“恒直流电容 + 周期电荷平衡”模型，没有逐时间步积分全部电容电压；大纹波、启动、负载阶跃和负载模式切换需要进一步电路仿真。

## 5. Vds 平台、尖峰与选型裕量

| 数值 | 应如何理解 |
|---|---|
| 稳态平台 | 约为 Vin + 反射输出电压；矩阵模式从实际周期波形取值 |
| 漏感钳位峰值 | 换流期间短时达到的实际模型峰值，不应画成整个关断区间都处于该电压 |
| Kc 钳位上限 | Vin+Kc×Vreflect，不再叠加旧振铃裕度；器件耐压仍需另外留量并实测 |

矩阵模式使用实际求解的 Vds 和钳位电流，钳位为理想定压元件；没有 Coss/Cj，因此边沿会出现理想跳变，不代表实测上升时间或寄生振铃。钳位功耗 Pclamp=average(Vc·iclamp) 只记一次，不再另加 ½LσI²f 的估算。

未启用矩阵的快速反激模型：历史 K 仍用 Lσ=(1−K)L；常数 Coss 与漏感形成首个 LC 波瓣，到达钳位后电流按 (Vc−Vr)/Lσ 衰减。漏感能量不足时不虚构钳位导通，K=1 时不画漏感尖峰；MOS 应力上限仍按用户配置的 Kc 取值，与较低的波形峰值分开。没有有效 Kc 时仅显示理想平台，并提示尚未覆盖尖峰。此快速包络未包含变压器分布电容、非线性 Coss、二极管恢复和后续振铃。

Q1 开通图从稳态平台开始；关断图按 t1–t8 对应栅极电荷时间，并叠加各自模型的钳位包络。钳位复位延续至 t8 后时单独标“钳位恢复”，不拉长或重新定义 t7/t8。R/C 初选与损耗共用 Pclamp：R=Vc²/Pclamp，C≈Pclamp/(fs·Vc·ΔVc)；Pclamp=0 时不提出需要耗散漏感能量的有限 R/C。

## 6. 仍需单独复核

- 预设效率在矩阵模式仅用于初值和设计参考，不再给物理方程额外叠加 Vo/η 的压降；最终效率仍统计明确建模的损耗。MOS 开关/栅极/Coss、磁芯、电容 ESR 等损耗不是全部包含在 RL 周期能量平衡中。
- 任意自感/互感矩阵不能唯一分离公共磁芯磁通与空间漏磁。磁链折算的 B(t)、饱和及磁芯损耗是工程参考，不是完整三维磁场结果；应结合磁件结构和实测确认。
- 已解析的 MLT、匝数、线径、股数及 ρ 共同决定电路几何 DCR，铜损使用同一电阻；温度依赖、引线端接、集肤/邻近效应和绕组分布仍需另行确认。
- 本版不包含启动、动态电容、Cj/Coss 换流、反向恢复、寄生振铃、磁饱和反馈或控制芯片逐周期行为。不同轻载钳位及寄生网络可能产生不同结果。
- 不收敛或电荷/能量平衡失败时应调整实际参数和模型，不接受未经验证的应力结果；不能把它当作“自动选择一个合理波形”。
