# 字体、属性保存与画布性能

2026-10-31 后续更新：当前 `20261031-adaptive-layout` 将字号扩为12–40px，步长2px；修正折叠后参数区保留旧滚动位置造成的顶部空白，功率级/器件/电容总览图利用剩余高度，多路输出保持独立滚动与延迟绘制。下文为原版记录。

2026-10-31。运行包：`releases/Windows-x64/20261031-canvas-edit/`。复制到其他电脑需复制整个程序文件夹。

## 字号

桌面架构页和单元计算器顶部都有“界面字号”，可设置11至20px。默认14px；高分辨率屏幕可试16或18px。设置独立保存在 `%LOCALAPPDATA%/PowerDesign/ui-preferences.json`，不写入电源设计 JSON，也不改变电气参数。返回架构或下次启动时保留设置。网页架构字号及原单元字号分别由浏览器保存。

原计算器将 Tk 的点字号、Windows DPI 及窗口自适应倍率叠加，参数栏的固定宽度无法容纳文字。现在使用像素字号，放大窗口不会自动放大字体；左栏随字号调整宽度，标签根据输入框和单位列占用后的剩余宽度换行。画布内节点文字继续随画布缩放，避免改界面字号后破坏节点几何。

## 保存节点和支路

选中对象后在右侧修改。属性面板底部始终有蓝色“保存节点修改”或“保存支路修改”，不必滚动寻找。编辑时显示“有未保存修改”；点击按钮后显示“已保存到当前工程”。桌面也支持 Ctrl+Enter，切换画布对象或保存系统工程时会先提交有效修改；无效值需先修正。

节点保存更新当前工程和本机恢复数据。需要独立文件、备份或传给他人时，再点击顶部“保存系统工程”导出全部节点、连接、布局与单元参数的 JSON。网页顶部保存也会先提交当前属性修改。

## 拖动

桌面不再每帧删除并重建节点、文字及网格，而是保留 Canvas 对象，移动当前对象，更新相邻连线和自动定位的二极管。拖动中不分析预算、不写工程文件；松手后更新画布边界并保存一次。平移同样避免每帧重建画布。

网页缓存节点、边的 DOM 元素及邻接关系，只更新相邻支路；画布范围在手势完成后更新。数值求解内核与电气模型未改动。

## 验证与维护

`tests/canvas_edit_check.py` 检查高 DPI 下的字号、标签和输入框位置、显示偏好保存、电气参数不变、蓝色保存按钮及恢复文件。拖动测试核对 Canvas 对象ID保持不变，且预算和文件写入函数在逐帧更新中均未调用。

本机七节点示例测得：50次局部更新平均约0.35ms；10次全图绘制平均约17.2ms。只是绘图代码耗时，不是端到端帧率；不同电脑、节点数量和后台负载下会不同。数据位于 `artifacts/qa/canvas_edit_20261031/drag-timing.json`。

字体偏好由 `ui_preferences.py` 管理；原生增量图形在 `system_canvas.update_drag`，属性编辑和保存入口在 `system_workspace_ui.py`；网页图形缓存仍在共用 `architecture.js`。旧工程与原字号无关，可继续打开。

实际桌面包已核对：将 OR 容量从50W改为70W，未保存提示出现，固定按钮保存后恢复文件记录70W。计算器通过真实操作调到18px，参数标签与数值框无干涉。自动布局检查覆盖12/14/18/20px，字号不随窗口变化，调整前后设计参数一致。网页测试覆盖字号重开保留、保存状态、节点/二极管两种缩放下的拖动、删除撤销、完整单元进入/返回及 JSON。
