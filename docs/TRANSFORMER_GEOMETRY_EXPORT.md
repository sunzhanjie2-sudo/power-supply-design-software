# 变压器三维建模数据

在个人桌面版的 **磁件 → 变压器可绕制评估** 打开“三维建模设置”，或直接点“导出三维建模数据”。本地 Python 网页在磁件页提供相同入口，采用设置后先重新计算。反激、准谐振反激和有源钳位正激使用已计算的整数匝数、线材及输入端点。此导出使用 Python 内核。

## 从磁件页生成仿真与闭环报告

桌面版的拓扑页、磁件页及右上角“导出报告”现集中打开**联合仿真与报告中心**。需要完整的“变压器 → 带裕量回填 → 电路计算 → LTspice”流程时按[联合报告说明](JOINT_SIMULATION.md)操作；下文的独立场仿真在中心的“工具与模型 → 变压器设置 / 单独场仿真”中保留。

个人 Windows 桌面版可以直接把**当前画布单元**交给本机变压器耦合参数提取器，以 Gmsh 划分网格、Elmer 求磁场，再用场解参数复算电源。以准谐振工程为例，从画布的“打开工程 / 原配置”载入工程，进入 QR 电源单元，在 **磁件 → 磁件设计与温升 → 变压器仿真与闭环报告…** 打开窗口。“变压器可绕制评估”页也能打开同一个窗口。

### 第一次运行

| 窗口字段 | 选择内容 |
| --- | --- |
| 本机提取工具目录 | 已配置好的“寄生参数提取研究”根目录，或带 `_internal` 的完整离线提取器目录。电脑上需有 Elmer，其 `bin` 目录含 `ElmerSolver.exe` 和 `ElmerGrid.exe`。程序从提取设置的 `solver.elmer_home` 读取安装根目录，也支持本机 `ELMER_HOME`。 |
| 提取设置 JSON | 选择对应磁芯与接线的“提取设置.json”。例如 PQ32/30 可在研究根目录的 `项目库/准谐振3230/01_提取设置/` 找到参考设置。模板依赖的磁芯 STEP/BREP、原数据包、材料来源文件（若指定）需要能在本机访问。 |
| 报告保存目录 | 选择有写权限的本地目录。每次仿真在其下新建独立子目录，保留输入、运行状态和实际生成的结果。 |

软件记住本机工具目录、输出位置及按磁芯记录的模板。首次选研究根目录时，项目库里只有一个与当前磁芯型号匹配的 CAD 模板才会被预选。若有多个候选，请自行选择，并核对绕组连接。

### 准备绕组并求解

1. **已有匹配的绕制与提取设置**时，直接点“一键仿真并生成报告”。软件冻结当前单元并核对输入、磁芯、材料、气隙、端口和物理段。
2. **仅有同型号磁芯模板**时，先点“从同型号磁芯准备参考设置…”。软件保留当前单元的匝数、线材和排布，用模板补缺失的净窗口与圆形骨架基准，按当前电源磁路的材料及气隙准备新的提取设置。若已有可用接线则沿用，完全空白时给出“各段同向、按层序串联相加、中间节点无外接”的参考接线。请对照实际绕线图核对弹窗中的尺寸、层序、方向和总气隙。确认后点击“一键仿真并生成报告”。接线只填了一部分、窗口装不下或已装配 CAD 的气隙不匹配时，应先补齐或更换模型。
3. 求解在后台进行。点“停止”可以取消本次任务。发生错误时，窗口保留诊断，“运行目录”可定位对应状态文件或求解日志。

### 读报告并回到画布

- **场仿真报告**显示提取工具的场图、绕组剖面、自感和互感矩阵、有符号的耦合系数以及所有副边理想短路折算到原边的电感。核对端口顺序、同名端和线性材料假设。
- **闭环对比**并列给出设计目标、场解结果，以及原设计和应用场解参数后在输入端点的电源计算。QR 可比较开关频率、占空比、MOS 峰值电流和应力、RCD 漏感及损耗、效率。这里的电源工作点来自同一计算器，场求解器提供的是磁件参数。
- 在 QR 的标量漏感模型中，原边开路自感用于 `L`，原边短路漏感通过 `K = 1 − L短路 / L开路` 换算成 RCD 模型系数。模型启用逐对磁耦合且端口匹配时，按端口名映射各对 `kij`。原始有符号矩阵随报告保存。符号冲突、工况复算失败或复算改变实际绕组几何时，界面保留复核原因。
- 确认上述对比后，点 **“采用参数并重算” → “← 返回系统架构” → “保存系统工程”**。再次打开该工程、进入同一单元，可重开当时的两份报告。工程 JSON 保存参数、结果摘要、哈希和本机报告位置。备份时一并保存完整运行目录，移动目录后可直接打开其中的 HTML。

当前提取使用线性、零直流偏置的磁静态模型。网格收敛、空气域收敛和样机测量分别记录。设计中的交流铜损、磁芯损耗、寄生电容、温升与偏磁饱和仍需各自的模型和验证。下文的几何 ZIP 也可单独导出，并作为本地 Python 网页向研究工具交接的数据。

## 将数据交给建模程序

直接打开原 JSON 再导出，可以保留当时的显示单位、曲线及原始文件编码。也可从命令行生成和核对数据包。

```powershell
& './.venv-web/Scripts/python.exe' cli.py geometry --spec 'examples/40W_CCM_3OUT_FLYBACK.json' --out 'T1.zip'
& './.venv-web/Scripts/python.exe' cli.py verify-geometry 'T1.zip'
```

| ZIP 成员 | 用途 |
|---|---|
| `resolved-cross-section.json` | 主接口 `power-transformer.geometry.v1`。按电气绕组、物理段和每匝每束读取 |
| `geometry.schema.json`、`model-input.schema.json` | 独立 JSON Schema，Draft 2020-12。读端应检查版本、类型和条件必填字段 |
| `calculator-input.json`、`engine-snapshot.json` | 本次计算输入及带内容哈希的双端快照。两端须使用同一套硬件和几何 |
| `source-input.original.json` | 工程编辑后导出时，如保留着载入的源文件，另外保存逐字节原件。直接从原文件导出时原件就是 `calculator-input.json` |
| `model-input.template.json`、`model-input.json` | 本次物理段的填写模板，以及实际采用的设置（如有）。可在界面导入，或传给 CLI 的 `--profile` |
| `cross-section.svg`、`cross-section.png` | 由计算器绘图函数使用同次排布结果生成。灰色挡墙仅为示意 |
| `manifest.json` | 各文件字节数和 SHA-256，关联输入、原件（如有）、几何哈希和快照 ID |

研究端调用 `from transformer_geometry import read_geometry_package` 可取得已校验的主接口字典。独立读取时，先校验清单和版本，再检查段引用、匝数、包围盒及矩阵顺序。

## 坐标和线束

几何长度为 **m**，进入 CAD 时统一乘 1000 转为 mm。原点在两半磁芯接合面的中心，Z 沿中柱，XY 为接合平面。局部 u 为轴向，v 从窗口内边界径向向外。留边和绝缘已经计入坐标。包围盒为 `[u_min,v_min,width,height]`，椭圆宽高均为完整直径。

2026-11-05 可选字段：当完整线圈并绕数大于 1 时，绕组附带 `parallel_wires`、`strands_per_wire` 和 `bundles_per_wire`；`strands` 保持每匝总铜股数，`parallel_bundles` 为每匝总绘制束数。缺省 1 的旧包不必增加字段。逐匝手调位置已反映在每个 bundle 的实际中心与包围盒中，不需要读端再次应用偏移；匝数不因并绕增加。当前与历史 v1 Schema 均由校验器明确识别。

- 圆形轨迹填写净窗口轴向起点 `z0_m` 和内边界半径 `r0_m_if_circular`，得到 `z = z0 + u`、`r = r0 + v`。0 是有效 Z 基准，未知填 `null`。
- 圆角矩形填写全局 XY 平面内的中心、内边界宽高和圆角半径。自定义轨迹提供闭合 XY 折线，从 +Z 看按逆时针顺序给出，禁止自交。内边界位于 v=0，按外法向偏移 v，在 z0+u 绕行。
- 旧逐层方案在解析时获得可复现的段 ID。手动插入、拆分或移动时保留已有段的身份，新段获得新 ID。每个绕组分别记录线束层厚之和、含层间胶带的积厚、首末层跨度。疏绕层同时给出摊开后的跨度和累计线束宽度。
- 每个 `turn_id` 表示段内一个空间匝，`parallel_bundle_id` 表示一支并绕束。同一匝可有多个线束截面。束内填充系数用于估算整束外径，外包络包括绝缘和股间空隙。线材来源及成品外形公差可在 `wire_evidence` 逐绕组声明。

## 接线与就绪判定

按稳定段 ID 填写起止节点、同名端、绕向和依据。绕向指从起点向终点行进、从 +Z 观察的 cw 或 ccw。端口正电流流入同名端。串联连接矩阵 A 的行是物理段、列是电气端口，归算采用 `L_ports = Aᵀ L_sections A`。段电感矩阵以段同名端为正参考，符号只施加一次。并联支路需要另给分流约束，通用串联归算矩阵置为 `null`。

随附三路反激的参考层序是 OUT1_A（6 匝）、P_A（6 匝）、OUT2_A（5 匝）、OUT3_A（2 匝）、OUT1_B（6 匝）。接口示意可用 **A → M → B** 表示两个段串联相加；实际端子编号由用户配置。中间节点 M 若只连接两个绕组段，可在 `terminals` 中声明其外部连接为 `none`，不据示意自动推定实物脚位。本例窗口 12 × 3.3 mm，共 25 个线束截面，名义径向余量约 0.006813 mm。

`ready.cross_section` 表示已得到逐束坐标，容纳结果单独见 `checks.two_dimensional_fit`。`ready.geometry_3d` 表示已具备名义闭合匝路径、基准、绕向和端口接线。轨迹假设带 `assumed` 状态。缺项见 `missing_fields`；窗口超限仍可导出二维数据，超过明细上限会明确标记。

真实骨架干涉、引线、材料频偏模型、网格、场求解收敛与样机测量分开记录。此阶段 `ready.electromagnetic` 为 false。目标 L 和配置 kij 位于 `design_targets`，提取结果需要另附频率、偏置、端口顺序和收敛记录。

磁路初算随 `design_targets.air_gap` 导出，含 μr、le、目标 AL、无气隙电感、气隙及来源。实际加工结构仍由 `core.gap_geometry` 的位置和类型确定。详情见 [磁导率与气隙](TRANSFORMER_GAP.md)。
