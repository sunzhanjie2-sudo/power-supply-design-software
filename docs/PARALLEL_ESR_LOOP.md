# 并联电容 ESR 环路模型

2026-10-25，模型修订 independent-parallel-rc-v1。适用于已启用正定耦合矩阵、周期工作点已收敛的固定频率 SSR 反激，支持 1–6 路输出、每路一颗或两颗电容。复用原有 C_out/Rc、C_out2/Rc2 和第二颗启用开关，不新增另一套电容参数。

## 每颗保留自己的 C 与 ESR

第 k 颗电容支路阻抗为 Zk(s)=Rk+1/(sCk)。两颗并联时采用 Zparallel=Z1×Z2/(Z1+Z2)，再与该路恒阻负载并联。一般不能在所有频率上简化成总 C 加一个 ESR：

    Zparallel(s) = (1+sR1C1)(1+sR2C2) /
                   [s(C1+C2)+s²C1C2(R1+R2)]

它保留两个支路零点和一个支路间附加极点。Reff=Σ(RkCk²)/(ΣCk)² 只作低频参考；R1∥R2 是高频阻抗极限，也不能代替完整网络。

实现采用每颗电容内部储能电压 u_k 作为状态。所有支路连接在同一个电容端 v：

    i_k=(v-u_k)/R_k
    du_k/dt=i_k/C_k
    i_rect,avg=(v-Vblock)/Rload+Σi_k+i_extra_load

ESR 严格为零的理想电容直接并联时共享一个电压状态、容量相加；其他有限 ESR 电容仍各自保留状态。不会将零 ESR 偷换成任意小电阻。停用第二颗时不建立其状态，也不使用其参数。

## 与绕组及峰值内环联立

原周期事件求解器继续提供绕组电流、平均整流电荷和比较器采样量的微扰导数。移除原总电容/负载的周期末更新项后，提取平均整流电流对绕组初始状态、电容端电压和占空比的导数，避免容量或负载重复计算。

只将绕组子系统作双线性低频连续等效，同时转换平均电流及比较器输出的直通项。随后用 KCL、各 RC 支路动态和峰值比较器约束联立，求出统一状态空间 A/B/C/D。电压模式则使用 Vm×δD=δu，不引入峰值反馈。

电容网络不仅修改控制到主输出的传递，也进入所有输出的控制响应、负载扰动及公共反馈分母。额外负载正方向为下拉电流，ESR 对负载瞬时压降的直通项保留。反馈取所选一路防反管前的电容端，输出端仍在防反管后；固定防反压降下两者的小信号增量相同。

三路、每路两颗有限 ESR 电容时共 3 个绕组状态与 6 个电容状态，总计 9 个状态。最多六路时不超过 18 个状态。模型按需建立，沿用后台数值线程和取消逻辑，不在启动时运行全部环路，不需要为每次修改参数执行完整 LTspice 瞬态。

## 精度与边界

这是低频小信号修正，不是完整开关求解器升级。原周期直流和整流电流仍在恒电容端边界下求解，ESR 纹波尚未反算至其电流脉冲；本次不宣称同时解决 Coss/Cj 换流、RCD 电容动态或全部电流峰值误差。ESL、实际光耦/TL431、消隐、驱动延迟和保护也未加入。

原开关纹波与逐颗电容 RMS/损耗仍使用已有复阻抗分流后处理，本次环路网络不重复增加损耗。未启用矩阵的理想/单路兼容模型、QR、PSR、正激维持原有能力，不套用这套耦合支路模型。

微扰步长一致性、较大电容纹波、模式边界及代数耦合病态检查仍保留。内环周期谱描述原恒电容端绕组核；快速 RC 极点经 Tustin 映射靠近 −1，不据此宣称真实 PWM 周期倍化。Bode 扫描和自动整定的旧临时带宽限制继续停用；高频准确度未因此获得保证。

## 代码与核对

- output_capacitors.py：逐颗 C/ESR 与恒阻负载的实际连续网络。
- multi_output_loop.py：周期导数提取、绕组低频等效及联合代数求解。
- tests/output_capacitors_check.py：与直接复阻抗对比、零 ESR、支路交换及关断。
- tests/multi_output_loop_check.py：独立频域 KCL、三/六路、反馈切换、DC 灵敏度及自动整定。
- tools/qa_parallel_esr_loop.py：复核用户配置、旧/新模型与实际低频 FRA。

公式采用原电容支路电路定律；反激功率级 ESR 零点的原厂依据可参见 [MPS 环路补偿说明](https://www.monolithicpower.com/en/learning/resources/how-to-design-a-feedback-loop-compensator-for-a-flyback-converter-in-four-steps)。多输出联立和周期核连续等效是本项目的实现假设，不将单路公式当成多路完整验证。
